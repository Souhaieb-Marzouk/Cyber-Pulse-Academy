1. What you will learn here

You will learn about M1057 — Data Loss Prevention (DLP). This is a Mitigation in the MITRE ATT&CK framework. A Mitigation is a defence. It is not something attackers do. It is something you, as a defender, can put in place to stop or slow down attacker behaviour.

Imagine you are a new analyst in a Security Operations Centre (a SOC — the team that watches company systems). Part of your job is to stop sensitive data from leaving the company. DLP is the main tool family for that job. It finds data that looks sensitive (for example numbers that look like credit cards), watches it as it moves, and blocks risky transfers.

In real work you will meet this mitigation everywhere: SOC analysts triage DLP alerts, incident responders use DLP to stop an active leak, detection engineers tune DLP rules, GRC analysts map DLP to company policy, and cloud and email administrators maintain the DLP features inside platforms like Microsoft 365 or Google Workspace. The documents you will touch include DLP policies, alert runbooks, and control matrices.

The risk DLP addresses is real: personal data, financial records, and trade secrets can leak by accident (a misdirected email) or on purpose (an attacker or an unhappy employee). A leak can mean fines, lost customers, and broken trust.

In this EASY exam you will build the foundations: what DLP is, the implementation measures M1057 lists for putting DLP in place, which attack techniques it addresses, and which ATT&CK tactics those techniques belong to.

2. Keywords covered in this exam

Object basics

  • M1057 — Data Loss Prevention (Mitigation)
  • Identify, categorize, monitor, and control data movement
  • PII, intellectual property, financial data
  • Accidental and malicious data leaks

Implementation measures in this exam

  • Sensitive Data Categorization — scan and tag files by pattern
  • Exfiltration Restrictions — block unapproved email attachments, USB, unencrypted cloud uploads
  • Data-in-Transit Monitoring — inspect outbound network traffic
  • Endpoint Data Protection — block copy-paste, printing, file sharing

Techniques addressed (foundations)

  • T1005 Data from Local System · T1025 Data from Removable Media
  • T1052 / T1052.001 Exfiltration Over Physical Medium / over USB
  • T1567 Exfiltration Over Web Service
  • T1048 Exfiltration Over Alternative Protocol

Tactics and lifecycle

  • TA0009 Collection — data is gathered
  • TA0010 Exfiltration — data leaves the organisation
  • Where DLP sits: at the exit doors of the network
