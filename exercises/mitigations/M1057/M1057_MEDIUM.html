1. What you will learn here

This is the MEDIUM exam for M1057 — Data Loss Prevention (DLP), a Mitigation in ATT&CK. In the EASY exam you learned what DLP is. Here you go one step further: you will connect DLP to the exact attack techniques it addresses, and you will practise the two-step thinking a SOC analyst uses every day: first what is happening, then which control stops it.

You will work like a real analyst. Alerts arrive from a web proxy, an email gateway, and endpoint agents. You will read the artefact, decide which ATT&CK technique the behaviour maps to (for example T1567 Exfiltration Over Web Service or T1052.001 Exfiltration over USB), and then choose the DLP measure from M1057 that prevents it — Data-in-Transit Monitoring, Exfiltration Restrictions, Cloud Data Security, Endpoint Data Protection, or Sensitive Data Categorization.

In a real job these skills appear in your daily ticket queue, in incident reviews, and in detection-engineering work where you tune a DLP rule after an incident. GRC analysts use the same mapping skill when they show auditors that a control covers a named technique. CTI analysts use it when they write reports that name both the technique and the defence.

You will also see the honest limits of DLP: it cannot read content inside encrypted tunnels, and it needs the right telemetry at the right place (network edge, endpoint, email gateway, cloud tenant). Knowing what a control does not cover is as valuable as knowing what it does.

2. Keywords covered in this exam

Techniques addressed in depth

  • T1567 / T1567.004 Exfiltration Over Web Service / Webhook
  • T1048 / .002 / .003 Exfiltration Over Alternative Protocol (encrypted and unencrypted)
  • T1041 Exfiltration Over C2 Channel · T1020.001 Traffic Duplication
  • T1052 / T1052.001 Physical Medium / USB · T1025 Removable Media
  • T1537 Transfer Data to Cloud Account · T1005 Data from Local System

Measures mapped to techniques

  • Email flow rules vs external forwarding (T1020.001)
  • Blocking uploads via browsers (T1567, T1048)
  • Blocking unencrypted protocol transfers (T1048.003, T1041)
  • USB and physical medium blocks (T1052.001)
  • Blocking external cloud sharing (T1537)

Tactics and telemetry

  • TA0009 Collection vs TA0010 Exfiltration placement
  • Web proxy logs · email gateway logs · endpoint DLP agent logs · CASB logs
  • Pattern hits: card numbers and SSN patterns

Alert handling workflow

  • DLP alert triage steps in order
  • Validate destination approval and user intent
  • Block / quarantine / report to the data owner
