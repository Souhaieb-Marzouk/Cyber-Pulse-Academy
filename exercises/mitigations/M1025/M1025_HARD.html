● What you will learn here

This exam works MITRE ATT&CK mitigation M1025 — Privileged Process Integrity at the level of real decisions. M1025 is a mitigation — a control you design, deploy, verify and defend in front of stakeholders. Its measures: Protected Process Light for LSA (RunAsPPL), memory protections (CFG, DEP, ASLR), code-signing validation (WDAC, AppLocker), access controls (DACLs, Mandatory Integrity Control, disabling unneeded debug capabilities), and kernel-level protections (PatchGuard, SELinux, AppArmor).

Who uses this at work? You will wear the hats that carry this control: the hardening programme lead sizing exceptions for broken legacy agents, the IR handler ordering evidence steps after a blocked SSP, the detection engineer naming the exact mechanism behind each refusal event, and the control owner writing the residual-risk paragraph the CISO reads aloud.

What will you practise here? Near-miss discrimination: options that look right and are wrong, artefact sets that must be read together (Code Integrity 3033/3065, LsaSrv boot events, Sysmon handle requests), one configuration task in the fake shell (icacls integrity labels), and decisions where the least aggressive action is the correct one. Explanations after every Check tell you why each near-miss was built to catch you.

● Keywords covered in this exam

Rollout decisions and exceptions

  • Pilot rings, plug-in inventory before enforcement
  • Vendor exception paths vs permanent weakening (the classic mistake)
  • Per-app CFG fixes instead of global rollback

Detection and telemetry

  • Code Integrity 3033 / 3065 refusals; LsaSrv protected-mode event
  • Sysmon-style LSASS handle denials (0x1010) and what they prove
  • Artefact-to-verdict mapping; audit mode vs enforcement

Access controls measure

  • DACLs limiting process interaction; MIC integrity labels
  • icacls /setintegritylevel — configuration in the shell
  • Disabling unneeded debug capabilities

Techniques and coverage

  • T1003.001; T1547.002 / .005 / .008; T1556.001 — per host class
  • Coverage gaps where PPL is not enforced

Residual risk

  • Signed-but-vulnerable drivers (BYOVD) and kernel paths
  • Driver blocklists and compensating controls

● How this exam works

  • Pass mark: 70%. Your score is the sum of exercise credits over the exercises you actually answered. PASS means you reached the mark; FAIL offers a Retake button that reshuffles everything.
  • Exercise types in this file: an artefact triage board, near-miss single questions, a multi-select coverage analysis, one fake-shell configuration task (icacls integrity labels), matching of refusals to mechanisms, ordering of IR steps, a two-step branching conflict, and executive-note fills.
  • Timer and the two pauses. A 45-minute countdown runs while you work. The manual Pause button stops the timer and hides the exercise for a real break. When you press Check, the timer stops automatically so you can study the feedback without pressure — it resumes only when you press Next (or Final Submit on the last exercise). The header always shows which pause is active.
  • Partial credit. Multi-answer exercises score per item: correct picks add, wrong picks subtract. The credit is (right — wrong) ÷ items, never below zero. Single-answer exercises are simply right or wrong.
  • Hints. One hint per exercise, and it costs 10% of that exercise's credit. The hint nudges; it never gives the answer away.
  • Skipping. Skip is free. Before you finish, a review screen lists every skipped exercise so you can go back and answer it. Skipped-and-never-answered exercises are excluded from both score and denominator — they count neither for nor against you. Skip and Hint never stop the timer; only the two pauses do.
