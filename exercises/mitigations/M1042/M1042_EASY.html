📚 What you will learn here

You will learn what mitigation M1042 is and how to use it at work. M1042 is a Mitigation in the MITRE ATT&CK framework. ATT&CK also has objects that describe attackers: tactics (attacker goals) and techniques (the ways attackers reach those goals). A Mitigation sits on the defence side: it tells you what you can do so those attacker techniques stop working. The full name of this one is Disable or Remove Feature or Program.

The idea is simple. Every program, feature and service on a computer is a possible door for an attacker. If the business does not need that door, you close it: you remove the program or disable the feature. This is called shrinking the attack surface — the total set of doors an attacker could try.

The ATT&CK page for M1042 lists five practical measures: remove legacy software (old Flash or Java versions that no longer get security updates), disable unused features (like SMBv1, Telnet or RDP when nobody needs them), control what users can install (with group policies), remove unnecessary services that run by default, and restrict browser add-ons and plug-ins that are not needed for work.

Who uses this at work? SOC analysts check that risky features are switched off when they investigate alerts. System engineers build hardening baselines (standard safe settings) with Group Policy. GRC analysts write the rules and keep the exception register. Vulnerability managers love this control because every removed program is one less thing to patch. Red teamers know a hardened host has fewer ways in. Threat-intel analysts map real incidents to the ATT&CK techniques that M1042 addresses, so leaders can see why the hardening money is well spent.

In this EASY exam you will practise the foundations: recognising what belongs to M1042, spotting features nobody uses, and knowing the simple steps of a safe hardening change.
