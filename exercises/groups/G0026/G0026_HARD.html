What you will learn here

This is the HARD tier of the G0026 APT18 exam series. You already know the page's rows. Now the scenarios stop helping you: artefacts carry noise, options carry near-misses, and the obvious answer is sometimes wrong on purpose. The skill under test is discrimination - separating the behaviour this page lists from its convincing neighbours.

The group profile gives you a rich playbook to discriminate within: valid accounts into external remote services (T1078 + T1133 dual-listed), cmd.exe execution, at.exe lateral movement with the type-3 logon plus 4698 anchor, Run-key persistence in HKCU, HTTP and DNS C2 channels, file and directory discovery, tool transfer onto hosts, payload string obfuscation, and deletion of tools and batch files. Around each row live false positives - nightly backup TXT jobs, signed patch scripts, users deleting their own files - and around each row live sibling techniques that are almost, but not quite, the one the page lists.

You will work like a senior of the team: triaging a morning queue with three verdicts, ranking response steps inside a playbook, taking four decisions on a live host without destroying evidence, writing attribution sentences that survive review, and mapping controls to rows with a reason for every rejection. Some questions ask you to defend the least aggressive correct action; some hide a benign case that looks exactly like the actor.

Everything remains grounded in the G0026 page and the references it cites. Read every artefact twice; the second read is where the near-miss loses.

How this exam works

  • Passing score: you pass with 70% or more, counted only over answered exercises.
  • 17 exercises, one per screen. Types in this file: a filtered log viewer, decision scenario with four steps, multi-select with near-misses, fill-in-the-blank spec, ranking, triage queue with three verdicts, matching, ordering, and five single-choice questions.
  • Timer: a 42:00 countdown. Pause stops it and hides the exercise. Check stops it automatically while feedback is open and it resumes on Next. In the branching scenario only the final Check pauses; intermediate step confirmations keep the timer running. Skipping never stops the timer.
  • Partial credit: multi-item exercises award (H − W) / N - correct items count up, wrong selections subtract, selecting everything scores zero.
  • Hints: one per exercise, costing 10% of that exercise's credit. On this tier hints remove one wrong path, not point at answers.
  • Skips: a review screen before the end lets you answer skipped exercises until the timer ends; never-answered exercises are excluded from the score.
