What you will learn here

This exam takes you one level deeper into the G0026 APT18 group profile. On the EASY level you learned what the object is. Here you learn to work with it: read a log or an artefact, name the behaviour in plain words, then bind it to the right technique row on the page - in two steps, every time.

APT18's page gives you a compact playbook: sign into external remote services with valid accounts, run commands with cmd.exe, upload tools onto victims, persist with an HKCU Run key, schedule jobs with the old at scheduler, talk out over HTTP and DNS, discover files and system information, and delete tools and batch files on the way out. Each row is a chance to detect the actor - if you know which sensor sees it.

Real work looks like this every day. A SOC analyst reads a proxy or VPN log and asks which page row this is. A detection engineer maps rows to telemetry sources and writes the analytic. An incident responder orders the events into a campaign flow. A CTI analyst drafts bulletins and must keep every claim tied to the page. A control owner picks mitigations - like MFA or password policy - that blunt the specific path the actor takes.

The exercises here give you short artefacts and ask you to combine two facts: behaviour plus technique, logon plus anomaly, control plus path. The explanations teach the why in simple words, so a wrong answer still teaches you the page. Everything is built from the G0026 page and the references it cites.
