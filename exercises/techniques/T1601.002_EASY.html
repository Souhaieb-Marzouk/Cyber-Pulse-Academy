What you will learn here

You will learn about T1601.002 — Downgrade System Image. This is a Sub-Technique in the MITRE ATT&CK framework. A sub-technique is one specific way an attacker can carry out a bigger technique. Here the big technique is T1601 — Modify System Image, and this sub-technique is the version where the attacker installs an older operating system on a network device, like a router, a switch, or a firewall.

Imagine you are a new analyst in a Security Operations Centre (SOC). One morning, a router in your company runs an older software version than yesterday. The boot setting now points to an old image file. An attacker may have done this on purpose. Why? Old versions often have weaker encryption and fewer updated defenses. This makes the attacker’s next steps easier and quieter.

Many roles use this knowledge every day. A SOC analyst reads device logs and alerts. A network security engineer hardens devices with boot integrity and signed images. A threat hunter looks for image transfers over TFTP, FTP, or SCP. An incident responder keeps evidence safe before fixing a device. A CTI analyst maps attacker behaviour to ATT&CK IDs in reports. A detection engineer writes the rules that catch version changes. A red teamer learns the attacker’s trade-offs. A GRC analyst maps this technique to controls like NIST 800-53 SI-07 (software and firmware integrity).

The tools you will meet in this exam are simple and real: device commands like show version, boot setting lines, syslog lines, and change tickets. The risk this technique addresses is real too: an attacker who controls the operating system of a network device can hide there for years.
