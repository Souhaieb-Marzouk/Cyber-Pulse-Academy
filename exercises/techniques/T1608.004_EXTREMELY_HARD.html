What you will learn here

You will learn how T1608.004 — Drive-by Target works as a Sub-Technique of T1608 Stage Capabilities, in the Resource Development tactic (TA0042) on the PRE platform: the adversary's workshop, before any victim appears. Drive-by Target means preparing a website so that people who visit it during the normal course of browsing get infected or quietly profiled — no click, no attachment, just a landing. This file sits at the expert end of the series: the staging has been found, and the fight moves to mitigation and response.

You will revise the terrain in plain words. A watering hole compromises sites a specific community visits regularly, so members are hit during ordinary work. Malvertising buys ad space through legitimate providers so payloads run on reputable pages. Bucket staging edits script files many sites load from publicly writeable cloud storage, and injected JavaScript or a hidden iframe carries the payload in the page itself. Staged profilers measure each visitor's browser first — the T1592 pattern — so the exploit is spent only where it will land.

The heart of this file is M1056 Pre-compromise, the only mitigation ATT&CK assigns to this technique. You will learn its full measure list: limiting information exposure, protecting domain and DNS with DNSSEC and WHOIS privacy, external monitoring with Shodan- or Censys-style services, threat-intel sharing through MISP-style platforms, email protections and training. You will also learn what it does not list — ad-blockers are not a formal M1056 measure — and the response moves that flow from it: lookalike takedowns, executive briefings, and the costly call to pull a watered site offline.

You will meet three documented campaigns close up. FIN7 compromised a digital-product website and modified download links to point to trojanized versions of the offered products. The C0010 operation compromised the login page of a legitimate shipping company, likely as a watering hole collecting visitor information. Mustard Tempest injected malicious JavaScript into compromised websites to infect victims via drive-by download. Each act sits on a different surface, and the response differs with it.

This is real work for several roles. A GRC analyst maps controls to the M1056 text and defends citations in audit. A CTI analyst turns contradictory signals — a changed script hash against an owner's reassurance — into an evidence pack for the national CERT. An incident responder orders the pressured sequence: scope the exposure window, brief leadership, request the takedown, escalate to the costly offline step only if infections continue, then share IOCs so the community pre-blocks the staging hosts. The 15 exercises cover all of it, ending on a takedown-evidence terminal.
