🎓 What you will learn here

You will learn about T1566.004 — Phishing: Spearphishing Voice. Many people call this attack vishing (voice phishing). It is a sub-technique in the MITRE ATT&CK framework. That means ATT&CK keeps it inside a bigger technique named T1566 — Phishing, and this sub-technique describes one special way of doing it: the attack arrives through a phone call or another live voice channel, not through an email attachment or a link.

Imagine you work at the company help desk. Your phone rings. The caller sounds like an internal IT colleague. He is calm, friendly, and in a hurry. He says the security team must reset your VPN access right now, and he asks you to read out the one-time code you just received. That is exactly what this sub-technique describes: a person uses voice to trick someone into giving access — a password, a multi-factor approval, or the install of a remote-control tool.

You will meet this object in many real jobs. A SOC analyst triages user reports of strange calls. An incident responder handles what happens when a victim installed a remote access tool during a call. A threat hunter looks for calls followed by odd downloads. A CTI analyst briefs the company about groups such as Scattered Spider and Storm-1811, which are known to use vishing. A detection engineer builds and tunes the ATT&CK detection strategy DET0245 from call logs, VoIP/SIP logs and MFA logs. A GRC analyst maps the user-training control (M1017) onto policy. The artefacts you will see are simple: call log records, MFA push logs, and software install events. The risk is serious: vishing often opens the door to account takeover and ransomware.

In this EASY exam we build the foundations: what this sub-technique is, where it sits in ATT&CK, what the attacker does on the call, and what a careful user and a first-line SOC should do.

🔑 Keywords covered in this exam

Every exercise below tests one or more of these concepts. They come directly from the MITRE ATT&CK page for T1566.004.

ATT&CK object basics
  • T1566.004 — Spearphishing Voice
  • Sub-technique of T1566 (Phishing)
  • Tactic: Initial Access (TA0001)
  • Sibling sub-techniques: T1566.001 / .002 / .003
Adversary behaviour
  • A voice / VoIP call as the delivery channel
  • Impersonation of a trusted source (IT help desk)
  • Urgency and alarm as pressure
  • Asking for MFA codes or approvals
  • Directing victims to URLs or remote tools
Platforms (from the ATT&CK page)
  • Identity Provider
  • Windows
  • macOS
  • Linux
Telemetry basics
  • Call log records
  • MFA push logs
  • Remote tool install events
First-line defence (M1017)
  • Verify the caller's identity
  • Hang up and call back an official number
  • Never share one-time codes
  • Report strange calls to the SOC
