🎓 What you will learn here

You already know what T1574 — Hijack Execution Flow is: attackers abuse the way the operating system finds and starts programs and libraries, so a trusted-looking program runs their code. This MEDIUM exam goes one level deeper, on the exact sub-techniques of the live ATT&CK page.

You will work the details a SOC analyst, detection engineer and incident responder actually need: which folder Windows checks first when a program asks for a library; how the PATH variable, unquoted service paths and weak service permissions are abused (T1574.007, .008, .009, .010, .011); how the .NET profiler settings (T1574.012 COR_PROFILER) and in-memory tricks (T1574.013 KernelCallbackTable, T1574.014 AppDomainManager) divert execution; and which telemetry (module loads, registry, services, file writes) exposes each one.

You will also meet the page's controls: M1044 Restrict Library Loading, M1022 file and directory permissions, M1024 registry permissions, and M1018 user account management — and you will apply them to concrete cases instead of reciting definitions.

Everything here is based on the T1574 ATT&CK page: its sub-techniques, its mitigation list, and its detection strategy DET0218 with the Windows analytic AN0609 (“processes loading libraries from abnormal paths”) and the macOS analytic AN0611.
