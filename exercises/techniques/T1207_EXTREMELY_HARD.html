What you will learn here

This is the expert tier for T1207 — Rogue Domain Controller. Exercises chain three or more ideas, include realistic noise and missing information, and ask for the kind of call a senior analyst, IR lead or detection engineer must defend in front of a CISO and counsel. In ATT&CK this object is a Technique: one specific attack method.

The full mechanics you must command: registration needs Administrator privileges (Domain or DC-local) or the KRBTGT hash, and creates server + nTDSDSA objects in the AD Configuration partition. Changes arrive as inbound replication with no originating-change record, so SIEM sensors and change audits can stay silent; replication metadata can even be tampered with. Detection therefore correlates multiple weak signals — object changes in the Configuration partition, unexpected use of Directory Replication Service SPNs (the GC/ or E3514235-… UUID), replication RPC from non-DC hosts, and the 4928/4929 partnership bracket.

Expect senior-grade artefact sets: stale CMDB records, uninstalled EDR agents, unsigned pentest authorisations, payroll batch windows, legal evidence-preservation requests and board-level comms. Some correct answers cost real money or downtime; some are 'gather more evidence' or 'escalate' — and one widely quoted best practice is wrong in this specific context.

Hints only restate a constraint you may have missed. Read every artefact; the truth is usually in what is missing, not in what is loud.
