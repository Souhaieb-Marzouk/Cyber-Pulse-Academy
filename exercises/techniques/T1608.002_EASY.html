What you will learn here

Welcome! In this exam you will practice T1608.002 Upload Tool, a Sub-Technique of T1608 Stage Capabilities. It lives in the Resource Development tactic (TA0042) and runs on the PRE platform — the part of the ATT&CK Matrix that happens before an attacker touches any victim. "Staging" means placing software somewhere it can be reached later. Upload Tool is one specific staging move: uploading a tool to third-party or adversary-controlled infrastructure so it is accessible during targeting.

A staged tool is not malware. It is legitimate software — open or closed source, free or commercial — that an adversary repurposed for malicious use. ATT&CK's classic example is PsExec (S0029), a normal administrator utility. The sibling sub-technique T1608.001 Upload Malware covers software that was built malicious from the start. That build-intent split is the key idea of this file.

Where do tools get staged? On servers the adversary bought or rented (T1583 Acquire Infrastructure), on systems they compromised (T1584 Compromise Infrastructure), on adversary-controlled GitHub-style repos, on Platform-as-a-Service apps, on one-shot file-hosting portals, and on cloud storage or paste sites. One rule matters everywhere: the staged file must stay reachable, so the victim network can pull it later with Ingress Tool Transfer (T1105).

This topic shows up in real work. A SOC analyst sees the victim-side pull of a staged RMM (remote monitoring and management) installer in proxy logs. A CTI analyst tracks staged tool URLs and links them to campaigns — for example, Medusa Group hosting a ConnectWise-class RMM zip on a public file-hosting service. An IR responder traces where a tool came from during an incident. A threat hunter watches for pulls of dual-use admin utilities. A detection engineer knows the staging act itself hides outside victim visibility, so they build detection on the downstream pull. And a red teamer stages tools in authorized operations too — same technique, approved target.

In the next 15 exercises you will define the technique, separate tools from malware, place it on the Matrix, sort staging locations, follow a staged file to the victim, and read logs of staging and pulls. Every exercise gives you a hint, an explanation, and a study pointer. Take your time — accuracy beats speed.
