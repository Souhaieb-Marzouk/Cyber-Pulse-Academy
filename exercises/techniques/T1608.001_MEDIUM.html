What you will learn here

Welcome back — this MEDIUM exam takes you one level deeper on T1608.001 — Upload Malware, the Sub-Technique of T1608 (Stage Capabilities) that sits in the Resource Development tactic (TA0042) on the PRE platform. The platform name simply means the action happens before any victim contact: the adversary uploads malware — payloads, droppers, post-compromise tools, backdoors — to third-party or adversary-controlled infrastructure so it is reachable when the operation needs it.

So what does the upload actually buy the adversary? A stable, reachable link lets the operator swap or update the payload behind one URL without resending a single lure. Hosting on reputable cloud services adds credibility, blends with normal SaaS traffic and muddies attribution. Some venues are built to survive takedowns: IPFS is peer-to-peer storage where files are found by their content hash, so there is no single server to seize, and a blockchain smart contract (a small program stored on a blockchain) holds data that no provider can remove. On top of that, masquerading — such as typosquatting a popular library name — raises the chance a victim installs the lookalike by mistake, and chat-platform CDNs like Discord hand out attachment links users already trust.

The technique has firm neighbours in ATT&CK. Upstream, Develop Capabilities (T1587) and Obtain Capabilities (T1588) produce or buy the malware that T1608.001 then stages. Downstream, the victim-side pull of the staged file is Ingress Tool Transfer (T1105), a chance install of a backdoored file is User Execution (T1204.002), and a backdoored package spreading through a trusted software store becomes Supply Chain Compromise (T1195).

You will use this in real work. As a SOC analyst, you will correlate download alerts with the staged URLs behind them. As a CTI analyst, you will track staging infrastructure — ATT&CK's detection strategy DET0824 leans on Internet Scan, meaning external scanning of attacker-controlled servers, not victim telemetry. As a threat hunter, you will look for open directories and unexpected file stores; as an IR analyst, you will source where a payload was hosted; as a detection engineer, you will cover the downstream pull and execution; and as a red teamer, you will stage payloads in authorized operations while weighing the same trade-offs the adversaries weigh.

The fifteen exercises below each connect two ideas — recognise a staging choice, then reason about what it enables or costs. You will finish with a terminal exercise: safe header reconnaissance of a suspect staging URL for a CTI report. Ready?
