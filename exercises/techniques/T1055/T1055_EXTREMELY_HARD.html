4. Exam rules

Scoring

  • This file holds one batch of tasks, all at level:
  • Pass mark: %. The score is a percentage of the tasks you actually answered.
  • Multi-select tasks score all or nothing: every correct option and no wrong option.
  • A hint costs 10% of that task's points, and the cost is applied only when you submit an answer to that task. A hint on a task you then skip and never answer costs nothing.
  • Every task is worth the same, and every task is scored all or nothing. There is no partial credit.

Timer and pause

  • You have minutes for this batch. The timer starts when you press Start.
  • Press Pause any time you need a break. While paused the exercise is hidden on purpose, so you cannot read it and think about it.
  • One task in this batch carries a shorter decision window. Where that applies, the window is named on the task itself.
  • When the timer reaches zero the exam ends and your answered tasks are scored.

Skip and review

  • Every task has a Skip button. Skipping costs nothing.
  • Before the exam ends you get a Review skipped exercises screen. You may return to a skipped task as many times as you like, while the timer is still running.
  • If you finish while a task is still not answered, that task is excluded from the score: it is not counted as right, not counted as wrong, and its points are not added to the possible total. Example: 10 tasks answered out of 13, 8 of them right → raw score 8/10 = 80%.
  • The final percentage applies the hint deduction to that raw score, so the two numbers can differ. Both are shown on the results screen.

How to answer

  • Read SCENARIO, then QUESTION, then work in YOUR ANSWER. Those three blocks always appear in that order.
  • Long scenarios can be collapsed after reading; a one-line summary stays visible.
  • Drag-and-drop works with the mouse, with touch, and with the keyboard: press Enter or Space on an item to pick it up, move to a bucket, then press Enter again to drop it. To move an item back, click it and then click the item bank, or drag it.
  • In a word-bank task, a blank shows the first letter of the missing word followed by one dot per remaining letter. That is a length clue, not the answer.
  • On the left of every option row there is a letter (A, B, C …). Drag-and-drop items and word-bank words also carry a letter, so the shuffle position is always visible even after you have moved something.
  • All keys and indicators in this file are written in a defanged form (hxxp://, 10[.]0[.]0[.]1) so nothing here can be clicked by mistake.
