ⓘ What you will learn here

T1683.001 is a Sub-Technique of T1683 (Generate Content) and covers the written side of that work: phishing lures, fraudulent financial (BEC) letters, fabricated job postings and employment credentials, decoy documents, and the persona content and narratives that keep a fake identity believable. It sits in the Resource Development tactic on PRE platforms, so the writing happens before a compromise, outside the victim's estate.

Real teams touch this technique from several seats. CTI analysts cluster lure texts into campaigns and map them to ATT&CK. SOC analysts handle the letters that already arrived. Detection engineers tune mail security gateway rules for lookalike senders. Brand and digital-risk teams hunt fake domains and letters that abuse the company name. Red teamers author lures only inside authorized engagements.

The tools of this trade are defensive ones: mail security gateways, brand-monitoring and digital-risk services, and takedown services that ask registrars to remove lure infrastructure. A typical deliverable is a CTI report that maps each lure cluster to ATT&CK techniques and proposes where to detect it.

The risks sit downstream. The same letter can feed Phishing (T1566), Spearphishing via Service (T1566.003) when it rides a legitimate platform, Phishing for Information (T1598) when it harvests credentials, or Financial Theft (T1657) when it moves money.

Remember the strategy: creation happens pre-compromise, and M1056 Pre-compromise is the only mitigation ATT&CK lists, because no control stops someone from writing text. Detection therefore happens where content lands — gateways, brand monitoring, report channels, out-of-band verification. This MEDIUM file trains exactly that two-step habit: classify the written content, then decide where you can act.
