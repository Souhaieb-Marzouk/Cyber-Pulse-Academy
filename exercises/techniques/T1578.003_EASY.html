What you will learn here

This exam is about the MITRE ATT&CK sub-technique T1578.003 — Delete Cloud Instance. MITRE ATT&CK is a public knowledge base that describes what real attackers do. This object is a sub-technique: a special case of the parent technique T1578 — Modify Cloud Compute Infrastructure, and it belongs to the tactic Defense Evasion. In this exam you will learn the basics of the real work around it: what a cloud instance is, why attackers delete cloud instances, which commands delete instances in AWS and Azure, how defenders find these actions in cloud logs, and which simple permissions stop this attack.
