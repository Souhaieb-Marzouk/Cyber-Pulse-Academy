What you will learn here

T1690 is a Technique in MITRE ATT&CK — the public catalogue that describes the actions real attackers use. This technique sits in the Defense Impairment tactic area (TA0112), the part of the catalogue for actions an attacker takes to weaken or switch off the protections and records that defenders rely on.

Prevent Command History Logging means an attacker stops the system from recording the commands they type, so their future actions leave no trail in command-history files. In this exam you will practise noticing when that has happened, naming the exact setting that was abused, and deciding what a defender should do next.

You will meet this technique in real work. A SOC analyst triages an alert about a changed shell setting. A threat hunter looks for accounts whose history file never updates. An incident responder preserves a live process's environment as evidence. A CTI analyst maps reported behaviour — such as APT38's habit of typing a space before every command — to ATT&CK. A detection engineer tunes the analytics AN1555–AN1559. A GRC analyst writes the hardening policy. A red teamer learns which of their actions would be recorded — or not. You will also see the risk: when command history is switched off, investigations lose their best record of what the attacker did.

Keywords covered in this exam

Prevent vs clear

  • T1690 — Prevent Command History Logging (stops future logging)
  • T1070.003 — Clear Command History (erases history already recorded)

Linux & macOS shell mechanics

  • HISTFILE and ~/.bash_history
  • HISTCONTROL values: ignorespace / ignoredups / ignoreboth
  • The space-prefix trick and its interplay with ignoredups
  • export HISTFILESIZE=0
  • Missing ~/.bash_history updates on bash/zsh shells (analytic AN1556)

Windows PowerShell mechanics

  • PSReadLine and ConsoleHost_history.txt
  • Set-PSReadLineOption -HistorySaveStyle SaveNothing
  • Set-PSReadLineOption -HistorySavePath (redirect vs stop)

Platforms & detection analytics

  • The T1690 platform list: ESXi, Linux, Network Devices, Windows, macOS
  • Detection Strategy DET0563 and analytics AN1555–AN1559
  • ESXi shell sessions with no recorded commands

Mitigations & hardening decisions

  • M1039 — Environment Variable Permissions
  • M1028 — Operating System Configuration (ignoredups instead of ignoreboth)
  • Shell-profile hardening review and spot-the-mistake
  • Risk-ranking hardening gaps across a fleet
  • Live /proc/<PID>/environ inspection during triage
  • Step-by-step triage of an env-var change alert

Real-world behaviour

  • APT38 (G0082) space-prefix sessions on an admin host
  • Sea Turtle (G1041) unset Bash and MySQL history files
