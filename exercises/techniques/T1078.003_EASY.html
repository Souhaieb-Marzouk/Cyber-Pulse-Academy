ⓘ What you will learn here

This unit teaches T1078.003 — Valid Accounts: Local Accounts. It is a sub-technique of T1078 (Valid Accounts). It is about adversaries who obtain and abuse the credentials of local accounts. Local accounts are configured by an organization on a single system or service — for users, remote support, services, or administration — and they are managed on the host itself, not by a central directory such as a domain controller.

You will meet this object in real work. A SOC analyst reads the Windows Security log on a workstation and asks why the local admin account signed in at 02:10. An IR responder traces how far one stolen local password has travelled. A detection engineer builds SIEM rules on 4624, 4625, and 4672 for local accounts that never normally log on. An IT support technician manages these accounts every day and shrinks the attack surface by removing the unused ones. A red teamer tests, under authorisation, whether one local admin password opens more than one host.

The daily tools are few: the Windows Security log, a SIEM to search it, a password manager, and LAPS-style tooling that gives every host its own local admin password. The risks are real: a valid local account works with no malware, blends with normal activity — the Stealth (the defense-evasion tactic) side of the card — and a reused local admin password can turn one leak into access to every host that shares it.

In this EASY exam you will define the sub-technique, route accounts to the right sibling (.003 local, .002 domain, .004 cloud), read local logon telemetry, and connect the MFA, password, and hygiene controls that stop local-account abuse.

⚖ Keywords covered in this exam

Object basics & boundaries

  • Local accounts are configured on one system or service — host-managed, not domain-managed
  • Kinds on the page: users, remote support, services, administration
  • Tactics: Initial Access, Persistence, Privilege Escalation, Stealth (defense evasion)
  • Who manages the account decides: .003 local · .002 domain · .004 cloud

Telemetry & detection

  • Workstation Security log: 4624 success, 4625 failed, 4672 special privileges
  • LogonType=2 means a person at the keyboard — off hours make it a signal

Mitigations & controls

  • M1032 MFA protects local accounts even without a domain or cloud service
  • M1027 Password Policies: complex, unique local admin passwords on every system
  • M1018 User Account Management: remove inactive or unused local accounts

Reuse risk

  • One local admin password shared by many hosts — one leak opens them all
