What you will learn here

This is the HARD tier of the T1686.002 — Network Device Firewall exam series. T1686.002 is a sub-technique of T1686 — Disable or Modify System Firewall in MITRE ATT&CK: it covers an adversary disabling network-device firewall mechanisms entirely, or adding, deleting, or modifying rules — ACLs, security zones, and policy entries on routers, switches, and perimeter appliances — to let otherwise blocked traffic flow. Its tactic is Defense Impairment (formerly Defense Evasion). The sisters are T1686.001 Cloud Firewall and T1686.003 Windows Host Firewall; telling them apart still matters here.

At this tier the answers are no longer obvious. Scenarios give you 2–4 artefacts that must be read together: an approved change ticket that almost covers the change, a maintenance window that almost explains the traffic, a rollback script that almost fixes the rule set. Real attacker behaviour is woven in: the 2025 Poland Wiper Attacks modified FortiGate security settings over the native CLI and disabled network traffic logging, and Salt Typhoon altered firewall ACLs to add IP addresses that bypass security policies.

You will practise the tasks of a senior SOC analyst triaging an alert queue, a detection engineer validating DET0306 telemetry, an incident responder choosing the least destructive containment, a red teamer judging what the analytic can and cannot see, and a control owner mapping CIS 12.1/12.3/12.5 onto this technique. Some questions deliberately reward the least aggressive correct action; at least one correct answer is "this is benign — do not escalate it".

Keywords covered in this exam

Every idea below is exercised by at least one task in this file.

Alert triage & evidence

  • True-positive vs benign-approved vs different-technique dispositions
  • Change tickets vs observed windows; top-down firewall rule processing
  • Management-plane audit streams: console vs API channels, admin VLANs vs unknown IPs

Real-world procedures

  • 2025 Poland Wiper Attacks — FortiGate settings modified via native CLI; network traffic logging disabled
  • Salt Typhoon — ACL modifications adding IP addresses to bypass policies and maintain access

Detection engineering (DET0306 / AN0855)

  • Data components: configuration change logs, device authentication logs, traffic telemetry, CLI command audit
  • Correlation: change followed by blocked-to-allowed spikes; bulk deletions; failed-then-successful logins
  • Red-side view: which rule-change variants the analytic sees best — and which blend into normal work

Response & controls

  • Credential rotation before restoration; evidence-preserving config exports; fleet-wide session hunts
  • CIS 12.1 (patching), CIS 12.3 (IaC/GitOps configuration management), CIS 12.5 (device operator authentication)
  • Mitigations M1047, M1051, M1018 applied under pressure
