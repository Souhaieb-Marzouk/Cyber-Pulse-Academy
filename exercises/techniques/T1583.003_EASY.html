What you will learn here

You will learn about T1583.003 — Acquire Infrastructure: Virtual Private Server. Imagine you are a new analyst in a Security Operations Centre (SOC). Before an attacker ever touches a company, the attacker must prepare tools and places to work from. One common preparation step is to rent a Virtual Private Server (VPS) — a ready-made virtual machine in a provider's cloud. MITRE ATT&CK calls this behaviour a sub-technique: a specific child of the bigger technique T1583, "Acquire Infrastructure". It sits inside the Resource Development tactic, the phase where the adversary gathers what the attack needs.

Why does this matter in real work? A SOC analyst meets the result of this step when company machines quietly talk to a rented server. A cyber threat intelligence (CTI) analyst writes reports that name this behaviour when profiling groups — the ATT&CK page links it to real actors such as APT38, HAFNIUM and Gamaredon. An incident responder uses it to explain where stolen data or attacker commands travelled. A detection engineer reads the page's detection strategy (DET0838) to plan internet-scan hunting. A red teamer rents VPSs the same way to make exercises realistic. A GRC or risk analyst uses the mitigation note (M1056 Pre-compromise) to explain why this step cannot simply be blocked with one company control. You will see all of these roles in the exercises below, with plain words and small examples.
