What you will learn here

This exam trains T1686.002 — Network Device Firewall, a sub-technique of the MITRE ATT&CK technique T1686 — Disable or Modify System Firewall. A sub-technique is one specific version of a bigger behaviour. The bigger behaviour is "an attacker weakens a firewall". This sub-technique narrows it to firewalls that protect a whole network: routers, switches, and perimeter firewall appliances. Its sisters cover other places: T1686.001 is the cloud firewall, and T1686.003 is the firewall inside one Windows machine. The tactic it serves is Defense Impairment (this tactic was formerly called Defense Evasion) — the attacker's goal of weakening your protections.

Here the tasks grow one step harder than the beginner level. You will combine two facts to answer: for example, read a ticket and a config line, then decide which sub-technique you are looking at. You will meet the real actors behind this behaviour. APT38, a financially motivated group, created firewall exemptions on ports 443, 6443, 8443, and 9443. Salt Typhoon, a name used for Chinese state-sponsored activity, modified network firewall ACLs to add their own IP addresses. Cyclops Blink, malware seen on network devices, changed iptables to open its command and control ports. Grandoreiro, a banking malware, blocked a bank security tool at the firewall level.

In real work you will use this object as a SOC analyst triaging an alert queue, a detection engineer writing a rule for the analytic DET0306, a firewall administrator keeping rules clean, an incident responder restoring a trusted configuration, a threat hunter chasing odd management IPs, and a GRC analyst mapping controls such as centralised AAA. The deliverables you touch are detection rules, incident tickets, config backups, and short reports.

Keywords covered in this exam

Every idea below is exercised by at least one task in this file.

Real-world procedures

  • APT38 — firewall exemptions on ports 443, 6443, 8443, 9443
  • Salt Typhoon — added IP addresses to network firewall ACLs to bypass policies
  • Cyclops Blink — iptables changes on network devices to enable C2 on a stored port list
  • Grandoreiro — blocked a bank security tool at the firewall level

Sub-technique discrimination

  • T1686.002 (network devices) vs T1686.001 Cloud Firewall vs T1686.003 Windows Host Firewall
  • Platform: Network Devices; ACLs, security zones, and policy rules

Detection logic (DET0306 / AN0855)

  • Rule creation, modification, or deletion from an abnormal management IP
  • Non-console channels: remote CLI and API, versus the management console
  • Unexpected allow-all rules; a spike in previously blocked traffic after a change
  • Device authentication logs before the change; failed logins then success
  • Attack path order: reach the management interface → modify rules → use the opened path

Mitigations & response

  • M1051 Update Software (patch the appliance), M1047 Audit (review who may change rules), M1018 User Account Management (least-privilege accounts)
  • Preventive vs detective actions; restoring a trusted configuration; hunting changes made by the same admin session
