📘 About the ATT&CK object: Hardware Additions (T1200)

T1200 — Hardware Additions is a Technique in MITRE ATT&CK. A technique describes one behaviour an attacker can use; a tactic is the goal. T1200 belongs to Initial Access (TA0001) — getting the first foothold — and has no sub-techniques. The behaviour: an attacker physically introduces computer accessories, networking hardware, or other computing devices into a system or network, and that new hardware becomes the way in.

ATT&CK draws a useful border: this is more than just a USB stick carrying files. Payload delivery by removable media is its own technique, T1091 Replication Through Removable Media. T1200 is about hardware that adds a new capability: passive network tapping, network traffic modification (an Adversary-in-the-Middle, linked to T1557), keystroke injection, kernel memory reading via DMA, or a new wireless access point on the office network. Platforms: Linux, Windows, macOS.

The page is honest about evidence: public usage by threat actors is scarce, but red teams and penetration testers use hardware additions often. The one documented example is G0105 DarkVishnya: they physically connected a Bash Bunny, Raspberry Pi, netbooks and inexpensive laptops to the local networks of banks to reach the company LAN from inside.

Where you meet this at work: a SOC analyst triages device-arrival alerts (on Windows, Security event 6416 and Kernel-PnP; on Linux, udev/kernel hot-plug lines; on macOS, unified logs from IOUSBHost). A detection engineer joins those events with DHCP and new-MAC metadata into a chain. A NAC engineer implements M1035: 802.1x with device certificates, and DHCP only for registered devices. An endpoint engineer implements M1034: block unknown devices with a security agent. A CTI analyst profiles groups like DarkVishnya. A red teamer proves the gap legally. The risk: the device is already inside the perimeter, so internet-facing controls never see it.

In this MEDIUM exam every exercise combines two connected ideas — for example: read a log, then map it to the technique; pick a gap, then pick the control that closes it. The goal is stated, but you decide what to look at first.

  • Passive network tapping
  • Traffic modification (AitM)
  • Keystroke injection (HID)
  • Kernel memory reading via DMA
  • Rogue wireless access points

📡 Telemetry detail

  • Windows: Security 6416 · Kernel-PnP · Sysmon
  • Linux: udev / kernel hot-plug · syslog
  • macOS: unified logs (IOUSBHost)
  • DHCP leases & new MACs

🛡 Mitigations

  • M1034 — endpoint block + monitoring agent
  • M1035 — 802.1x, device certificates, DHCP registration

🏦 Real-world example

  • G0105 DarkVishnya — banks
  • Bash Bunny · Raspberry Pi · netbooks · laptops

📝 How this exam works

  • Goal: reach 70% or more to pass. Each exercise can give partial credit.
  • Exercise types: two-step questions, select-all questions, control mapping, a DHCP log review, a red-vs-blue decision walk-through, and one terminal task where you pick the options.
  • Partial credit (in plain words): exercises with more than one correct item score per item. Correct picks add credit, wrong picks subtract it. The formula is (right − wrong) ÷ total, never below zero. So a half-right answer still earns part of the point.
  • Check = free time: when you press Check, the timer stops by itself. You can read the feedback and the explanation for as long as you want. Nothing is lost. The timer starts again only when you press Next (or Final Submit on the last exercise).
  • Manual pause: the Pause button is for a real break. It stops the timer and hides the exercise until you press Resume.
  • Hint: one hint per exercise. A hint costs 10% of that exercise's credit (never below zero). It gives a nudge, not the answer.
  • Skip: every exercise has a Skip button. Skipping is free. Skipped exercises go to a review pool. Before you finish, you may return to them and answer them, as long as the timer is still running. A skipped exercise that stays unanswered does not count at all — it is not right, not wrong, and not in your total.
  • Retake: if you fail, you can retake the exam. Questions and answer positions are shuffled again.
