1What you will learn here

Hello! In this exam you will learn about T1647 — Plist File Modification, a Technique in the MITRE ATT&CK framework. A technique is one specific way an attacker does something. This technique lives in the Enterprise matrix and works only on macOS (Apple computers).

Imagine an app on a Mac. The app carries a small settings file called a plist (short for property list). The most famous one is Info.plist. It is a simple text (or binary) file full of key–value pairs, like LSUIElement = 1. macOS reads these pairs to decide how to treat the app: its name, its icon, and what extra things it loads.

An attacker who can edit a plist can quietly change how the Mac behaves: hide an app from the Dock, make an app run extra commands at start, or point a Dock icon to a malicious program. That is why this technique belongs to the Defense Impairment tactic (the tactic ATT&CK used to call Defense Evasion, TA0005): the edit helps the attacker stay hidden and can enable other tricks like persistence.

Here is where you will meet this object in real work: a SOC analyst triages macOS alerts about plist changes; an incident responder checks LaunchAgents and Info.plist files on a suspect Mac; a CTI analyst reports on macOS malware such as XCSSET and Cuckoo Stealer, which ATT&CK lists as using this technique; a detection engineer builds alerts from the DET0109 detection strategy; and app developers follow the M1013 guidance (Apple's Hardened Runtime) so their apps resist tampering. The risk is real: malware that hides in plain sight on Macs by editing small settings files.
