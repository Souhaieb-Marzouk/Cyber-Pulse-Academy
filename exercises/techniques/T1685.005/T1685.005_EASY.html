What you will learn here

Welcome! This exam teaches you T1685.005 — Clear Windows Event Logs. You will learn what this behaviour is, why attackers do it, and how you spot it.

First, the big picture. MITRE ATT&CK is a big catalogue of attacker behaviours. Each behaviour is called a technique. A sub-technique is a more specific version of a technique, like a sub-folder inside a folder. T1685.005 is a sub-technique of T1685 — Disable or Modify Tools. Its job in the catalogue is simple: it describes attackers wiping the event logs of a Windows computer to hide what they did.

Imagine you are a SOC analyst (a person who watches security alerts all day). Windows computers write down almost everything in event logs: who logged in, which programs ran, what failed. If an attacker deletes these notes, your view of the attack goes dark. This behaviour belongs to the ATT&CK tactic Defense Impairment (TA0112) — the phase where an attacker damages your ability to see and stop them.

In your daily work you will meet this object in many roles. A SOC analyst sees the alert The audit log was cleared and must judge it. An incident responder checks which evidence survived after logs were wiped. A threat-intel analyst reads reports that name groups using this trick — famous ransomware gangs and spy groups do it. A detection engineer builds alerts for it. A GRC or control owner makes sure logs are copied off the computer so a wipe cannot destroy them.

The tools you will practise here are small and real: the built-in Windows command wevtutil, the PowerShell command Clear-EventLog, the Event Viewer window, and the alert Event ID 1102. By the end you will read a short log, spot the wipe, and know the next simple step.
