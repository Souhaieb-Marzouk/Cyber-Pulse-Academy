🧭 What you will learn here

This is the second tier for T1222.002 — Linux and Mac Permissions, a sub-technique of T1222 in the MITRE ATT&CK catalogue. A sub-technique is the detailed child of a broader technique. While the EASY tier taught you to recognise the commands, this tier makes you connect two ideas at a time: read a log and judge it, recall a command and pick its flag, see an alert and weigh who caused it.

The behaviour itself stays the same: an attacker already on a Linux or macOS host changes file and directory permissions or attributes — with chmod, chown, chattr, chflags or ACL tools like setfacl — to reach protected files, make payloads executable, hide files, or lock defenders out. ATT&CK files this under Defense Impairment (TA0005), the tactic about blunting protections (once called Defense Evasion).

Where you will use this at work: a SOC analyst decides if a permission alert is an attack or a package manager doing its job. A detection engineer turns the ATT&CK detection strategy DET0351 (analytics AN0998 for Linux, AN0999 for macOS) into auditd watch rules and EDR analytics. A threat hunter looks for SUID bits and immutable flags. A GRC analyst owns the two ATT&CK mitigations — M1026 Privileged Account Management and M1022 Restrict File and Directory Permissions. An incident responder builds a timeline from permission changes. The false-positive side matters too: package managers and configuration tools change permissions all day, so context — file location, mode, parent process — decides what is real.

Take your time with the artefacts. Every explanation tells you why, in plain words.
