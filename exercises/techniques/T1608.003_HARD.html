What you will learn here

Welcome to the HARD file on T1608.003 — Install Digital Certificate, a Sub-Technique of T1608 Stage Capabilities in the Resource Development tactic (TA0042). A quick recap of the staging act itself: the adversary uploads an SSL/TLS certificate file to a server it controls — ATT&CK names web servers and email servers — and configures that server to use it. The host can now speak encrypted hxxps, and that feeds two goals: C2 traffic encrypted with Asymmetric Cryptography (T1573.002) over Web Protocols (T1071.001), and a credible padlock on phishing pages.

This file is about catching that act. The assigned detection strategy is DET0840 with analytic AN1972, and its data source is Internet Scan — external scanning of attacker-controlled infrastructure, not victim telemetry. That choice follows from a hard limitation: the install happens on the adversary's own servers, outside victim visibility, so no victim sensor sees it. ATT&CK's note is blunt — detection effort usually pivots to the downstream phases, above all the encrypted web C2 behavior the install enables.

Your best weapons are public. Certificate Transparency (CT) logs are public records of every certificate issued, and defenders watch them for lookalike domains of protected brands. Each row gives you pivot fields: the issuer (who verified and signed), the serial number (unique per issuance), and the SAN (the hostnames the certificate covers). Shared issuer and SAN patterns cluster sibling servers; JARM — a fingerprint of the TLS server stack — groups hosts built the same way; scan archives show a known certificate re-appearing on a new address.

Who works this daily? A CTI analyst pivots on certificate details and monitors CT feeds for fresh staging. A detection engineer maps the downstream observables the strategy points at. A threat hunter runs briefings like the Sea Turtle one in this file — that group captured legitimate certificates from victim organizations, installed them on its own infrastructure, and enabled adversary-in-the-middle operations. A SOC analyst triaging phishing asks one credibility question: does the lure carry a valid padlock, and how convincing is that to a victim?

HARD means every exercise correlates two or three ideas across artefacts, and every wrong option is wrong for a reason you can defend in one breath. Two traps are loaded: one case that looks alarming but is benign, and one where the least aggressive action is the correct one. The two terminal exercises name no tools — you bring the craft.
