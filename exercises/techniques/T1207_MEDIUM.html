What you will learn here

Welcome back! This exam goes one step deeper into T1207 — Rogue Domain Controller. In ATT&CK this object is a Technique: one specific attack method. At MEDIUM level, every exercise connects two ideas — for example, recognise the behaviour, then choose the right control.

Quick recap in plain words: a company's directory is Active Directory (AD). Domain controllers copy data between each other (replication). An attacker with Administrator-level rights — or the domain's most powerful key, the KRBTGT hash — can register a normal computer as a fake domain controller using DCShadow, then push crafted changes that arrive looking like normal replication. Its neighbour DCSync (T1558.003) does the opposite direction: it reads data out. T1207 is the write path. Knowing this difference is half of this exam.

The exercises mirror real work: SOC triage on a live alert, detection engineering on event 4928 and DRSUAPI network flows, a mini decision drill for IR, and control reasoning for GRC (the listed mitigation is M1037 — Filter Network Traffic, plus privileged access management).

The language is simple, but you must decide what to look at first. Wrong pieces subtract credit in multi-part exercises — answer exactly what is asked.
