ⓘ What you will learn here

▣ YOUR TRAINING GOAL

In this exam you go one step deeper into T1578.002 — Create Cloud Instance, the sub-technique of T1578 — Modify Cloud Compute Infrastructure that lives in the Defense Impairment tactic (formerly Defense Evasion). You already know the basics: an attacker with cloud credentials creates a fresh virtual machine to escape the rules and agents on the machines you already watch. Now you connect two ideas at a time: a log line plus the baseline it breaks, a creation event plus the response it needs, a permission over-grant plus the technique it enables.

That is exactly how the object is used at work. A SOC analyst reads a CloudTrail RunInstances event or an Azure virtualMachines/write event and asks: who, where, when, and does it break our baseline? A detection engineer tunes the ATT&CK detection strategy DET0449 (analytic AN1242): rarely used accounts, unusual geolocations, rapid snapshot-then-create sequences, unexpected policy changes — while allowlisting the Terraform pipeline and change-ticketed batches. A cloud engineer removes ec2:* style over-grants because least privilege (mitigation M1018) is what stops the creation in the first place. A red teamer runs the creation on purpose to prove the alerting works. And a CTI analyst can tell you that Scattered Spider and LAPSUS$ ran this exact play in real incidents. The risk stays the same: a rogue instance is a trusted, billable machine the attacker owns — inside your network.
