What you will learn here

In this exam you train one ATT&CK object: T1578.005 — Modify Cloud Compute Configurations, a sub-technique of T1578 — Modify Cloud Compute Infrastructure, in the Defense Impairment (TA0112) tactic, on IaaS platforms. Sub-technique means: the parent technique says "an attacker changes cloud compute things to hide", and T1578.005 is the specific version where the change touches account-wide settings instead of machines. The ATT&CK description names those settings: service quotas (usage ceilings), subscription associations (which billing container a workload sits in), tenant-wide policies (rules for the whole account, like Azure Policy or AWS service control policies), and the set of allowed regions.

Why does an attacker bother? Because these settings decide what is possible and what is visible. A quota increase means a mining fleet (ATT&CK calls the payoff Resource Hijacking, T1496) fits below the ceiling. An enabled unused region means work can move to a place with no eyes — ATT&CK tracks that follow-on behaviour as T1535, Unused/Unsupported Cloud Regions. A weakened policy removes guardrails. And because only settings change, running instances keep working — nothing crashes, nobody reboots, no host alarm fires. Microsoft Threat Intelligence publicly documented criminals doing exactly this for cryptojacking in 2023.

This object appears in many real work tasks. SOC analysts triage cloud alerts and need to know which API events carry these changes. Detection engineers build the analytic that ATT&CK documents for this technique: it watches for anomalous configuration changes and correlates identity + configuration + provisioning logs, with tuning fields like who made the change, the time window, the change type, and the geography. Cloud security engineers own the guardrails. GRC analysts check coverage of the two ATT&CK mitigations, M1018 User Account Management and M1047 Audit. In this exam you will read CloudTrail events, write detection keywords, and make triage calls across AWS, Azure, and Google Cloud.

Keywords covered in this exam

ATT&CK identity & chain

  • T1578.005 — Modify Cloud Compute Configurations
  • Parent: T1578 — Modify Cloud Compute Infrastructure
  • Tactic: Defense Impairment (TA0112) · Platform: IaaS
  • Payoff: T1496 Resource Hijacking
  • Follow-on: T1535 Unused/Unsupported Cloud Regions

Behaviours & settings

  • Service quota increase (compute ceiling lift)
  • Tenant-wide policy weakening (guardrail removal)
  • Region enablement (operate where nobody looks)
  • Subscription association change
  • Silent property: running instances untouched

Provider API actions

  • AWS: RequestServiceQuotaIncrease
  • Azure: Microsoft.Quota/quotas/write
  • Azure: Microsoft.Authorization/policyAssignments/write
  • Google Cloud: SetOrgPolicy

Data sources & correlation

  • AWS CloudTrail management events
  • Provisioning logs (RunInstances follow-on)
  • Identity + configuration + provisioning correlation
  • Cloud Service Modification data component

Detection logic & tuning

  • eventName matching in analytics
  • Change-then-use correlation window
  • Excluding known automation (UserContext)
  • Mutable elements: TimeWindow, ChangeType, GeoLocation
  • False positives: planned capacity work, migrations

Mitigations

  • M1018 User Account Management (preventive)
  • M1047 Audit (detective)
  • Approval workflows for quota and policy changes
