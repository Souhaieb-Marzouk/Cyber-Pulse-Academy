What you will learn here

This exam tests T1207 — Rogue Domain Controller the way an analyst meets it in real life: several artefacts at once, near-miss answers, and decisions where the obvious move is sometimes the wrong one. In ATT&CK this object is a Technique: one specific attack method.

What the technique really does: with Administrator rights (or the KRBTGT hash), the attacker registers a normal host as a fake domain controller with DCShadow — creating server and nTDSDSA objects in the AD Configuration partition — and pushes crafted changes that arrive as inbound replication. Because replicated changes have no originating-change record (event 5136), the technique can slip past change auditing and SIEM sensors. It is used for SID-History injection, group and ACL backdoors, and even tampering with replication metadata to confuse forensics.

You will work like the roles that own this problem: SOC triage across log + netflow + ticket artefacts, IR containment with the least aggressive effective action, detection engineering on events 4928/4929/5136 and the DRSUAPI UUID, and CTI mapping (Mimikatz S0002 — lsadump::dcshadow; documented real-world use in the SolarWinds Compromise, C0024).

Hints here only remove one wrong path — they never name the answer. Expect at least one exercise where the calm, boring option is the correct one.
