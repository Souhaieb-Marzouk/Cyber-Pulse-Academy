T1207 — HARD practice exam

ATT&CK object: T1207 — Rogue Domain Controller (Technique, Enterprise matrix, v20) Severity: HARD Exercises in this file: 15 Estimated time: 50 minutes · timer budget 50:00 Pass mark: 70%

What you will learn here

You will learn T1207 — Rogue Domain Controller, also known by its method name DCShadow. In MITRE ATT&CK, this is a Technique object. A technique describes one behaviour an adversary uses to reach a goal. This one lives in the Defense Impairment tactic (TA0112), which is the part of the matrix for behaviour whose purpose is to break security mechanisms so defenders cannot see or trust what is happening.

Imagine you are on a team that looks after a company network running Windows and Active Directory (AD). AD is the system that stores all user accounts and computers for the company. Real domain controllers (DCs) are the servers that copy that data to each other — this copying is called replication. In this technique, an attacker who already has administrator power registers a fake DC. The real DCs then believe the fake one, and the attacker can push changes into AD through normal replication. Those changes can be any object: accounts, permissions, even the schema.

In this HARD exam the scenarios are realistic and the wrong answers are almost right. You will separate DCShadow from its look-alikes (DCSync, Golden Ticket, planned DC promotion), tune the AN0770 analytic without drowning in false positives, and choose the least aggressive correct action when an alert fires. Artefacts come in sets — a log, a ticket, a config — and you must read them together.

You will see where this technique is used in real work. SOC analysts triage alerts about strange replication events. Threat hunters search for hosts that behave like DCs but are not. Incident responders investigate attacks that used this method and repair the damage. Threat-intelligence analysts write reports that name T1207 in attacker toolkits. Detection engineers build and tune the ATT&CK detection strategy DET0276 for it. Red teamers emulate it in labs to test whether the blue team catches it. GRC and control owners use it to justify tiered admin models. The tools you will meet are the Windows Security event log, event IDs like 4928, 4929 and 4662, the DRSUAPI RPC interface, SPN records, and the Mimikatz tool whose LSADUMP::DCShadow module is the procedure example ATT&CK lists for this technique.

The risk it addresses is severe: an attacker who succeeds can change AD data while bypassing SIEM logging, hide the change by tampering with replication metadata, and create backdoors that survive many cleanup attempts. That is why understanding this technique matters for every defender who works with Active Directory.
