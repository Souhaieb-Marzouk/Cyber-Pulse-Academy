🎓 What you will learn here

At HARD level you stop memorising T1574 — Hijack Execution Flow and start working it like a real shift. You will read logs against baselines, decide what a hijack actually gives the attacker, and choose the containment that fixes the problem without wrecking the business.

The exercises pull from the live T1574 page: the sub-technique family (DLL abuse, installer permissions, dynamic linker hijacking, service file/registry permissions, unquoted paths), the mitigation table (M1044, M1022, M1024, M1018, M1040, M1052, M1047, M1051, M1013), and the detection strategy DET0218 — especially the Linux analytic AN0610 (“modifications in /etc/ld.so.preload, service config changes, or file writes replacing existing executables”) and the macOS analytic AN0611.

You will also meet the real procedure examples the page lists: Denis replacing a nonexistent msfte.dll, DarkGate abusing the mscfile registry key, ShimRat hijacking cryptbase.dll inside migwiz.exe, and campaign C0017 where APT41 loaded malicious libraries through Import Address Table modifications in legitimate Microsoft binaries.

Expect near-miss answers: two options that look defensible, one that survives. Expect one rule above all: the correct action is often the least aggressive one that still stops the abuse.
