📘 About the ATT&CK object: Hardware Additions (T1200)

T1200 — Hardware Additions is a Technique in the MITRE ATT&CK framework. ATT&CK is a public catalogue that describes how real attackers work. A technique describes one behaviour an attacker can use. A tactic is the goal — the “why”. This technique belongs to the Initial Access tactic. That is the goal of getting the first foothold inside a company. T1200 has no sub-techniques.

What does Hardware Additions mean? Imagine an attacker walks into an office. They plug a small hardware device into a free USB port or a free network socket. The device is not a normal mouse or printer. It is built to help the attacker. Examples from the ATT&CK page: a device that pretends to be a keyboard and types commands by itself; a passive tap that quietly copies network traffic; a box that edits network traffic (an Adversary-in-the-Middle); a card that reads the memory of a computer through a fast port (DMA); a new Wi-Fi access point added to the office network. The attacker does not need to phish anyone. The device does the work. ATT&CK also lists the platforms Linux, Windows and macOS.

One honest detail from the page: few threat groups are publicly documented using this technique, but many red teams and penetration testers use it. The page gives one real example: the group DarkVishnya (G0105) physically connected a Bash Bunny, Raspberry Pi, netbooks and cheap laptops to the local networks of banks.

Where is this used in real work? SOC analysts see device-arrival alerts and decide if a device is known. Asset teams keep the hardware inventory true. Detection engineers build the chain analytic that ATT&CK calls DET0069. Network and NAC engineers run 802.1x, device certificates and DHCP registration (mitigation M1035). Endpoint teams block unknown devices (mitigation M1034). Red teamers use such devices in legal tests. Incident responders handle real cases. GRC analysts write the rules. The risk is simple: one small box behind the firewall can undo years of good perimeter security.

In this EASY exam you will learn the foundations: what the technique is, which tactic it belongs to, what these devices look like, what they leave in logs, and the two named mitigations. Every exercise guides you and tests one simple idea.

📝 How this exam works

  • Goal: reach 70% or more to pass. Each exercise can give partial credit.
  • Exercise types: single-choice questions, gap-fill, matching and sorting cards, a small alert drill, a decision walk-through, and one guided terminal task.
  • Partial credit (in plain words): exercises with more than one correct item score per item. Correct picks add credit, wrong picks subtract it. The formula is (right − wrong) ÷ total, never below zero. So a half-right answer still earns part of the point.
  • Check = free time: when you press Check, the timer stops by itself. You can read the feedback and the explanation for as long as you want. Nothing is lost. The timer starts again only when you press Next (or Final Submit on the last exercise).
  • Manual pause: the Pause button is for a real break. It stops the timer and hides the exercise until you press Resume.
  • Hint: one hint per exercise. A hint costs 10% of that exercise's credit (never below zero). It gives a nudge, not the answer.
  • Skip: every exercise has a Skip button. Skipping is free. Skipped exercises go to a review pool. Before you finish, you may return to them and answer them, as long as the timer is still running. A skipped exercise that stays unanswered does not count at all — it is not right, not wrong, and not in your total.
  • Retake: if you fail, you can retake the exam. Questions and answer positions are shuffled again.
