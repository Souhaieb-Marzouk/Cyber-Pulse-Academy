📘 About the ATT&CK object: Hardware Additions (T1200)

T1200 — Hardware Additions is a Technique in MITRE ATT&CK under Initial Access (TA0001): an adversary physically introduces computer accessories, networking hardware, or other computing devices into a system or network, and that hardware becomes the way to gain access. It has no sub-techniques; platforms are Linux, Windows and macOS. It is deliberately broader than removable-media payload delivery (T1091): the description names passive network tapping, traffic modification (AitM, T1557), keystroke injection, kernel memory reading via DMA, and new wireless access points. Public threat-actor usage is scarce; G0105 DarkVishnya is the documented example — Bash Bunny, Raspberry Pi, netbooks and cheap laptops connected to bank LANs.

The expert level lives in DET0069, the ATT&CK detection strategy for this technique, and its three platform chains. AN0185 (Windows): new external device (USB/Thunderbolt/PCIe) or new block device → within a short window, same user/session spawns a process or the OS mounts a volume → optional follow-on such as HID keystroke injection, DMA driver load, or a new network interface MAC on DHCP, correlated across Security event 6416 / Kernel-PnP, Sysmon and DHCP/network metadata. AN0186 (Linux): udev/kernel hot-plug → block device via udisks/diskarbitration → optional new interface or DHCP lease, correlated with syslog, auditd SYSCALL open/creat on /dev, and DHCP/Zeek. AN0187 (macOS): unified logs (IOUSBHost, IOThunderbolt) report device arrival → diskarbitrationd attaches a volume → optional config profile manipulation or a new interface MAC obtaining a lease, correlated with FSEvents and DHCP/Zeek. Mitigations: M1034 (endpoint block + monitoring agent) and M1035 (NAC: device certificates, 802.1x, DHCP restricted to registered devices).

At senior level this object touches the whole operation: a detection engineer tunes chains and allowlists without blinding the SOC; a SOC lead designs triage rules (and learns why blind auto-close is dangerous); an IR lead preserves volatile evidence before containment and writes notes that survive legal scrutiny; a CTI analyst frames attribution with honest confidence; a CISO decides which control to fund first and accepts the business cost. The traps are real: benign docks and demo gear generate the same arrival events; asset databases lag reality; the fastest containment sometimes destroys evidence; and the popular “best practice” answer can be wrong for a specific site.

In this EXTREMELY HARD exam you will chain three or more ideas, resolve conflicting signals, work around missing information, accept real costs, and sometimes decide that the right move is to gather more evidence or escalate — not to act.

📝 How this exam works

  • Goal: reach 70% or more to pass. Each exercise can give partial credit.
  • Exercise types: long incident chains, conflicting-evidence reviews, a triage queue, evidence-ordering under pressure, attribution calls, and one terminal task about safe evidence capture.
  • Partial credit (in plain words): exercises with more than one correct item score per item. Correct picks add credit, wrong picks subtract it. The formula is (right − wrong) ÷ total, never below zero. So a half-right answer still earns part of the point.
  • Check = free time: when you press Check, the timer stops by itself. You can read the feedback and the explanation for as long as you want. Nothing is lost. The timer starts again only when you press Next (or Final Submit on the last exercise).
  • Manual pause: the Pause button is for a real break. It stops the timer and hides the exercise until you press Resume.
  • Hint: one hint per exercise. A hint costs 10% of that exercise's credit (never below zero). It gives a nudge, not the answer.
  • Skip: every exercise has a Skip button. Skipping is free. Skipped exercises go to a review pool. Before you finish, you may return to them and answer them, as long as the timer is still running. A skipped exercise that stays unanswered does not count at all — it is not right, not wrong, and not in your total.
  • Retake: if you fail, you can retake the exam. Questions and answer positions are shuffled again.
