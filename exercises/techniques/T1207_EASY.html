What you will learn here

Welcome! This practice exam teaches you one MITRE ATT&CK technique: T1207 — Rogue Domain Controller. MITRE ATT&CK is a free, public catalogue that describes the moves real attackers use. Each move is called a technique, and T1207 is one of them. In ATT&CK language this object is a Technique: it describes one specific attack method — making a normal computer pretend to be a domain controller.

Imagine a company's address book for computers and people. That is Active Directory (AD). Special servers called domain controllers keep this directory in sync by copying data between each other; the copying is called replication. An attacker with powerful account rights can register a normal computer as a fake domain controller, using a method called DCShadow. The fake controller then pushes crafted changes into the directory, and the changes arrive looking like normal replication. They can give the attacker more access, create hidden ways back in, or help them reach credential data. That is why ATT&CK files T1207 under the Credential Access tactic.

You will see where this knowledge is used in real jobs: SOC analysts triage alerts about new domain controllers; threat hunters turn this technique into hunt ideas; incident responders contain fake controllers; CTI analysts describe it in reports; detection engineers write SIEM rules for it; red teamers test defences with it; and GRC and control owners limit who may create domain controllers. The tools around it are simple to name: SIEM, EDR, Windows event logs, and network monitoring.
