🎓 What you will learn here

You will learn what the MITRE ATT&CK sub-technique T1574.004 — Dylib Hijacking is and how attackers use it on Mac computers.

Mac programs do not contain all of their code either. They load ready-made code files called dylibs (dynamic libraries — the macOS version of the shared library files Windows calls DLLs) when they start or need a feature. Dylib Hijacking is the trick of putting a fake dylib with the expected name into a folder the program searches when it starts. The macOS dynamic loader checks those folders in order, finds the attacker's file first, and loads it into the trusted program.

T1574.004 is a sub-technique of T1574 (Hijack Execution Flow) and works on macOS only. ATT&CK maps it to the Execution and Stealth tactics.

Why does this matter in real work? A SOC analyst triages Mac alerts where a signed app loaded a dylib it never loaded before. A threat hunter checks which apps look for missing libraries. An incident responder on a Mac captures the loaded-dylib evidence before cleaning anything. A CTI analyst names T1574.004 in reports when the evidence shows a planted dylib. A detection engineer turns the page's detection strategy (DET0152, analytic AN0435) into rules. A control owner sets folder permissions so attackers cannot write into the folders programs search. The risk: malware that runs inside a trusted Mac app, comes back at every start, inherits the app's rights, and hides from security products.
