How this exam works

  • Three blocks per exercise: the SCENARIO (setup only), the QUESTION, and the ANSWER area. Read them in that order.
  • Check validates your answer, marks each part green / red / amber, shows the explanation, and automatically pauses the timer in review mode — the exercise stays visible so you can study it.
  • Review-mode pause ends only with Next. Editing answers or checking again does not restart the clock.
  • Pause (manual) hides the exercise while it is active. The two pause types are independent and can stack.
  • Skip moves you on and marks the exercise amber. Skipped exercises are excluded from scoring entirely. You can come back to them any time before the timer ends.
  • Partial credit: multi-answer exercises score per element. Get 3 of 4 slots right and you keep 3/4 of the points; wrong picks earn nothing but cost nothing.
  • Revise reopens a checked exercise. Every new Check pauses the timer again.
  • Hint (−10%): one nudge per exercise, costs 10% of that exercise's points.
  • Timer end or Submit closes the exam. Answers you never Checked earn nothing — always press Check.

Keywords covered

Every keyword below is exercised in this file. Themes: CR&A request & approval S&I scheduling & implementation T&R tracking & records G&P governance & pitfalls

CR&A — Change request & approval

Request for Change (RFC) · change requester / owner · business justification · impact analysis · risk analysis & risk level · change types: standard / normal / emergency · Change Advisory Board (CAB) · emergency CAB (ECAB) · approval workflow & approvers · priority vs urgency · separation of duties

S&I — Scheduling & implementation

change window / maintenance window · freeze & blackout periods · stakeholder notification · implementation plan · sandbox / test lab · pilot deployment · user acceptance testing (UAT) · rollback / backout plan · post-change verification & validation · downtime & SLA commitments

T&R — Tracking & records

change ticket & ticket ID · status lifecycle (submitted → in review → approved → scheduled → in progress → completed → closed / failed / rolled back) · change log & change record · audit trail · version control & revision history · configuration baseline · CMDB · asset inventory · configuration backup & archive · documentation updates (diagrams, SOPs)

G&P — Governance & pitfalls

unauthorized / shadow change · scope creep · post-implementation review (PIR) · emergency change process & retroactive documentation · standard (pre-approved) changes · audit & compliance evidence · change metrics (success / failure / rollback rate) · freeze violations
