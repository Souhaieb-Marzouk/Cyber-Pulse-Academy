How this exam works

  • Exercise types: scenario simulations, drag-and-drop matching, log/alert analysis, terminal emulator, fill-in-the-blank, spot-the-mistake, prioritization, ordering, dual-perspective, and a few multiple-choice questions.
  • Check button: validates your answer, locks it for scoring, and pauses the timer so you can study the explanation. The timer resumes only when you press Next.
  • Skip button: moves on without answering. Skipped exercises are excluded from scoring. You can return to them later, as long as the timer has not ended.
  • Manual pause: the Pause button in the top bar hides (blurs) the exercise so you cannot read it while paused. Manual pause and Check-pause stack — the timer resumes only when both are cleared.
  • Partial credit: multi-answer exercises (multi-select, drag-and-drop, matching, ordering, fill-in-the-blank) are scored per correct element. Single-answer exercises (single-choice QCM, single terminal command) are all-or-nothing.
  • Hints: each hint costs −10% of that exercise's points. Hints reveal a nudge, not the answer.
  • Navigation: use the question-number row to jump between exercises. Colours show state: cyan = current, green = correct, amber = partial, red = wrong, amber outline = skipped.
  • Retake: when you finish, you can retake the exam. Questions and answer choices are reshuffled each time.
