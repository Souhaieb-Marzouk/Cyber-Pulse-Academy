How this exam works

  • Realistic scenarios. You triage tickets, read logs, build commands and fix configs — like real cloud network work, not a school quiz.
  • Exercise types. Multiple choice (limited), multi-select, drag & drop, matching, ordering / prioritising, fill-in-the-blank, an interactive terminal, a log viewer with a filter box, spot-the-mistake config reviews and branching incidents.
  • Check. Press Check to validate. Each element is marked: ✓ correct, ✗ wrong, ⚠ partial / missed. Checking also pauses the timer in review mode: content stays visible so you can study the feedback. The timer resumes only when you press Next.
  • Skip. Skip jumps to the next exercise and flags this one as skipped (amber marker). Skipped exercises are excluded from scoring entirely — from both your points and the maximum. You can go back to a skipped exercise (until time ends) and finish it; it then counts again.
  • Two different pauses. The Pause button hides the exercise while paused (no studying). The Check-pause keeps everything visible. They stack: the timer runs again only when the manual pause is off and you pressed Next.
  • Partial credit. Multi-answer exercises score per correct element. Wrong picks earn nothing but do not subtract. Single-answer exercises are all-or-nothing.
  • Hints. A hint costs −10% of that exercise's points (max 2 per exercise) and gives a nudge, never the answer.
  • Passing score: 70%. Score is computed over non-skipped exercises only, with partial points included.
  • Press Check on every exercise you answer. An answer you never checked counts as zero if time runs out.
