How this exam works
  • Exercise types — SOC alert triage, decision-point scenarios, drag & drop, matching, ordering / priority ranking, fill-in-the-blank, policy drafting, spot-the-bug in configs, interactive log viewer with a filter box, a fake shell terminal, plus a few classic multiple-choice items (never more than five).
  • Check — validates your answer, marks every element green (correct) or red (wrong), shows points and an explanation, and locks the answer for scoring. Use Revise to unlock and edit; a new Check re-locks it.
  • Two different pauses — the Pause button freezes the clock but blurs the exercise. After pressing Check, the clock also freezes ("review mode") but everything stays visible so you can study the feedback. Review mode only ends when you press Next. Both pauses can stack.
  • Skip — skips an exercise and flags it amber. You can come back to skipped or answered exercises any time before time runs out. Skipped exercises are excluded from scoring (not counted in points or total). Submitting with everything skipped is blocked.
  • Partial credit — multi-answer exercises score per element: each correct element earns its share, wrong picks earn nothing but never subtract. Single-answer exercises are all-or-nothing.
  • Hint — one hint per exercise, costs 10% of that exercise's points. It nudges; it never tells the answer.
  • Results & retake — final screen shows total, per-exercise report with explanations (including for skipped ones), and a Retake button that reshuffles everything.
  • All indicators are defanged (hxxp, 10[.]0[.]0[.]1) — a real analyst habit that keeps logs inert. Keyboard-friendly: every control is a real button.
