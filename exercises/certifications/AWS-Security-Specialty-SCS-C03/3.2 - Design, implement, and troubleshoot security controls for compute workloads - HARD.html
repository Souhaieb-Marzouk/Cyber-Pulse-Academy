3.2 — Design, implement, and troubleshoot security controls for compute workloads (HARD)

About this HARD practice exam

  • Scope: the same objective as the MEDIUM exam — hardened AMIs and images (EC2 Image Builder, Systems Manager), instance profiles and compute roles, Amazon Inspector and GuardDuty for compute, Patch Manager with continuous validation, secure administrative access (Session Manager, EC2 Instance Connect), pipeline security scanning (Amazon Q Developer, Amazon CodeGuru Security), and GenAI protections (OWASP Top 10 for LLM Applications, Bedrock Guardrails) — tested from harder angles.
  • Severity: every exercise is HARD. Expect subtle distractors, near-miss answers, several artefacts per scenario (ticket + log + config), cases where the obvious answer is wrong, and judgment calls an experienced analyst must make.
  • Size: 30 exercises · 35-minute timer · passing score 70%.
  • Exercise types: multi-artefact investigations, ambiguous alert triage, decision workflows, trust-policy and recipe bug hunts, priority ranking under constraints, log analysis with a filter box, orderings, matchings, multi-selects, four single-choice questions, and two goal-only terminal tasks — the tool is not named, you must choose it.

How answering works

  • Check validates your answer, shows green/red/amber marks with explanations, locks the answer for scoring, and pauses the timer in review mode. The exercise stays fully visible. Only pressing Next resumes the clock.
  • Manual Pause (top bar) hides and blurs the exercise while the clock is stopped. The two pauses stack; both must clear for time to run.
  • Skip moves on without scoring the exercise (amber marker). You can return to skipped exercises any time before the timer ends and finish them.
  • Partial credit: multi-answer exercises score per element. Wrong extra picks earn nothing but do not subtract. Skipped exercises are excluded from both your earned points and the total.
  • Hint: one hint per exercise reveals a nudge for −10% of that exercise's points.
  • Revise unlocks a checked answer; checking again re-locks it (the timer stays paused until you press Next).
