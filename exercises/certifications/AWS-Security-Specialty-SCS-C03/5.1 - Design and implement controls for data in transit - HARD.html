5.1 — Design and implement controls for data in transit

How this exam works

  • This is a HARD severity, certification-style practice exam on enforcing encryption in transit, secure and private access, and inter-resource encryption. Every exercise is built from real SOC / cloud-engineer work.
  • Each exercise shows three labelled blocks: SCENARIO (the setup), DATA (logs, configs, tickets when present) and QUESTION (exactly what to do). You answer inside the ANSWERS block.
  • Exercise types: multiple choice, multi-select, matching, ordering, ranking, drag-and-drop groups, fill-the-blanks, typed input, log analysis with a filter box, a fake terminal, decision paths, alert triage, spot-the-faulty-line and blue/red dual-view items.
  • Check grades the exercise, locks the answer, reveals per-element marks and an explanation, and pauses the timer in review mode. The clock stays paused until you press Next — the content stays fully visible so you can study it.
  • Pause (top bar) is a separate manual pause: it hides and blurs the exercise. Resume with the same button. Both pauses can stack.
  • Skip jumps to the next exercise and marks it amber. You can return to skipped exercises until time ends. Skipped exercises are excluded from scoring (they earn nothing and cost nothing).
  • Partial credit: multi-answer exercises are scored per correct element. Wrong picks never subtract points — they just earn nothing.
  • Hint reveals a nudge (never the answer) and costs −10% of that exercise's points. Revise reopens a checked exercise; press Check again to re-score.
  • If the timer ends, the exam submits itself. Untouched exercises are then excluded from scoring.
You must answer at least one exercise before submitting — an exam with only skipped exercises cannot be scored.
