Chapter practice exam · HARD severity · 32 exercises · 55 minute timer · pass mark 70% · build v3.0

How this exam works

  • Goal: master the 5.2 skills — encryption at rest (KMS, CloudHSM, the SSE family), data integrity (Object Lock, Vault Lock, versioning, checksums, code signing), lifecycle & retention, and secure replication & backup.
  • Check: answer an exercise, then press Check. You get inline marks (green = right, red = wrong, amber = missed), the explanation, and a review pause — the clock is frozen while you read.
  • Two different pauses: the Check review pause keeps everything visible and resumes only when you press Next. The Pause button hides the exercise while the clock is stopped; resume it with the same button. The two pauses stack.
  • Skip: press Skip to move on. Skipped exercises turn amber in the navigator and are excluded from the score. You can return to any exercise via the numbered chips until the timer ends or you press Finish.
  • Partial credit: multi-answer exercises give one point per correct element. A wrong pick earns nothing but subtracts nothing. Single-answer exercises are all-or-nothing.
  • Hint: one per exercise. It costs 10% of that exercise's points and gives a nudge, never the answer.
  • Result: 70% over the answered exercises passes. A fail shows a Retake button; retakes reshuffle questions and answers.
