AWS Security Specialty — 6.3 Evaluate the compliance of AWS resources — MEDIUM practice exam

MEDIUM severity Pass mark: 70% Timer: 60 min 30 exercises

You are taking a certification-style practice exam on 6.3 — Evaluate the compliance of AWS resources (AWS Config and remediation, Security Hub, Audit Manager and Artifact, the Well-Architected review, and multi-account governance). Every exercise is built from real compliance work: read the scenario, study the evidence, and answer.

How this exam works

  • Exercise types: single-choice and multi-select questions, drag-and-drop, matching, ordering, prioritization, fill-in-the-blank, terminal commands, log review, branching scenarios, and “spot the mistake”.
  • Check answer grades the current exercise, shows green/red/amber marks per element and a full explanation, and pauses the timer in review mode — content stays visible so you can study it. The timer resumes only when you press Next (or navigate away).
  • Partial credit: multi-answer exercises split their points across the correct elements. Each correct element earns its share; a wrong pick earns nothing and never subtracts. Skipped and unanswered exercises are excluded from both score and total.
  • Hint (−10%): up to two hints per exercise, each costs 10% of that exercise’s points. A hint nudges you — it never reveals the answer and never pauses the timer.
  • Skip / return: skipped exercises are marked in the navigator and can be reopened any time while the timer runs. Answer them and they count normally again.
  • Manual pause hides the exercise content (so it cannot be studied) and freezes the timer until you resume. The two pause reasons can stack; the timer runs only when neither is active.
  • Revise flags an exercise with a ▲ marker in the navigator so you can find it again quickly.
  • Reach the pass mark for a certificate-style result; otherwise study the report and Retake — questions and choices are reshuffled on every attempt.
