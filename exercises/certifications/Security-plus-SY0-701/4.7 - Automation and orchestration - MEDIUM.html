4.7 - Automation and orchestration

Certificate: CompTIA Security+ (SY0-701) · Chapter 4.7: Explain the importance of automation and orchestration related to secure operations.

This file: MEDIUM severity · 30 realistic exercises · 1 point each · time limit 45 minutes (about 90 seconds per exercise) · passing score 70%.

Every exercise mirrors real work: SOC shifts, SOAR playbooks, cloud consoles, audit logs, config files and a simulated terminal. You will triage alerts, build workflows, spot bad automation code, rank risks and make judgment calls.

How this exam works

  • Check validates your answer, marks each element green (correct), red (wrong) or amber (partially correct / missed), locks the answer for scoring, shows the explanation — and pauses the timer in review mode. The content stays fully visible so you can learn. The timer resumes only when you press Next.
  • Pause (manual) is different: it hides the exercise behind an overlay while the clock is stopped, so you cannot study while paused.
  • Revise unlocks a checked exercise. Press Check again to re-score; each new Check pauses the timer again.
  • Skip jumps to the next exercise and marks it in the navigator (dashed amber). Before submitting — while time remains — you can return to any skipped exercise and finish it. Skipped exercises are excluded from scoring (neither earned nor possible points).
  • Partial credit: multi-answer exercises award a share of the point per correct element. One hint per exercise reveals a nudge and costs 10% of that exercise’s points.
  • Submitting with answers selected but never checked grades them automatically. If all exercises are skipped, the exam cannot be submitted.
  • Exercise order and answer order are shuffled on every attempt, including retakes.

Exercise types you will meet

Single & multiple choice, drag-and-drop sorting into slots and categories, timeline ordering and risk ranking, matching pairs, fill-in-the-blank policy/config drafting, a log viewer with a live filter, a simulated terminal where you type real commands, branching incident decisions, spot-the-mistake code review, and dual blue-team / red-team perspectives.
