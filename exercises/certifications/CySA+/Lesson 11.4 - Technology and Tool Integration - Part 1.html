🛡️ Certification Exam v2.0 — Security Platform Integration & SOC Automation

Scenario-based certification. Every exercise copies real work in a Security Operations Center, an incident response team, a GRC desk, or a cloud engineering team.

Exam rules

  • Pass score: 80% of the total points.
  • Exercises: 23 dynamic tasks. Some give partial points.
  • Timer: --, computed from the number and the difficulty of the exercises.
  • Pause: allowed. While paused, the question is hidden so you cannot read it.
  • Navigation: you may go back, but every answered question is locked.
  • Hints: each hint shows a nudge, never the answer, and costs 10% of that question's points.
  • Feedback: after each answer you see a plain-English explanation.
  • Retake: questions and answer choices are shuffled again.

Exercise types

  • Branching SOC scenario simulations (your choice changes the story)
  • Drag & drop: platforms, controls, indicators
  • Drag to reorder: timelining, ranking
  • Log viewer with a filter box (Kibana/Splunk style)
  • Click-to-match: tools, APIs, HTTP errors, metrics
  • Fill-in-the-blank: playbook, policy, report drafting
  • "Spot the mistake" in a live integration config
  • Terminal emulator: type the real command
  • Dual perspective: blue team detect / red team evade
⚠ All indicators of compromise are defanged

IPs appear as 203[.]0[.]113[.]9, URLs as hxxp://evil[.]example, and domains as cdn-update[.]example. This is a professional habit: it stops the material from pointing at live infrastructure.
