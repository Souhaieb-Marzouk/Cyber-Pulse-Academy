How to read this page

Each row in the table is one topic and the batches reserved for it: four tiers for a keyword, technique, mitigation or tactic, and a MEDIUM and HARD pair for each chapter of a certification. Colour is never the only signal: every row carries a symbol and a word as well, and the same four states are written out beside each swatch below.

  • no batches reserved — documentation only
  • reserved, nothing published yet
  • partly published
  • every reserved batch published
  • ✓ published — the batch file exists and the topic page links to it, so it opens and scores like any other.
  • ◐ partly published — some of the topic's batches are finished. The count beside it says exactly how many of how many.
  • ○ reserved, not started — the topic reserves its batches and none has been written yet. The topic page says so plainly rather than opening an empty frame.
  • — no batches reserved — the topic is documented reference material with no exercise slots at all. Every topic in this state is listed here rather than hidden, because the gap is the honest part of the roadmap.

The two figures in the batches column are published and reserved: 2 / 4 means two of that topic's four reserved batches can be started today. A topic with more batches is not better than one with fewer — a certification with fourteen chapters legitimately has more, and the percentage on the coverage cards above is what makes the catalogs comparable.

Why this dashboard cannot drift from the data

The manifest behind this page is regenerated by the project's build tooling from the topic files themselves, and the table is recomputed from that manifest every time the page loads. No count is typed into the HTML, so publishing a batch cannot be forgotten here and a missing batch cannot be hidden. A new batch moves these figures on the next build without anyone touching this page.
