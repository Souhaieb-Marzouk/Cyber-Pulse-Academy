Statistics

CyberPulseAcademy counts how its exercise batches are used, and it counts them the smallest way it can. The site ships in local mode by default, which means the numbers on this page are read from this browser's own storage. On a fresh deployment, and on any deployment that has not been switched over, they describe only your own device and nobody else's results.

Remote mode is opt-in by the site owner, and when it is switched on the username is hashed on this device before anything is sent: the raw name never leaves the page. What an endpoint receives is a truncated hash, a country code, a topic id, a batch number and a score. The owner can also switch collection off entirely, in which case nothing is recorded anywhere, including in your browser.

Recorded activity

Local mode: this browser is the whole database

This deployment ships with statistics set to local, so every figure below comes from this device's own storage and nowhere else. Nothing is posted, nothing is shared, and no other visitor is counted in it. The owner can switch the site to remote mode, which reports anonymous aggregates to an endpoint the owner operates, or turn collection off completely.

In local mode the figures above are yours alone. The exact list of what is stored, and for how long, is set out below.

What is collected, exactly

Five things, all of them listed here. Nothing else is written to your device, and nothing else is ever sent, in any mode.

username Kept only in your browser, to label your own results and your own attempt history. It is never used to identify you to anyone else. localStorage, key cm.identity.v1 Until you delete it, with the Delete my data button or your browser's own site-data controls.
country (a two-letter code) Anonymous aggregate grouping, so the public statistics can show how many countries take part without naming a single person. localStorage, key cm.identity.v1, and optionally the owner's endpoint in remote mode Until you delete it.
per-exercise score and pass/fail So you can see your own progress, and so the public statistics can show pass rates per exercise batch instead of vague totals. localStorage, key cm.attempts.v1 The last 500 attempts. Older records are dropped as new ones arrive, which keeps the store far inside the browser quota.

What is never collected

  • No email address, at any point, in any mode. There is no account and no sign-up.
  • No IP address stored by CyberPulseAcademy. The host that serves these pages sees the request needed to deliver them, as every web server does; that log belongs to the host, not to this project, and it is not used for these statistics.
  • No device fingerprint, no canvas or font fingerprint, no hardware identifier.
  • No advertising identifier, no advertising network, and no adverts on any page.
  • No third-party cookie. The site sets no cookies at all, and no consent pop-up is needed because nothing is shared with anyone.
  • No cross-site tracking, no tracking pixel, no embedded analytics product, no CDN and no external script of any kind.
  • No raw username ever transmitted in remote mode. The hash is truncated to 16 hex characters and is used only to count distinct visitors.

Your controls

Two buttons in the footer of every page are the complete control panel. Neither is buried in a settings menu, and neither requires an account.

  1. Edit identity opens the identity dialog and lets you set, change or clear the name and country kept in this browser. Clearing the name stops it labelling your results; nothing else on the site changes, and reading is never gated behind it.
  2. Delete my data asks for confirmation, then removes every cm.* key this site owns: your name, country, theme choice, consent record and every recorded attempt. It is immediate, it cannot be undone, and it happens only in this browser.

In local mode those two buttons are a complete deletion, because the data never left the device in the first place. In remote mode the counters are anonymous aggregates that cannot be traced back to your device, so there is nothing there to delete by name. If your browser blocks local storage, the site shows a notice, keeps working for the session, and saves nothing at all.
