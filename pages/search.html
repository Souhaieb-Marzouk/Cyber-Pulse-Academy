Search

One search box over all 2014 topics: keywords, certifications, ATT&CK tactics, techniques, mitigations, detection strategies and threat groups. The search reads the same catalog manifest the listing pages are built from and ranks the matches in your browser, so it is instant after the first load, there is no search server, and no query is sent anywhere.

Matches are ranked by which field they hit, not by popularity. An ATT&CK identifier such as T1059 or a topic id ranks above a tag, which ranks above a match buried in an objective or a summary, so the thing you typed is near the top instead of the thing that merely mentions it.

How to search

Four kinds of query are understood, and they combine. Leave the box empty and the page becomes a browse list instead of a search.

Query syntax understood by the search box, with an example of each
What you type What it does Example
Free text Every word must match something, and results are ranked by which field matched: ATT&CK id, then topic id, then title, tags, theme, objectives and summary. More words means fewer, sharper results. kerberos
"Quoted phrases" The words must appear together in that order. A phrase found in a title outranks the same phrase found in a summary, and a phrase that matches nothing removes the whole result. "process injection"
type: Restricts the search to one catalog. The seven values are keyword, certification, tactic, technique, mitigation, detection and group. type:technique
theme: Restricts the search to one theme. A trailing asterisk is accepted and treated as a prefix match, so you can type the start of a theme name. theme:crypto
  • Combine them in one line. For example type:mitigation mfa finds the mitigations that mention multi-factor authentication, and type:technique theme:cloud "valid accounts" narrows to cloud-themed technique topics that use that phrase.
  • Press / anywhere on this page to move focus straight into the search field and select whatever is in it. Press Tab to leave the field and carry on through the page, or Escape to dismiss the browser's own suggestions.
  • Results explain themselves. Matched terms are highlighted in each result, the count is announced politely as it changes, and the query is written into the page address, so a search you want to keep can be bookmarked or shared as a link.
  • The catalog selector is per-catalog, not a filter. Choosing one catalog narrows the pool before ranking; typing type: in the box does the same thing and keeps the selector free for a second pass.
