Simple definition

OSED is a practical certification from OffSec about finding and exploiting bugs in compiled Windows programs. It focuses on exploit development, which means turning a software crash into working code that takes control of a program. The exam is hands-on: you analyse a real application and write an exploit yourself. OffSec calls the credential the Exploit Developer certification.

Why should you care?

This certification proves you can do difficult work that few people can do. An employer sees that you understand memory, assembly language, and debugging, not just tools. It opens doors to vulnerability research and exploit development roles. It also makes you a stronger penetration tester, because you learn how bugs really work. The exam is respected because you cannot pass it by memorising answers.

How it works, in plain steps

  1. First, build your base skills. You need to read C code, understand basic x86 assembly, and know how Windows memory is laid out.
  2. Next, learn to use a debugger such as WinDbg. A debugger lets you pause a program and watch how it crashes.
  3. Then practise fuzzing, which means feeding a program unexpected input until it breaks, and studying the crash it produces.
  4. After that, study exploit mitigations such as DEP and ASLR, and learn how researchers bypass them.
  5. The exam is a timed, proctored practical test. You receive a target and must produce a working exploit that bypasses protections.
  6. Finally, you write a short report explaining the vulnerability and your exploit. Your report is part of the grade.

Real-world example

Think of a program like a locked building with many doors. Most doors are strong, but one has a weak hinge. A fuzzer is the person who walks around pushing every door until one moves. Finding the weak hinge is only half the job. The exploit developer then works out exactly how to open that door and walk inside. OffSec OSED asks you to do both jobs within one fixed time limit.

Key takeaways

  • This exam is very hard, so learn C, assembly, and debugging before you enrol.
  • You must write a working exploit, so passive study is not enough. Practise on real programs.
  • Your written report matters. Clear notes during testing save you time at the end.

In more detail

OffSec OSED, the Exploit Developer certification from OffSec, is an advanced hands-on credential for security professionals who already write code and want to prove they can find and exploit memory corruption bugs in compiled Windows software. It sits at the expert end of the OffSec path, well above entry level. The exam is a practical, proctored challenge in which you are given a target application, must discover a vulnerability through fuzzing and reverse engineering, and then build a working exploit that defeats modern protections and runs your own code. There is no multiple choice section. Passing proves to an employer that you can do real exploit development rather than repeat theory, and it leads to roles such as exploit developer, vulnerability researcher, reverse engineer, and senior penetration tester. Exam domains and objectives

  • Explain how Windows memory, the stack, and the heap support the execution of a compiled program
  • Read basic x86 assembly and link it back to the C source that produced it
  • Use a debugger to reproduce a crash and identify the exact instruction that fails
  • Fuzz a target application and triage the crashes it produces by severity
  • Describe the common exploit mitigations on Windows and how each one works
  • Build an exploit that redirects execution and runs your own payload on the target
