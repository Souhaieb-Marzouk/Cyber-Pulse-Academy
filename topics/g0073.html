G0073 APT19

G0073Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

APT19 is a name used by security companies for a spying group. Public reports link it to Chinese state interests. That link is an assessment, not a proven fact. It has targeted government and company networks since around 2014. It is best known for booby trapping websites that its chosen victims often visit.

Why should you care?

People trust the websites they use every day for work. When one of those sites is changed, the visitor has little reason to be suspicious. This makes the entry step very quiet. It also means a security team only protects its own servers. The danger may wait on a site outside the company.

How it works, in plain steps

  1. The attacker studies a group of targets and finds websites they all read regularly.
  2. That website is broken into, and code is added that runs for chosen visitors only.
  3. A visitor loads the page and malicious code runs on the visitor computer.
  4. The compromised computer contacts the attacker through a normal web service online.
  5. The attacker uses built-in tools to stay hidden and gathers documents and passwords.
  6. Access is kept with scheduled tasks or services so it survives a restart.

Real-world example

Picture a busy bus stop that everyone on one street uses each morning. Someone replaces the timetable board with a copy that looks identical. It even shows the correct times. The board now contains something that only affects people who scan the small code printed on it. Regular passengers see nothing unusual. The people who scan it are followed. A watering hole attack works like that board. The place is trusted, the change is invisible, and only chosen visitors receive the harmful part.

Key takeaways

  • Keep browsers and plug-ins updated, because they are the surface a watering hole attacks.
  • If a trusted site you use daily is compromised, tell your security team, not just the site.
  • Review scheduled tasks and services, since attackers use them to keep access after a reboot.

In more detail

APT19, also tracked as Codoso and Sunshop Group, is a suspected state-linked espionage activity set that public reporting has connected to Chinese interests with moderate confidence. It has been documented since around 2014 attacking government, defence, legal, financial and technology organisations, with reported victims in the United States, Europe and Asia. Its best known technique is the watering hole: the group compromises websites that its chosen audience already visits, such as industry forums, legal publications and professional portals, and serves malicious content only to visitors it wants to infect. Public reporting has also described spear phishing with weaponised documents, abuse of public exploit code for enterprise software, and the use of legitimate remote access services so that malicious traffic is hard to separate from normal business activity. Persistence is typically achieved with scheduled tasks and services, and collection focuses on documents, credentials and mailbox content. Evidence in a network includes suspicious script in hosted web content, unusual browser child processes, scheduled tasks created outside change control, credential theft tooling on workstations, and authentication from unexpected locations. Two misunderstandings are common. The first is that watering holes require a rare browser exploit, when public reporting shows many infections rely on tricking the user into running something. The second is that because the sites involved are legitimate and trusted, the intrusion is treated as a website problem rather than an intrusion problem, which delays host investigation.

What you will practise

  • Explain what a watering hole attack is and why trusted sites are used for it.
  • Describe the difference between a browser exploit and a lure that needs user action.
  • Identify persistence mechanisms that survive a reboot and how to audit them.
  • Explain why legitimate remote access services make detection harder.
  • State the confidence level attached to public attribution for this group.
