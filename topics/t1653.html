T1653 Power Settings

T1653PersistenceExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

This technique is about keeping a computer switched on and awake. Attackers change the power settings so the machine will not sleep, lock, or restart. Their hidden program keeps running while the machine stays available.

Why should you care?

Many harmful programs cannot survive a restart. If the machine restarts, the attacker may lose their foothold. By blocking sleep and shutdown, they keep their access alive for longer. A machine that never locks also exposes everything on the screen to anyone nearby. These changes often go unnoticed, because hardly anybody checks power settings.

How it works, in plain steps

  1. The attacker has code running on the machine and needs it to stay active.
  2. They use a built in power tool, such as powercfg, to change the system power plan.
  3. They set sleep and disk timeouts to never, so the machine stays fully awake.
  4. They may extend the lock screen timeout so the session stays open and unlocked.
  5. Some attackers also delete the programs that carry out shutdown or restart.
  6. The hidden code keeps running, because the machine never enters a dormant state.

Real-world example

Think of a hospital night desk where a member of staff props open a fire door with a chair. The door is meant to close and lock by itself, but the chair stops it. Now anything can pass along that corridor all night, without a key and without setting off an alarm. Nobody notices, because from a distance the door still looks shut. Changing power settings is that chair. The computer is supposed to fall asleep and close itself down, but the attacker has stopped that from happening. The machine stays open and available until somebody moves the chair.

Key takeaways

  • A machine that never sleeps or restarts gives an attacker more time and fewer interruptions.
  • Unexpected power configuration changes are worth investigating on any host.
  • Check lock screen and shutdown settings after a suspected compromise.

In more detail

Power settings abuse keeps a compromised host awake and available so that malicious code is not interrupted by a sleep, hibernate, or shutdown transition. On Windows the powercfg utility controls every configurable power option, including standby timeouts, disk idle behaviour, and whether the machine may sleep at all, and the same values appear in registry keys that can be edited directly. On Linux the equivalent levers live in the systemd sleep configuration and related files. Attackers may also extend lock screen timeouts so a machine stays logged in and unattended, or delete the programs that carry out shutdown so the operating system cannot complete a restart. The technique supports persistence rather than causing impact. The evidence is configuration change: modified power schemes, new values in power related registry keys, and process creation records for powercfg, all of which are unusual on a server and need a business reason on a workstation.

What you will practise

  • Explain why an attacker wants a machine to stay awake and unlocked.
  • Describe what powercfg controls and how those settings can be changed.
  • Identify the registry and configuration locations that store power settings.
  • Explain how removing shutdown components affects a host.
  • List the log sources that reveal power configuration commands.
