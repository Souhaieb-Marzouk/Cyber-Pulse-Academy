T1595.001 Active Scanning: Scanning IP Blocks

T1595.001ReconnaissanceExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

This is when an attacker tests a whole range of internet addresses that belong to your organisation. They want a map of which addresses are in use. It is like checking every house number on a long street to see who is home.

Why should you care?

Your address range is public information, so an attacker can map it without permission. The map then shows which systems are worth attacking. Because a sweep touches many addresses quickly, it is one of the easiest attacks to notice if you watch your firewall records.

How it works, in plain steps

  1. The attacker looks up which internet address ranges are registered to your organisation.
  2. They send very small test messages to every address in those ranges.
  3. Addresses that reply are recorded as live, and silent addresses are set aside.
  4. They may try one common port on each live address to see if a service is listening.
  5. They note response times and unusual replies that hint at the operating system in use.
  6. They save the list of live addresses as the target list for deeper scanning later.

Real-world example

Think of a postal worker who walks an entire street and simply notes which letterboxes are real and which houses stand empty. No letter is delivered and no door is opened. The worker leaves with a map that tells a burglar exactly which houses are worth a second visit.

Key takeaways

  • An address sweep shows up as one source touching many of your addresses with tiny packets.
  • Keep an accurate asset register so you know which addresses should stay silent.
  • Block unused addresses at the perimeter so a sweep returns nothing useful.

In more detail

This sub-technique is the address range sweep: systematic probing of the publicly routed addresses an organisation holds, whether allocated as a contiguous block or as several ranges. The adversary starts with registration and routing data to work out which addresses belong to the target, then sends lightweight probes to each address to separate live hosts from unused ones before spending effort on detailed service examination. Simple reachability requests are common, as are single port probes such as a connection attempt to a web or remote access port, and the responses reveal which hosts answer, how quickly, and sometimes which operating system family they run. In its parent the focus is active scanning in general, while this one is specifically about the map making stage that determines where later scans and exploits are aimed. Firewall and netflow records show one source touching many target addresses with few packets each, which is the classic signature, and defenders distinguish it from approved inventory scans by source ownership, timing and whether the sweep covers addresses that no asset register claims.
