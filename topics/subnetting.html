Subnetting

Network FundamentalsHardKeyword

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Subnetting means splitting one large group of network addresses into smaller groups. An IP address works like a street number for a computer on a network. A subnet is a smaller neighbourhood inside that network. Subnetting helps you keep different kinds of computers apart and makes traffic easier to manage.

Why should you care?

If every device sits in one huge network, a single infected laptop can reach every server directly. Splitting the network into smaller parts limits how far a problem can spread. It also makes rules easier, because a firewall can allow or block a whole group instead of single machines. Smaller groups carry less broadcast traffic, so the network stays faster and quieter. Without this structure, a security team loses its clearest tool for keeping systems apart.

How it works, in plain steps

  1. Every IP address has two parts: one names the network and one names the device inside it.
  2. A subnet mask, or prefix length, tells the computer where the network part ends.
  3. Borrowing bits from the device part creates extra smaller networks inside the original range.
  4. Each smaller network keeps its own first address for the router and its own broadcast address.
  5. Devices in the same subnet talk directly, while traffic between subnets must pass a router.
  6. Because that traffic always passes a router or firewall, you can write rules for each group.

Real-world example

Picture a large office building with one open floor and no internal walls. Anyone can walk to any desk, and one noisy visitor disturbs everybody. Now add walls and turn the floor into separate departments, each behind its own door. Staff move freely inside their own department and must pass through reception to visit another. Subnetting builds those walls inside a network, and the router is the reception desk that decides who may pass.

Key takeaways

  • Subnetting is a security control, not just arithmetic, because it creates the boundaries your rules apply to.
  • Devices in different subnets can only talk through a router, which is where you filter and log.
  • Keep servers, user devices, management access and guest networks in separate subnets.

In more detail

Subnetting is the practice of dividing one IP address range into smaller logical networks, each with its own broadcast domain and its own routing entry. It works by borrowing bits from the host portion of an address and assigning them to the network portion, which is expressed as a subnet mask or a prefix length such as a slash twenty four. In real environments subnetting decides which devices can reach each other directly, where routers and firewalls must be placed, and how many usable addresses a segment supports, which makes it the practical foundation of network segmentation. The mistake people make is treating it as arithmetic for examinations rather than as a security control: subnet boundaries are what allow a team to apply different filtering, logging and access rules to servers, user devices, management interfaces and guest networks. A related error is forgetting that the first and last addresses in each subnet are reserved and cannot be assigned to hosts.

What you will practise

  • Explain what subnetting is and why networks are divided this way.
  • Describe how a subnet mask or prefix length defines a network boundary.
  • Identify which traffic passes directly and which must go through a router.
  • Explain how subnet boundaries support filtering and logging rules.
  • Describe how segmentation limits the spread of an infection.
  • Explain why some addresses in each subnet cannot be given to a host.
