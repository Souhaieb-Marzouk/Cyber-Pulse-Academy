G0065 Leviathan

G0065Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Leviathan is a spy group that public reports link to China. It attacks government offices, navies, defence companies and research centres. Security companies use many other names for it, including APT40, MUDCARP, Gadolinium and Gingham Typhoon.

Why should you care?

This group is fast and busy. When a new weakness is published, they often use it within days, before many companies finish patching. They also target web servers that must stay online, so turning a machine off is not an option. For you, that means patch speed matters as much as patch process. If an internet facing service has a known flaw and a fix is available, the gap between publishing and patching is the window an attacker will use.

How it works, in plain steps

  1. The group scans the internet for servers running software with a known weakness.
  2. They exploit that weakness to run their own commands on the server, often through a web page.
  3. They leave a small script called a web shell, which lets them return through the website later.
  4. They send phishing emails to staff and collect more usernames and passwords.
  5. Stolen credentials are reused against other systems, both inside the same network and in other victims.
  6. They gather documents and research data, then keep the access available for future tasks.

Real-world example

Think of a hotel with a service door that staff use for deliveries. A workman notices the lock is old and shares the trick with others. Soon many people are using that door, and each one copies a few guest records on the way out. The hotel keeps the front desk busy and never checks the side entrance. Leviathan does this with web servers. The side door is an unpatched service, and the copies are documents and credentials.

Key takeaways

  • Internet facing servers are the group's favourite entry point, so patch them quickly.
  • A web shell is a small script that gives an attacker a way back through a website.
  • Credentials stolen from one victim are often reused against many other organisations.

In more detail

Leviathan, tracked as G0065 and reported under many aliases including MUDCARP, Kryptonite Panda, Gadolinium, BRONZE MOHAWK, TEMP.Jumper, APT40, TEMP.Periscope and Gingham Typhoon, is a prolific espionage group whose activity has been documented since around 2013. Multiple vendors assess that it operates in support of Chinese state interests, and reporting links its targeting to naval, maritime, defence, government and research organisations, with a strong focus on organisations in Southeast Asia and on entities connected to South China Sea issues. The group is notable for opportunistic and high volume operations, for rapid weaponisation of newly published vulnerabilities, and for using web facing application exploits, spear phishing and web shells to establish access. It also collects credentials across many victims, then reuses them for later intrusions. Investigators typically find traces in web server logs showing unusual requests to newly created script files, exploit attempts against internet facing services, mail gateway records, and authentication events from unfamiliar locations.

What you will practise

  • Explain what Leviathan is and list several aliases used for it in public reporting.
  • Describe how exploitation of internet facing services leads to web shell persistence.
  • Explain why rapid weaponisation of new vulnerabilities shortens the patching window.
  • Describe how credential reuse across victims multiplies the impact of one intrusion.
  • Identify the log sources that reveal web shell access and exploitation attempts.
