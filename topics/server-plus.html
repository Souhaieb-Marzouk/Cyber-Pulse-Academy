CompTIA Server+

CompTIAExtremeCertificationUnofficial Study Resource

In more detail

CompTIA Server+ is a vendor certification offered by CompTIA. This independent study guide covers all 4 objective domains: Server hardware installation and management, Server administration, Security and disaster recovery, Troubleshooting. Each domain is broken into 20 lessons in total, and every lesson has a MEDIUM and a HARD scenario exam. The exams use realistic workplace situations rather than recall questions, so you practise applying each objective the way the job asks for it.
