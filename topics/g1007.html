G1007 Aoqin Dragon

G1007Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Aoqin Dragon is a name used in public research for a group that spies on government and education offices in Southeast Asia. It is known for spreading its software through universal serial bus drives, which are the small sticks people plug into computers to move files. That lets it reach computers with no internet connection.

Why should you care?

Some networks are kept apart from the internet on purpose, because they hold sensitive work. A memory stick carried between offices can silently undo that protection. People share files on drives every day, so this route is easy to miss. The group is also patient, which means an infection can sit unnoticed for a long time while documents are copied out slowly.

How it works, in plain steps

  1. The group sends a fake document that installs a small program when the target opens it.
  2. That program copies itself onto any universal serial bus drive later plugged into the computer.
  3. When the drive is used on another machine, the program runs there too and spreads again.
  4. Shortcut files, which are just links to other files, are used to hide the real program.
  5. The program collects documents from shared folders and waits quietly for long periods.
  6. Copied files are moved out later, sometimes through a different computer with internet access.

Real-world example

Picture a company where the design team and the finance team sit on separate floors with separate networks. They cannot email each other, so they exchange files on a memory stick left at the front desk. One day a stick arrives with a harmless looking shortcut to a meeting agenda. Whoever opens it on the finance floor carries a passenger along. The wall between the floors was never broken. Someone simply walked through the door with the passenger in a pocket. That is how removable media defeats a separated network.

Key takeaways

  • Control which universal serial bus devices may connect, and log every device that does.
  • Treat shortcut files on removable media as suspicious, because they can launch hidden programs.
  • Separated networks still need endpoint monitoring, since files must move between them somehow.

In more detail

Aoqin Dragon is a long running espionage cluster described in public reporting since roughly 2013, with victims in government, education and related organisations across Southeast Asia and Australia. Its most distinctive reported characteristic is reliance on removable media: the operators spread implants through infected universal serial bus drives and shortcut files, so that malware moves between networks that are deliberately kept apart from the internet. Reporting also describes document lures, simple loaders that fetch later stage components, and command and control over common web protocols with long periods of dormancy. This makes detection awkward, because the evidence appears on endpoints and file shares rather than only at the network edge: autorun and shortcut file creation, unexpected executables on removable drives, scheduled tasks that run from user directories, and outbound requests from hosts with no business reason to connect out. The misunderstanding worth correcting is that air gapped or segregated networks are automatically safe: removable media is a bridge, and controls such as device policy, endpoint logging and file share monitoring are what make that bridge visible. Public research attributes the activity to a China linked nexus with moderate confidence and notes tooling overlap between several clusters in the region.

What you will practise

  • Explain how removable media allows malware to cross a network boundary that has no internet connection.
  • Describe how shortcut files and autorun behaviour are abused to launch a hidden program on a new host.
  • Identify the endpoint artefacts and file share evidence that reveal a removable media intrusion.
  • Design device control and monitoring measures that reduce removable media risk without stopping legitimate work.
  • Summarise reported targeting and attribution for this cluster, including the moderate confidence attached to it.
