T1016 System Network Configuration Discovery

T1016DiscoveryExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

This technique means collecting the network settings of a computer. These settings include its address on the network, the gateway it uses to reach other networks, and the routes it follows. A gateway is the device that links one network to another. The attacker uses these facts to work out what they can reach and where to go next.

Why should you care?

Network settings tell an attacker the shape of your network. They show which other machines are nearby and how to reach them. They also show where the exits to the internet are. This step is quick, quiet, and usually comes just before the attacker tries to spread to other systems.

How it works, in plain steps

  1. The attacker runs built-in system commands on a computer they already control.
  2. One command prints the host's own network addresses, mask and default gateway.
  3. Another prints the routing table, which lists the paths the host uses to other networks.
  4. They check the local neighbour list to see which other hosts replied recently.
  5. They repeat the same checks on network devices, or on virtualisation hosts, if they reach them.
  6. They combine these results with other discovery to pick their next target.

Real-world example

Think of a driver who wakes up in a strange city with no map. They look at the street sign outside, the fuel gauge, and the list of motorway exits printed on the dashboard. That is enough to know roughly where they are and which road leads out of town. System network configuration discovery is that quick look around. The driver has not moved yet, but every later decision is now much easier.

Key takeaways

  • Address, gateway and route details tell an attacker how far your network can be reached.
  • These are normal administration tools, so alert on patterns rather than single runs.
  • Separate your networks so one host's view does not map the whole estate.

In more detail

System network configuration discovery covers the commands and calls used to learn how a host is addressed and connected: its network addresses, subnet masks, default gateway, routing table, name resolution settings, neighbour or address cache entries and interface details. On Windows the usual utilities are the address configuration tool, the address resolution cache viewer, the NetBIOS statistics tool and the route printer; on Linux and macOS the equivalents are the interface configuration tool, route listings and resolver settings. The same facts can also come from a network device command line, where an operator or an attacker reads interface and route tables, or from a virtualisation host utility that reports physical adapters and their addresses. The output tells an adversary which ranges are reachable, where the exits from the network are, and whether the target sits on a flat segment. Evidence lives in process creation records with those command lines, in shell history and in network device configuration logs. Administrators and monitoring agents run identical commands, so context, frequency and correlation with later movement decide whether the activity is hostile.
