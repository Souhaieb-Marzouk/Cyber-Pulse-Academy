Simple definition

The Information Systems Security Engineering Professional (ISSEP) is an advanced certification from ISC2. It is open only to people who already hold the Certified Information Systems Security Professional (CISSP). It is about building security into a system during its design and engineering, not about fixing it afterwards.

Why should you care?

It costs far less to design security in than to add it later. Engineers who can do this are in demand for large projects. This certificate proves that you know the whole system lifecycle and the paperwork that goes with it. It supports senior engineering and consultancy roles. It also shows that you can work with project managers and customers, not only with code.

How it works, in plain steps

  1. Confirm that you hold the Certified Information Systems Security Professional (CISSP) and meet the rules for a concentration exam.
  2. Read the official ISC2 exam outline and note the five domains and the tasks in each one.
  3. Study the systems engineering process, from needs and requirements to design, testing and disposal.
  4. Learn how risk is assessed and accepted across the life of a system.
  5. Practise questions that describe a project stage and ask for the correct engineering action.
  6. The exam is multiple choice and separate from the core exam, so allow several months of study.

Real-world example

Think about buying a new payroll system for a government office. An engineer who understands this certification does not start with the software. They first write down the security needs, such as who may approve a payment and how records are kept. Then they check each design choice against those needs, test the system, and plan how the old system and its data will be destroyed at the end. That orderly path is what the ISSEP exam rewards.

Key takeaways

  • The certification follows a system from first requirement to final disposal.
  • Learn the engineering process and the documents it produces, not only the technology.
  • You must hold the Certified Information Systems Security Professional (CISSP) before you take this exam.

In more detail

The Information Systems Security Engineering Professional (ISSEP) is a concentration exam from ISC2 for holders of the Certified Information Systems Security Professional (CISSP) who work on systems engineering. It sits at an advanced level and suits security engineers, systems engineers, architects and consultants who build security into a system from the first requirement to final disposal. It proves to an employer that you can run the engineering process properly, manage risk across a system lifecycle, and produce the documentation that certification and accreditation bodies expect. The exam covers five published domains, from engineering foundations and risk management through design, secure operations, and the disposal or transition of a system, using multiple choice items that test process judgement. It leads to roles such as security engineer, systems security architect, and programme security lead. Exam domains and objectives

  • Apply a recognised systems security engineering process to a real project
  • Write security requirements that can be tested and traced through a design
  • Assess and treat risk at each stage of a system's life
  • Check that a design meets its security requirements before it goes live
  • Plan secure operation, maintenance and change for a deployed system
  • Prepare a system and its data for safe disposal or transfer
