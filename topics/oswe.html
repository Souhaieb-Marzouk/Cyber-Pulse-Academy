Explained in plain language

Written for beginners. No security background needed.

Simple definition

OSWE is an advanced certification from OffSec about web application security. A web application is software you reach through a browser, such as a shopping site or an internal tool. This certification is different from most because you receive the source code, which is the human readable program text. You read that code to find security bugs, then prove each bug is real by exploiting it.

Why should you care?

Automated scanners miss many serious bugs that only code review can reveal. This certification proves you can find those bugs yourself. An employer sees that you can join a development team and improve security before release, not only after. It supports well paid application security roles. It also makes you a sharper tester. You learn why an input is dangerous, not just which string triggers an alert.

How it works, in plain steps

  1. Learn one server side language well, such as Java, PHP, or a JavaScript runtime, because you must read code.
  2. Study the main vulnerability classes: injection, authentication flaws, and unsafe data handling.
  3. Set up the sample applications in your own lab and trace how a request flows through the code.
  4. Practise turning each weakness into a working exploit, so you can show genuine impact rather than a warning.
  5. Rehearse with a timer, because the exam gives you a fixed period and several applications to attack.
  6. The exam is proctored and practical. You review source code, exploit what you find, and submit a report.

Real-world example

Picture a mail room where every parcel is checked at the front desk. Attackers cannot smuggle anything past that desk. But the staff never check the internal envelopes that travel between departments. A code reviewer looks for those internal envelopes. They are the places where the program trusts data it should not trust. OffSec OSWE asks you to find one of those internal envelopes. You then prove that you can reach the vault.

Key takeaways

  • You must read code well. Pick one web language and study it properly first.
  • A warning is not a finding. You must exploit each bug to prove real impact.
  • OffSec does not publish domain weights here, so build your own study plan around weak areas.

In more detail

OffSec OSWE, the Web Expert certification, is an advanced hands-on credential for people who audit and attack web applications at source code level. It suits web developers moving into security, application security engineers, and penetration testers who want to go beyond black box testing. The exam is a practical, proctored challenge in which you receive applications with their source code, review that code to find vulnerabilities, and then exploit each finding to prove real impact. There is no multiple choice section. OffSec does not publish per domain weightings for this exam, so the chapter list below gives the official domain names without percentages. Passing proves to an employer that you can read unfamiliar code, trace untrusted input to a dangerous function, and write a working exploit, and it leads to roles such as application security engineer, secure code reviewer, and senior web penetration tester. The domain structure below follows the published objectives; check the vendor's current version before booking.

Exam domains and objectives

  • Read an unfamiliar web application code base and map its entry points
  • Identify the exact places where untrusted input reaches a dangerous operation
  • Recognise authentication and session handling flaws from source code alone
  • Assess injection and deserialisation weaknesses in server side code
  • Build a working exploit that proves the real world impact of each finding
  • Explain root cause and remediation to a development team in plain language
