G0099 APT-C-36

G0099Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

APT-C-36 is a name for a group of attackers that public reporting calls Blind Eagle. They mostly target organisations in Colombia and nearby countries. They send emails in Spanish that look like official notices or bills. The email leads to a harmful file that runs quietly on the computer.

Why should you care?

The fake notices match the paperwork that real staff handle every day, so they are convincing. The group reuses built in Windows tools, so simple file blocking often fails. They also change their servers often, which breaks lists of known bad addresses. Staff who handle invoices and legal notices are the first line of defence here. A short pause before clicking can stop the whole chain.

How it works, in plain steps

  1. The attackers study local paperwork, such as court notices, taxes, and invoices.
  2. They send an email that copies that style and language. Urgent messages about taxes or bank problems are common ways to gain trust.
  3. The email links to a file or carries a document attachment. The victim only needs to allow document content for the attack to begin.
  4. Opening it runs a script that uses tools already installed on Windows.
  5. Those tools download the real harmful program from the internet. These jobs often use names that look like ordinary software updates.
  6. The program starts automatically each time the user logs in. Trusted sites are used because security tools rarely block them.

Real-world example

Picture a fake tax letter that arrives in a real envelope with the correct official logo. It says you owe a small amount and must open the attached form today. The form looks like every other form you have filled in this year. You open it, because ignoring official post feels risky. That is the trick: the letter works because it copies something you already trust. This group copies real notices so closely that only careful checking shows the difference.

Key takeaways

  • Verify unexpected invoices and legal notices by phone before opening them.
  • Attackers often use tools that already exist on your computer.
  • Blocking known bad file hashes alone will not stop this group.

In more detail

APT-C-36, widely reported as Blind Eagle and also tracked as AguilaCiega, TAG-144 and APT-Q-98, is a Spanish-language intrusion set whose publicly documented activity concentrates on Colombia and neighbouring countries in Latin America, with targets that reporting describes as government, financial, energy, healthcare and law enforcement organisations. The group is a good example of commodity-plus-custom tradecraft: analyses describe spearphishing emails that carry a link to a file-hosting service or an attached document, followed by a chain that abuses legitimate system utilities, such as scripting engines and signed Windows components, to fetch and run the final payload. That approach is deliberate, because it defeats blocklists built on file hashes and lets the operators change infrastructure quickly. The lures in reporting are thematically local and administrative, often framed as court notices, invoices, tax matters or delivery notifications, which makes language and context the main filter a defender can use. Attribution in public reporting varies: several vendors place the group in the financially motivated criminal space, while others note overlap with state-interest targeting, so any statement about sponsorship should be presented as an assessed view held with limited confidence. Detection leans on mail gateway metadata, endpoint process lineage where a scripting engine or an office application spawns a network-capable process, proxy records for the initial fetch, and persistence through user-level autorun keys or scheduled tasks. The recurring misunderstanding is that localised lures are exotic; in practice the operator simply writes the email in the victim's own working language, and the same detection logic applies.
