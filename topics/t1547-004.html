T1547.004 Boot or Logon Autostart Execution: Winlogon Helper DLL

T1547.004PersistenceExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Winlogon is a Windows program that manages the logon screen. It can load helper programs and helper libraries (small code files) when you sign in. An attacker can change the Windows settings that name those helpers so their own code starts every time you log on.

Why should you care?

Signing in is something you do every day. If an attacker's file is named as a logon helper, their code runs again after every reboot or sign-in. That means they do not need to break in twice. In the machine-wide settings the helper can run with high privileges, so it may also help an attacker gain more power on the computer. Few people ever look at these settings, so the change can stay hidden for a long time.

How it works, in plain steps

  1. Windows stores the names of logon helper programs in registry keys for the whole computer and for each user.
  2. When you sign in, Winlogon reads those names and starts the programs or libraries they point to.
  3. The Userinit value normally names userinit.exe, and the Shell value normally names explorer.exe, your desktop.
  4. An attacker edits one of those values, or adds an entry under the Notify list, so a different file is loaded.
  5. The attacker's file is often placed in a folder that looks normal, and may reuse a familiar file name.
  6. Detection compares these values with the known defaults and checks what loaded just after logon.

Real-world example

Think of a hotel front desk. The clerk keeps a laminated card listing the people allowed to enter rooms and the jobs to do at each shift change. A visitor swaps that card for one with an extra name on it. Every morning the new clerk reads the card and lets the stranger in, because the instructions look official. Nobody questions the card until someone compares it with the original kept in the manager's office.

Key takeaways

  • Logon helpers run your attacker's code again at every sign-in, so removal needs the settings fixed, not just the file deleted.
  • Compare Winlogon registry values with the known defaults for that Windows version.
  • Record which programs start just after logon, and note any that are not the usual desktop shell.

In more detail

Winlogon helper abuse gives an adversary code execution at every interactive logon by redirecting the components that winlogon.exe loads. Values under the machine and per-user Winlogon registry keys name helper programs: Userinit normally points to userinit.exe, Shell normally points to explorer.exe, and the Notify subkey lists notification package DLLs that receive Winlogon events. Replacing one of those values with an attacker-controlled path, or adding a new Notify entry, causes the substituted binary or library to run as the authenticating user, and in the machine-wide keys it can run in a privileged logon context. The artefact is easy to describe and hard to blend in: a registry value that differs from the platform default, a DLL outside System32 that loads into the Winlogon or userinit process tree, and a logon-time process whose parent chain is winlogon.exe or userinit.exe rather than explorer.exe. Defenders baseline these values per Windows build, alert on any deviation, and correlate registry writes with process creation, since legitimate software rarely rewrites them.

What you will practise

  • Explain what the Winlogon helper registry values are and when the operating system reads them.
  • Identify the Notify, Userinit, and Shell subkeys and describe what each one normally controls.
  • Describe the process tree that appears when a logon helper runs, and how it differs from a normal logon.
  • Detect suspicious changes to Winlogon helper values using registry monitoring and process creation events.
  • Distinguish a legitimate software update of a logon helper from an attacker modification.
  • Explain why persistence at logon survives reboots and how to remove it completely.
