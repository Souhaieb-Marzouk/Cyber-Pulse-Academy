T1561 Disk Wipe

T1561ImpactExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

A disk wipe is an attack that destroys the data stored on a hard drive. The attacker does not read the data and does not simply delete files. They overwrite the storage itself with rubbish so the original content is gone. This is done to stop a company working, not to steal information.

Why should you care?

Deleted files often can be recovered, but overwritten storage cannot. A successful wipe can destroy servers, laptops, and backups if they are reachable. Some wiping software spreads by itself from machine to machine, so one infection can stop a whole company in hours. The cost is measured in downtime, lost records, and the long job of rebuilding systems. Because the damage happens fast, preparation and backups matter more than last minute cleaning.

How it works, in plain steps

  1. The attacker gains a foothold on a machine, usually with high level or system permissions.
  2. Their software opens the storage device directly instead of using normal file operations.
  3. It writes rubbish data over large areas, or over the small areas needed for booting.
  4. The same tool may copy itself to other machines using stolen accounts and shared folders.
  5. Victims notice failed programs, crashes, and computers that will not start again.
  6. Defenders look for unusual raw device access and a burst of writes before the failure.

Real-world example

Think of a warehouse that keeps its stock records on paper. A thief does not take the goods. Instead they pour ink over the record books and the shelf labels. Staff cannot find anything, cannot prove what is missing, and cannot trade. The building still stands and the shelves are still there. But nothing can be found or trusted until everything is rebuilt.

Key takeaways

  • Disk wiping destroys availability and is not about stealing data.
  • Wipers often spread across the network, so one host can become many.
  • Backups kept offline and separate are the strongest protection against this impact.

In more detail

Disk wipe is an impact technique in which the adversary destroys raw disk data to remove availability rather than to steal anything. Instead of deleting files through the operating system, the attacker writes directly to the storage device and overwrites sectors, either across arbitrary regions of the volume or at the specific on disk structures that are needed to boot. The distinction matters because the damage is not recoverable through the file system: ordinary forensics and recovery tools that work with directory entries and file records find nothing to work with once the underlying blocks have been rewritten. Destructive campaigns also tend to scale. Wipers frequently carry worm like behaviour so that one compromised host spreads the payload to others using valid accounts, credential dumping, and administrative shares, which turns a single execution into an organisation wide outage. Wiping is also aimed at network devices, where the equivalent effect is achieved through the device command line interface, for example an erase instruction that removes the configuration or reformats the file system. The available telemetry is thin because the events that matter most happen during the boot process and after the machine is already damaged. Useful indicators include raw device access by unexpected processes, a heavy burst of writes to low numbered sectors, sudden input output errors across many systems, and machines that restart and then fail to reach the operating system. Recovery and resilience planning, not prevention alone, determine how quickly an organisation returns.

What you will practise

  • Define disk wipe and explain why it targets availability rather than confidentiality.
  • Describe why direct writes to storage are harder to recover than ordinary file deletion.
  • Explain how worm like behaviour can turn one wiped host into a network wide outage.
  • Identify the endpoint and boot level artefacts that indicate wiping is under way.
  • Explain how wiping is carried out against network devices through their command line.
  • Outline the resilience measures that reduce the impact of a destructive campaign.
