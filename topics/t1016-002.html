T1016.002 System Network Configuration Discovery: Wi-Fi Discovery

T1016.002DiscoveryExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Wi-Fi is a wireless way to join a network using radio. This technique means collecting the names of wireless networks a computer has joined before, and sometimes their passwords too. The parent technique maps a computer's addresses and routes. This sub-technique looks only at wireless network details and saved keys.

Why should you care?

Saved wireless passwords are real credentials, and people often reuse them elsewhere. A home or cafe network is usually less protected than the office network. The list of networks also shows where the laptop travels, which helps an attacker plan. Anyone who gets an ordinary user account can usually read this data.

How it works, in plain steps

  1. The attacker gets an account on the computer, often an ordinary user account.
  2. They run a built-in command that prints the names of saved wireless profiles.
  3. They then ask for one profile in clear form, which reveals its stored password.
  4. On Linux they read the saved connection files under the network manager folder.
  5. On macOS they request the password from the system keychain for a known network.
  6. They collect the names and keys so they can reuse or sell them later.

Real-world example

Think of a shared flat where every door has a spare key hanging on a hook by the entrance. Each key has a label on it: home, office, gym, cafe. A visitor who reaches that hook takes every key at once. They do not need to break a single lock, because the labels tell them exactly which door each key opens. Saved Wi-Fi profiles are that row of labelled keys on the wall.

Key takeaways

  • Saved wireless profiles can contain clear text passwords that are worth stealing.
  • The command that prints a profile in clear form is the key detection signal.
  • Treat stored wireless keys as secrets, and delete profiles you no longer need.

In more detail

Wi-Fi discovery is the sub-technique of collecting wireless network details from a host, including the names of networks the device has joined before and, where the platform stores or will reveal it, the saved passphrase for each one. On Windows the wireless network shell command lists saved profiles and, with the correct flag, prints a profile's key in clear text, while other tools reach the same data through the wireless network application programming interface. Linux keeps connection profiles as files in the NetworkManager directory, and macOS can return a stored key from the system keychain for an account with enough permission. The value to an adversary is twofold: the profile list shows where the machine travels, which supports account and remote system discovery, and the keys unlock networks that are typically less defended than the corporate one. Endpoint telemetry is the main evidence, since the command lines are distinctive and reads of the wireless profile store are unusual for most processes. Ordinary users and support staff do run these commands, so the account and the stated reason deserve scrutiny.

What you will practise

  • Explain how this sub-technique narrows the parent technique to wireless details.
  • Describe where Windows, Linux and macOS keep saved wireless network information.
  • Explain why a saved wireless key is a risk beyond that single network.
  • Identify the command lines and file reads that reveal wireless profile collection.
  • Recommend steps that reduce the number of saved wireless profiles on a machine.
