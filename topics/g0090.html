G0090 WIRTE

G0090Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

WIRTE is a name for a small spying group reported from 2019. It attacked government, diplomatic and military offices in the Middle East. The attackers sent documents with political topics that caught the reader's interest. They used tools already built into Windows instead of large viruses. Researchers describe the activities, but the people behind them are not confirmed.

Why should you care?

Politically themed files are a strong lure, because curiosity is powerful. When attackers use built-in tools, antivirus software may see nothing unusual. The traces that remain are small: a document opening, a script starting, a connection to an outside server. If nobody reviews those records, the intrusion stays invisible for months. Simple monitoring of script and network activity closes that gap.

How it works, in plain steps

  1. The attackers study the current political events that matter in the target's region.
  2. They create a document about that topic and send it to chosen staff.
  3. The document starts a script on the computer when the reader opens the file.
  4. The script then gathers system details and downloads a set of extra instructions.
  5. The tool then sends results to an outside server over ordinary web traffic.
  6. The attackers keep their access and reuse the same lure with new targets.

Real-world example

Think of a fishing boat that uses the same favourite bait every season. The fish do not learn, because the bait matches what they already want to eat. The boat is small and quiet, and it never empties the whole lake. It simply returns again and again. Attention-grabbing documents work in exactly the same way.

Key takeaways

  • Topical or political files are a common lure, so treat them with care.
  • Built-in scripting tools can hide attacker activity from file scanning.
  • You cannot confirm who is behind a campaign from behaviour alone.

In more detail

WIRTE, also reported under the name Ashen Lepus, is a small espionage cluster that Kaspersky and other vendors described from 2019 onward, with targeting of government, diplomatic, military and political organisations in the Middle East, including Palestinian and Israeli related entities. The operators were noted for using the same kind of politically themed decoy documents repeatedly, and for relying on scripting environments and legitimate tooling rather than heavy malware, which keeps their footprint small and their activity easy to confuse with routine administration. Reporting describes collection aimed at diplomatic and geopolitical information, with command and control often carried over common web protocols. Reporting on the group's sponsorship is limited and sometimes contradictory in public sources, so the cluster name should be understood as a label for observed behaviour rather than a confirmed organisation, and defences should rest on script visibility, mail inspection and monitoring of outbound connections.
