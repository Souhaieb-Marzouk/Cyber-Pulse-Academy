T1059.006 Command and Scripting Interpreter: Python

T1059.006ExecutionExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Python is a popular programming language that is easy to read and write. It is installed on many computers, especially those used by developers and administrators. Attackers use it because a short script can download more files or run other commands. The script can run from a command line or from inside another program, so it rarely attracts attention.

Why should you care?

Because Python is a normal and expected tool in many workplaces, its presence raises no alarm at all. A short script can do a great deal, from downloading files to talking to other computers. It also runs the same way on Windows, Linux and macOS, so one script suits many machines. Attackers can turn it into a standalone program to hide the fact that a script is running. That combination makes Python both common and easy to miss.

How it works, in plain steps

  1. A user or a program starts the Python interpreter, which reads and runs instructions.
  2. The instructions can come from a command line, from a file or from another program.
  3. The built in libraries can open network connections and download files from the internet.
  4. The script can then start other programs or run commands on the operating system.
  5. Attackers often pass encoded instructions so the real purpose is not obvious to a reader.
  6. Python code can be turned into a standalone program so no interpreter appears in the process list.

Real-world example

Picture a large office building that gives every desk a standard toolkit. The tools are useful, and nobody questions a colleague carrying one across the floor. A visitor signs in at reception and picks up the toolkit. He uses it to unscrew a door panel. Then he runs a cable from that panel to his own equipment. The toolkit is legitimate, the badge is real, and the work looks like maintenance. Only the task itself was never authorised, and the tools gave no warning at all.

Key takeaways

  • Python is normal in many environments, so its use is not suspicious by itself.
  • Short scripts can download, run and install other content very quickly.
  • Look at what the interpreter is asked to do, not just that it ran.

In more detail

Python is a general purpose language that adversaries use for execution because it is widely installed, quick to write, and comes with libraries for files, networking and system interaction. Code can be run interactively from an interpreter, executed from a script file, or compiled into a standalone binary so that no interpreter path appears in the command line. Once running, built in modules let the code retrieve further content from the network, run additional commands and interact with the host, which makes Python convenient both as a loader and as a final payload. On Windows, Linux and macOS the interpreter is common enough to blend into administrator and developer activity, and it appears frequently in cloud and automation environments. Detection therefore relies on command line and process telemetry showing an interpreter that fetches remote content, executes an encoded or inline command, writes executables, spawns a shell, or runs from a temporary or user writable directory. Environments with declared dependencies and managed interpreters give a far cleaner baseline than hosts with unmanaged installations.
