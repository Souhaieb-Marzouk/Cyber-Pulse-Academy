G0100 Inception

G0100Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Inception is the name for a spying group that researchers have followed since about 2014. Public reports call it Cloud Atlas as well. It has attacked government offices and companies in many regions. It mainly gets in by sending a harmful document as an email attachment.

Why should you care?

The group wants documents, plans and saved passwords. It hides its control traffic behind ordinary cloud services and other people's routers. That makes the traffic look harmless on a network chart. It also keeps a quiet foothold, so it can stay for a long time. If you only look at which web addresses your network contacts, this group is very hard to see.

How it works, in plain steps

  1. The intruders study a target and write an email that looks like normal business correspondence.
  2. The email carries a document file that contains hidden harmful code inside it.
  3. When the person opens the document, the hidden code runs and installs a small program quietly.
  4. The program checks the computer, lists its files, and copies documents it finds interesting.
  5. It also takes saved passwords and login sessions from the web browsers on that machine.
  6. It keeps itself running after a restart and sends stolen data through cloud services.

Real-world example

Imagine a courier who never comes to your door. Instead, the parcel is handed over at a busy public library counter that everyone uses. Staff at your building see only that a delivery happened at the library, which is a normal place for deliveries. Nothing about the address looks strange, and the library keeps no list of who collected what. That is what hiding control traffic behind popular cloud services looks like. The connection is real and the destination is respectable, so the address alone tells you nothing. You have to notice the behaviour instead, such as a quiet computer suddenly reading hundreds of documents.

Key takeaways

  • Traffic to a well known cloud service can still be an intruder's control channel.
  • Saved passwords in browsers are a target, so treat browsers as valuable data.
  • A document that asks you to enable content deserves a second look, even from a known sender.

In more detail

Inception, also tracked in public reporting as Cloud Atlas and the Inception Framework, is an espionage cluster that MITRE ATT&CK catalogues as active since at least 2014. The targeting described there is unusual in shape: government entities and multiple industries primarily in Russia, with activity also reported in the United States and across Europe, Asia, Africa and the Middle East. That spread matters operationally, because it means the group is not confined to one region and adapts its lures to the local language and business context. The reported delivery method is weaponised documents attached to spear phishing email, exploiting vulnerabilities in office file formats rather than in the operating system, which is why filtering by file type or macro settings alone is not sufficient. Post compromise the framework is modular. Reported components handle reconnaissance of processes, software and domain membership, file hunting for common document formats, and theft of saved passwords and sessions from several web browsers, with the results encrypted and returned over ordinary web protocols. Persistence is established through registry run keys and through system utilities invoked in a way that loads attacker supplied libraries. Command and control is deliberately indirect: reporting describes chains of compromised routers and use of legitimate cloud providers, so the traffic arrives from a hosting address that looks ordinary. The defensive consequence is that destination reputation and allow lists are weak signals here; the durable evidence sits on the endpoint, in registry changes, in unusual parent processes for scripting engines, and in the sudden mass reading of documents, so defenders should expect an adversary whose control channel deliberately terminates at a well known cloud service.

What you will practise

  • Describe Inception and the regions and sectors that public reporting associates with its activity.
  • Explain why document based exploitation defeats controls that only block certain file types.
  • Describe how cloud services and compromised network devices can hide command and control traffic.
  • Identify endpoint evidence such as registry run key changes and scripting engine child processes.
  • Explain the risk that stored browser credentials and sessions create for an organisation.
  • Assess the limits of destination based network allow lists when an adversary uses legitimate hosting.
