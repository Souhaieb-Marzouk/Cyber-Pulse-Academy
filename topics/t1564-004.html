T1564.004 Hide Artifacts: NTFS File Attributes

T1564.004StealthExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

On Windows, a disk can use a format called NTFS, short for New Technology File System. This format keeps extra details about every file. Those details are called attributes. An attacker can store hidden data inside these attributes, so the file looks normal from the outside.

Why should you care?

Normal folders and file listings often hide these extra attributes. A file can look empty or unchanged while it carries a hidden payload. Many simple scanning tools read only the visible part of a file. This means a hidden copy of malware can sit on a machine for a long time. Knowing how to look deeper is therefore important.

How it works, in plain steps

  1. The NTFS format keeps a table with one record for every file and folder on the disk.
  2. Each record holds attributes, which are named pieces of information about the file.
  3. One attribute holds the file content, and a single file can have more than one.
  4. Extra content attributes are called alternate data streams, or ADS for short.
  5. An attacker writes a payload into one of these extra streams to keep it out of view.
  6. Standard directory listings and many scanners read only the main content stream.

Real-world example

Imagine a filing cabinet in an office. Each folder has a label, and you can see how thick the folder is. Now imagine someone sews a thin extra pocket inside a folder and slides a secret page into it. The folder still has the same label and almost the same thickness. Anyone who looks only at the label and the size sees nothing strange. Only a person who opens the folder and feels inside finds the extra pocket. Alternate data streams work in that same quiet way.

Key takeaways

  • A file can carry hidden content that its name and size do not show.
  • Use tools that list streams and extended attributes, not just file names.
  • Treat an executable started from a stream path as highly suspicious.

In more detail

NTFS File Attributes abuses the metadata structures of the New Technology File System, the Master File Table that holds one record for every file and directory on a volume. A payload can be written into Extended Attributes or into an extra Data attribute, commonly called an alternate data stream, instead of the visible file body. The host file keeps its name, its reported size and its content hash, so scanners that read only the main stream see nothing unusual. Defenders find this by enumerating streams rather than trusting a directory listing, and by watching for processes that read or launch content from a stream path.

What you will practise

  • Describe how the Master File Table records files on an NTFS volume.
  • Explain what an alternate data stream is and how data is stored inside one.
  • List the tools and telemetry that reveal stream or attribute content.
  • Explain why a hash check on visible content can miss a hidden payload.
  • Recognise file paths that point at a stream rather than a normal file.
