Simple definition

Security+ is a well-known entry-level security certificate from CompTIA. SY0-801 is the newer version of that exam, and this page covers the newer one.

Why should you care?

Many entry security jobs ask for Security+. Practising here uses the same five domains as the exam version you are sitting, so the labs and the batches you open match the certificate you are studying for.

How it works, in plain steps

  1. You study five domains: general concepts, threats and mitigations, architecture, operations, and programme management.
  2. Each domain is a chapter on this page, and each lab sits under the section it belongs to.
  3. The labs are simulations: you read an artefact, choose an action, and see why it was right.
  4. Exercise batches for the sections are being written and will appear beside the labs.

In more detail

CompTIA Security+ is the vendor-neutral baseline certification for defensive security work, and SY0-801 is the newer exam version that replaces SY0-701. This page tracks the SY0-801 edition: the lab set is published, and its exercise batches are being written against the same five domains so practice and reading stay aligned.

Exam domains and objectives

  • General Security Concepts: controls, the CIA triad, authentication and authorisation, change management and cryptographic solutions.
  • Threats, Vulnerabilities and Mitigations: threat actors and vectors, vulnerability classes, malicious activity and the controls that reduce exposure.
  • Security Architecture: secure design, cloud and virtualisation, resilience and the placement of network security controls.
  • Security Operations: monitoring and alerting, logging, identity administration, automation and operational hardening.
  • Security Program Management and Oversight: risk management, third-party risk, compliance, auditing and security awareness.
