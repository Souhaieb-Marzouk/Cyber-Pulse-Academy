T1087 Account Discovery

T1087DiscoveryExtremeTechnique

Account discovery is the enumeration of user, service and machine identities that exist in an environment, usually early in an intrusion, to identify accounts worth targeting for credential access or lateral movement. The mechanism is straightforward: the adversary queries whatever directory, database or operating system interface is reachable and returns identity information. On Windows systems this includes local account enumeration through command line utilities and remote procedure calls, domain enumeration through directory service queries and management cmdlets, and reading cached or configuration stored identity data. On Linux and Unix it includes reading local account and group files, querying directory services, and inspecting configuration management and orchestration data. In cloud environments the equivalent is calling identity provider interfaces to list users, groups, roles and service principals, and examining policy documents to learn who can assume what. Telemetry differs by platform but shares a shape. Endpoint logs capture the responsible process, its command line and parent, and whether the query tool ran from an unusual location such as a temporary directory. Directory services record the bind account and the volume of search operations, and large or unusually broad queries stand out against the routine lookups that applications and helpdesk tools perform. Cloud audit logs record the calling principal, the interface operation and its result, and the source address. Investigations rarely treat a single enumeration as conclusive. Asset inventory agents, identity governance tooling, backup software, monitoring systems and legitimate administration all enumerate accounts. Analysts look instead at breadth and intent: an account listing that covers the whole directory from a workstation that normally queries nothing, enumeration performed by a service account outside its application context, queries immediately following a new foothold, or results quickly followed by authentication attempts against the accounts that were discovered. Combining the identity of the caller, the scope of the query and the sequence of subsequent actions is what separates reconnaissance from routine housekeeping.

What you will practise

  • Explain how local, domain and cloud identity enumeration differ in mechanism and in the telemetry they generate.
  • Interpret directory service search volume and cloud identity interface calls to identify unusually broad enumeration.
  • Baseline which applications, agents and administrators legitimately enumerate accounts in your environment.
  • Correlate enumeration with subsequent authentication attempts against the accounts that were discovered.
  • Distinguish service account misuse from expected application behaviour using context and source host role.
  • Prioritise discovery alerts by caller privilege, query scope and position in the incident timeline.
