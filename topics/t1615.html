T1615 Group Policy Discovery

T1615DiscoveryExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Group Policy is a way for a Windows domain to send settings to many computers at once. Discovery means reading those settings. An attacker does this to learn the rules of your network. They also look for settings they could change later for their own benefit.

Why should you care?

The policy settings describe where your defences are strong and where they are missing. Reading them costs an attacker almost nothing, but it saves them a great deal of guessing. The same settings can later be changed to run malicious code everywhere at once. If you do not log policy queries, you lose an important early warning.

How it works, in plain steps

  1. An attacker with any normal domain account can read many policy settings.
  2. They run built in commands such as gpresult, or a script that queries the domain.
  3. The commands report which policies apply to users, computers, and to groups.
  4. They also read policy files stored in a shared folder on the domain controllers.
  5. The results show security settings, password rules, and where administrators log in.
  6. Attackers may later change a policy so that their own code runs everywhere.

Real-world example

Think of a block of flats with one management office that sets the rules for every home. Heating times, door codes, and visitor rules all come from that office. Any resident can read the noticeboard in the lobby, which lists the current rules for the whole building. A new tenant studies it carefully and learns which doors are never locked and when the caretaker is away. The noticeboard was public by design, and reading it looked completely normal.

Key takeaways

  • Group Policy describes your defences, which makes it valuable to an attacker.
  • Policy files in SYSVOL are readable by ordinary domain users by default.
  • Policy queries from machines that never administer the domain deserve review.

In more detail

Group Policy discovery is the enumeration of centrally managed configuration in an Active Directory domain. Group Policy Objects are the containers that hold these settings, and their files sit under a predictable path inside the SYSVOL share on domain controllers, which any authenticated domain user can usually read by default. Attackers use built in tools such as gpresult and the Group Policy PowerShell cmdlets, along with community tooling that queries the domain directly, to map password policy, logon scripts, software deployment, and the security settings that are actually enforced. The output shows where local administrator rights are granted, which controls are missing, and which settings could be modified to push their own payload to many machines at once. It also exposes naming and structure patterns that help an intruder blend in. Detection rests on process creation records with command line logging, attention to policy queries from hosts that never administer the domain, and unusual accounts reading policy files from SYSVOL.

What you will practise

  • Explain how policy discovery supports later policy modification.
  • State which log sources record policy enumeration activity.
