G1020 Mustard Tempest

G1020Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Mustard Tempest is the name for a criminal operation that turns ordinary websites into traps. Public reports have followed it since about 2017. When you visit a hacked site, a message appears telling you to install a browser update or a missing font. The update is fake, and it installs harmful software. The group sells the results to other criminals.

Why should you care?

You did nothing wrong. You visited a site that was working normally the day before. The site owner may not even know it was changed. Because the message looks like a routine update, many people click it without hesitation. Real updates never ask you to download a file from an unknown page, but few users know that rule. The harm does not stop at one laptop, because the access is often sold onward to groups that deploy ransomware.

How it works, in plain steps

  1. The attackers break into a normal website, often through a weakness in its content system.
  2. They add a short piece of code that shows a fake update message to visitors.
  3. They send visitors through a filter that hides the trap from security researchers.
  4. The victim is told to download a browser or font update they do not need.
  5. That download installs a loader, which fetches more harmful programs later.
  6. The stolen access is sold to other criminals who add stealers or ransomware.

Real-world example

Imagine a corner shop. Someone has quietly replaced the sign on the door with one that says repairs are happening next door. Customers walk to the next door and hand their keys to a stranger in overalls. They never question it, because the sign looked official. The shop itself is innocent. The sign is the injected code. The stranger is the fake update waiting to be installed.

Key takeaways

  • Never install a browser or font update from a page that offers you a download.
  • Update only through your browser settings or your operating system's own update tool.
  • Site owners should monitor for unexpected content changes and injected scripts.

In more detail

Mustard Tempest, tracked in public reporting as DEV-0206, TA569, GOLD PRELUDE, and UNC1543, is a financially motivated distribution operation rather than a classic intrusion team. It has been documented since around 2017 running large scale compromised website campaigns, most notably the fake browser update pattern in which a hacked but otherwise ordinary site displays a message telling visitors to install a browser or font update. The visitor is redirected through a gate that filters out researchers and automated scanners, then receives a malicious script or installer. Reported payload families include JavaScript loaders that other criminal groups rent, with follow-on malware such as information stealers, remote access trojans, and tools that lead to ransomware. The business model is distribution as a service, so the same infrastructure and the same victim website may serve several criminal customers over time. Practical defence means treating website compromise as a supply chain problem: monitoring for injected script, watching for content changes, and giving users a clear rule about installing updates only through the browser's own built in mechanism.
