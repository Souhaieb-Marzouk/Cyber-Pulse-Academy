G0135 BackdoorDiplomacy

G0135Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

BackdoorDiplomacy is a name used by researchers for a group that spies on foreign ministries and embassies. Public reports link it to Chinese interests. It usually breaks into servers that are open to the internet, not into individual laptops.

Why should you care?

Servers that are open to the internet are often the least watched part of a network. They may not run the same protection as office computers, and few people look at their logs. This group uses them as a base for months. It also uses memory sticks to reach computers that are kept offline for safety, so an isolated network is not automatically protected.

How it works, in plain steps

  1. The group looks for internet-facing servers that have known, unpatched weaknesses.
  2. It exploits one of them and places a small program in a web folder.
  3. That program lets it run commands through the normal web service, so traffic looks ordinary.
  4. It uses this base to reach other servers inside the network.
  5. It has also used removable drives to move into networks with no direct internet access.
  6. It collects documents and email slowly, while administrators see nothing unusual.

Real-world example

Think of an office building where the lobby is staffed and watched, but the basement server room is unlocked and nobody visits it. A thief ignores the lobby and lives in the basement, using the building's own power and water. Every day the staff walk past the door without looking in. Internet-facing servers are often that basement, and that is why they need the same attention as the front desk.

Key takeaways

  • Internet-facing servers need monitoring and protection just as much as laptops.
  • Check web and upload directories for files that should not be there.
  • Control removable media, because it can carry an attack into isolated networks.

In more detail

BackdoorDiplomacy is an espionage cluster that public reporting associates with Chinese state interests and that has been tracked targeting ministries of foreign affairs and diplomatic organisations, primarily in Africa, the Middle East, Asia and Europe. The group's reported signature is the abuse of internet-facing server software as both an entry point and a collection platform: it exploits known vulnerabilities in web and file-transfer services, and it has been described dropping a web shell that it then manages through a legitimate server process, sometimes communicating over a protocol the server already uses so that network traffic is difficult to distinguish from normal administration. Reporting also describes the use of removable media for lateral movement into networks that are not directly reachable, and the reuse of a public backdoor family, which blurs attribution because the same code appears in other campaigns. Because the initial target is often a public-facing appliance or server that is not covered by endpoint agents, evidence lives in web server logs, file system changes in web directories, and outbound connections from hosts that should not initiate them. The common misunderstanding is that endpoint protection on workstations covers the whole estate; internet-facing servers frequently have no agent at all.

What you will practise

  • Explain why internet-facing servers are frequently the weakest monitored part of an estate.
  • Describe how a web shell blends into legitimate server traffic and what evidence it leaves.
  • Explain how removable media enables movement into segmented or offline networks.
  • List the log sources needed to detect exploitation of a public-facing service.
  • Explain why reuse of public backdoor code limits attribution confidence.
