Explained in plain language

Written for beginners. No security background needed.

Simple definition

OSEP is an advanced certification from OffSec for penetration testers who already have experience. A penetration tester is a security professional paid to attack a company's own systems with permission. OSEP focuses on attacking networks that have modern defences in place. OffSec calls the credential the Experienced Penetration Tester certification.

Why should you care?

Many networks now run endpoint protection and application controls that block simple attacks. This certification proves you can work around those defences. An employer sees that you can stay quiet during an assessment instead of being caught straight away. It is a strong step up from a first certification and supports red team roles. It also shows you can keep working when a target does not behave as expected.

How it works, in plain steps

  1. Start only after you can complete a basic network penetration test without help.
  2. Learn how defenders detect attackers. Study antimalware, logging, and monitoring so you know what noise you make.
  3. Practise writing your own small tools in a scripting language so you are not limited to off the shelf programs.
  4. Study defences such as application allow lists and how attackers get around them in a lab you own.
  5. Build a home lab with Windows and Linux targets, and practise pivoting between networks.
  6. The exam is a long practical assessment. You must compromise the environment while staying undetected, then submit a report.

Real-world example

Imagine you are asked to test a bank vault. This vault has cameras and a guard who reacts to any noise. A beginner walks in through the front door and is caught at once. An experienced tester studies the guard's routine, finds the blind spot, and only moves when the camera is turned away. OffSec OSEP tests the second approach. It does not ask whether you can get in, because you already can. It asks whether you can get in without being noticed.

Key takeaways

  • Do not start here. Pass an entry level certification and get real practice first.
  • Stealth is graded. A loud attack that works may still count as a failure.
  • OffSec does not publish domain weights for this exam, so plan study time by your own weak areas.

In more detail

OffSec OSEP, the Experienced Penetration Tester certification, is an advanced hands-on credential for penetration testers who already hold a working certification and now need to operate against defended, modern networks. It sits above entry level and assumes you can already run a basic engagement. The exam is a long practical assessment in which you attack a simulated enterprise while a security operations centre watches, so stealth and defence evasion matter as much as exploitation. OffSec does not publish per domain weightings for this exam, so the chapter list below gives the official domain names without percentages. Passing proves to an employer that you can evade endpoint protection, bypass application controls, and move through Windows and Linux estates, and it leads to roles such as senior penetration tester, red team operator, and security consultant. The domain structure below follows the published objectives; check the vendor's current version before booking.

Exam domains and objectives

  • Write small custom tools in a scripting language to support an engagement
  • Evade antimalware and endpoint detection so your activity is not alerted on
  • Bypass application allow lists and other host controls on a Windows target
  • Move between network segments by using a compromised host as a pivot
  • Attack Active Directory environments and take control of the domain
  • Produce a professional assessment report that explains findings and business impact
