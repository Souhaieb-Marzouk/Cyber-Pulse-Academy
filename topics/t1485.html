T1485 Data Destruction

T1485ImpactExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

This technique means an attacker destroys the files and data on a computer or across a whole network. The aim is to make the information impossible to recover. It is not the same as normal deletion, because the content is overwritten, not just unlinked.

Why should you care?

Lost data can stop a hospital, a factory or a bank from working at all. If the files are overwritten, backups may be the only way back, and backups can be attacked too. Attackers use destruction to cause maximum harm, to cover their tracks, or to pressure a company into paying. Without early warning, you may only learn about the damage when users cannot open anything.

How it works, in plain steps

  1. The attacker first gains access to many systems using stolen accounts and remote administration tools.
  2. Tooling is placed on each system, often through a shared network drive or copied file share.
  3. On a chosen signal, the tool opens target files and overwrites their contents with random or fixed data.
  4. Some tools overwrite many times, or use ordinary pictures, so recovery becomes even harder.
  5. The files are then deleted or renamed, and sometimes the disk structure is damaged as well.
  6. The activity repeats across the network until the attackers decide to stop.

Real-world example

Picture a library where each book has a card in the catalogue. Throwing away a card is normal deletion, and the book is still on the shelf. Now imagine someone finds every book and paints over each page until it is unreadable, then throws the cards away. The shelf looks emptier but the real loss is the words. That is why destroying data is so much worse than simply deleting a file.

Key takeaways

  • Overwriting data is very different from deleting it, and normal backups are your best recovery.
  • Keep at least one backup copy offline and test that you can restore from it.
  • Sudden heavy disk write activity across many machines is a strong warning sign.

In more detail

Data destruction is the deliberate overwriting of file contents rather than the removal of directory entries. Simple deletion unlinks a name from its data, and the blocks usually remain readable to forensic tools, so wipers write over the data with random bytes, fixed patterns or even image files before removing the name. The scope can be a single host or an entire estate, and destructive tooling frequently borrows lateral movement and credential access behaviour so it can spread before it strikes. The artefacts are distinctive: sustained write throughput on many files in a short window, a sudden flood of deletions, and file recovery tools finding no residual content. Defenders use write volume anomalies, mass rename events and the process tree that issued them as the primary signals, because normal user deletion does not saturate storage or match those patterns.

What you will practise

  • Explain the difference between deleting a file and overwriting its contents.
  • Describe how destructive tools spread across a network before they act.
  • Identify the signs of mass overwriting in endpoint and storage telemetry.
  • Explain why offline and immutable backups change the outcome of this attack.
  • Describe how this technique relates to disk wiping techniques that target storage structure.
  • Explain how destructive malware can also erase the logs that would show what happened.
