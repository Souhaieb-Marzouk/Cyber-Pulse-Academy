Explained in plain language

Written for beginners. No security background needed.

Simple definition

This is a foundation certificate from CompTIA about computer networking. A network is a group of computers and devices that share data, such as the internet in an office. Network+ proves you understand how that sharing works, how devices are configured and how to find faults.

Why should you care?

Almost every security problem involves a network, and almost every outage starts as a connectivity problem. Employers want people who can explain addresses, routes and ports without guessing. This certificate is often the first serious step from a support desk into an infrastructure or security team. It also builds the base for cloud and cyber security study later.

How it works, in plain steps

  1. Learn how data is packaged and sent, starting with the layered model that describes each step.
  2. Study addresses and names, including internet protocol addresses, subnet masks and domain name resolution.
  3. Build a small home lab with a switch, a router and two virtual machines so you can watch real traffic.
  4. Learn the tools you will use daily, such as ping, traceroute, address lookup and a packet capture program.
  5. Study wireless, virtual private networks, cloud connectivity and basic network security controls.
  6. Practise scenario questions, then sit the proctored exam, which includes questions with more than one required action.

Real-world example

Think about posting a letter to a friend in another city. You write the address, and the post office sorts it. Lorries move it along roads until it reaches the right flat. Your friend must be at home to receive it, and a reply travels back the same way. A computer network works like that postal service. Internet protocol addresses replace street names, and routers replace sorting offices. Network+ teaches you the whole postal system, not just one letter.

Key takeaways

  • Learn the layered model well, because almost every other topic hangs from it.
  • Hands on practice with real devices or a simulator makes the addressing topics much easier.
  • Check the current exam objectives on the CompTIA website, because a newer version may be live.

In more detail

CompTIA Network+, exam code N10-009, is a vendor neutral certification for people who build and support the networks that everything else runs on. It sits at a foundation level, above basic IT support and before specialist security or cloud exams, and it suits help desk staff, junior administrators and career changers. Passing it tells an employer that you understand how data moves between systems, that you can configure and explain common network devices, and that you can diagnose a connectivity fault methodically. The exam is proctored and mixes multiple choice and multiple response questions with performance based items that present a scenario with several correct actions to choose. It leads to roles such as network technician, network administrator, support engineer and network operations centre analyst, and it is a common stepping stone to Security+. The domain list below follows the published objectives, so check the current version with CompTIA before booking. Exam domains and objectives

  • Explain how data moves across a network using layered models and common protocols
  • Configure addressing, routing, switching and wireless settings for a small network
  • Describe cloud and virtual networking concepts and how they connect to a physical network
  • Apply network security controls that reduce the chance of a successful attack
  • Monitor, document and change a network using recognised operational practices
  • Troubleshoot connectivity and performance faults with a structured method and the right tools

Chapter 1 Networking concepts 23% 18 exercises

What this chapter covers

  • OSI model layers: physical, data link, network, transport, session, presentation, application.
  • Networking appliances: routers, switches, firewalls, IDS/IPS, load balancers, proxies, NAS, SAN, and wireless devices.
  • Cloud concepts: NFV, VPC, network security groups, cloud gateways, deployment models (public, private, hybrid), service models (SaaS, IaaS, PaaS).
  • Ports and protocols: FTP, SFTP, SSH, Telnet, SMTP, DNS, DHCP, HTTP, HTTPS, SNMP, LDAP, RDP, SIP.
  • Traffic types: unicast, multicast, anycast, broadcast.
  • Transmission media: wireless (802.11, cellular, satellite), wired (fiber, coaxial, DAC).
  • Transceivers and connectors: SC, LC, ST, MPO, RJ11, RJ45, F-type, BNC.
  • Network topologies: mesh, hybrid, star/hub and spoke, spine and leaf, point-to-point, three-tier, and collapsed core.
  • IPv4 addressing: public vs. private, APIPA, RFC1918, loopback, subnetting (VLSM, CIDR), and address classes (A, B, C, D, E).

Chapter 4 Network security 19% 16 exercises

What this chapter covers

  • Logical security: encryption (data in transit/rest), PKI, IAM, MFA, SSO, RADIUS, LDAP, SAML, TACACS+, time-based authentication, authorization, least privilege, role-based access control, and geofencing.
  • Physical security: cameras and locks.
  • Deception technologies: honeypot and honeynet.
  • Security terminology: risk, vulnerability, exploit, threat, and CIA triad.
  • Audits and compliance: data locality, PCI DSS, and GDPR.
  • Network segmentation: IoT, IIoT, SCADA, ICS, OT, guest, and BYOD.
  • Types of attacks: DoS/DDoS, VLAN hopping, MAC flooding, ARP poisoning/spoofing, DNS poisoning/spoofing, rogue devices/services, evil twin, on-path attack, and social engineering (phishing, dumpster diving, shoulder surfing, tailgating).
  • Security features and defense: device hardening, NAC, key management, ACL, URL/content filtering, trusted vs. untrusted zones, and screened subnet.

Chapter 5 Network troubleshooting 19% 10 exercises

What this chapter covers

  • Troubleshooting methodology: identifying the problem, establishing a theory, testing, planning, and implementing a solution, verifying functionality, and documenting findings.
  • Cabling and physical interface issues: cable issues (incorrect type, signal degradation, improper termination, TX/RX transposed), interface issues (increasing counters, port status), and hardware issues (PoE, transceiver mismatch, signal strength).
  • Network services issues: switching issues (STP, VLAN assignment, ACLs), routing issues (routing table and default routes), address pool exhaustion, and incorrect gateway/IP/subnet mask.
  • Performance issues: congestion, latency, packet loss, and wireless interference.
  • Tools and protocols: protocol analyzers, command line tools, cable testers, and Wi-Fi analyzers.
