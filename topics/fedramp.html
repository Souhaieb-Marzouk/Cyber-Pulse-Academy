FedRAMP

GRC & ComplianceHardKeyword

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

FedRAMP means the Federal Risk and Authorization Management Program. It is a United States government programme that checks whether a cloud service is safe enough for government use. A company can be assessed once, and many agencies can then reuse that result. It is a shared way to trust cloud providers.

Why should you care?

Government data can be sensitive, so agencies need proof before they trust a cloud service. Without a shared programme, every agency would repeat the same long checks. FedRAMP saves that work and gives a common language for security controls. For a cloud provider it can be the price of entry to public sector customers. If the provider ignores it, the deal usually stops at the security review.

How it works, in plain steps

  1. The cloud provider chooses an impact level that matches the data it will hold.
  2. It documents how it meets a long catalogue of required security controls.
  3. An independent assessor tests the evidence and writes a formal security report.
  4. A government authorising body then reviews the report and grants a formal authorisation.
  5. The provider must then monitor its controls all year and report big changes.
  6. Customer agencies can reuse that authorisation instead of starting from the beginning.

Real-world example

Imagine a large office building with many tenants. Each tenant once hired its own inspector to check the lifts and the wiring. That took months every time. Now one approved inspector checks the building once and writes a single report. Every tenant can read the same report and move in much faster. FedRAMP works like that for cloud services. The report does not cover how a tenant arranges its own furniture. Each tenant still checks its own desks, keys and locks.

Key takeaways

  • FedRAMP is a shared way to check cloud services that government agencies want to buy.
  • An authorisation is not a permanent badge, because controls are monitored all year.
  • It covers the provider service, not how you configure your own accounts inside it.

In more detail

FedRAMP, the Federal Risk and Authorization Management Program, is a United States government programme that standardises how cloud services are assessed, authorised and continuously monitored before agencies may use them. It constrains the provider rather than the buyer: the provider must document and evidence how its service meets a large catalogue of security controls drawn from the NIST SP 800-53 control set, choose an impact level that matches the sensitivity of the data handled, and accept independent assessment of that evidence. A successful review produces an authorisation that other agencies can reuse instead of repeating the whole assessment, which is the economic point of the programme. The mistake is treating it as a permanent certificate or as cover for the customer's own configuration: the authorisation describes the provider's service boundary, while the agency remains responsible for how it configures its own tenancy, identities and data. Continuous monitoring obligations, not the original report, are where most programmes fail.

What you will practise

  • Explain what FedRAMP is and which problem it solves for government cloud buyers.
  • Describe the main steps from provider assessment to reuse by another agency.
  • Explain how impact levels shape the evidence a provider must produce.
  • Explain why continuous monitoring is part of the authorisation, not an extra task.
  • State which security responsibilities stay with the customer after authorisation.
