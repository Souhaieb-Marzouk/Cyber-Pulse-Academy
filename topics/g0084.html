G0084 Gallmaker

G0084Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Gallmaker is a name given to a spying campaign reported in 2018. It targeted government, military and diplomatic offices, mainly in the Middle East. The attackers sent documents that quietly fetched information from the internet. They did not need to install their own harmful program, because Windows already includes the tools they used. Researchers linked the activity to a state sponsor, but that link is a judgement, not proof.

Why should you care?

You can lose data without any virus file on your computer. Attackers can use tools that are already there, so nothing new appears in a file list. Many older defences look only at files, and they miss this completely. That is why you need records of which programs run on your machines. If you log that activity, this kind of quiet intrusion becomes visible.

How it works, in plain steps

  1. A document arrives by email and looks like a normal report or invoice.
  2. When it opens, the document asks Windows to fetch a small file online.
  3. The small file holds instructions only, rather than a full harmful program on disk.
  4. Windows then runs those instructions with a scripting tool that is already installed.
  5. The instructions then quietly collect information from the computer and nearby systems.
  6. The results are sent out through ordinary web traffic to a control server.

Real-world example

Imagine a guest who brings no luggage because he plans to use your own kitchen. He asks politely for a bowl and a knife, cooks his meal, and leaves everything exactly as he found it. Nothing is missing from your cupboards, so no inventory check notices him. Only a record of who used the kitchen shows that he was ever there.

Key takeaways

  • Malware does not have to be a separate file, because built-in tools can be reused.
  • Log script and process activity, since file scanning alone will miss this.
  • Treat public attribution as an assessment and defend against the behaviour.

In more detail

Gallmaker is a small espionage cluster that Symantec reported in 2018, describing targeted activity against government, military, defence and diplomatic organisations in the Middle East and elsewhere. The operators were notable for skipping malware almost entirely: they sent documents that abused a built-in feature for loading remote objects, then relied on the PowerShell command environment already present on Windows to collect data and move it out. Because no executable file lands on disk in the usual way, classic file scanning has little to work with, and the useful evidence sits in email gateway records, document open events and script execution telemetry. Public reporting describes a nexus linked to a state sponsor with limited supporting detail, so the attribution is best treated as an assessment, while the technique itself is widely copied and worth defending against regardless of who uses it.

  • Explain the difference between an attribution claim and a proven fact.
  • List the email and endpoint records that would support an investigation.
