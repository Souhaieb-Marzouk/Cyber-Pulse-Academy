Explained in plain language

Written for beginners. No security background needed.

Simple definition

This is an entry level certificate from the Cloud Native Computing Foundation. It covers Kubernetes and cloud native technology. Kubernetes is a tool that runs application containers across many computers and keeps them healthy. The associate level means the exam checks ideas more than repairs to a live cluster.

Why should you care?

Most modern software is packaged in containers and run on Kubernetes. Teams need people who understand that world. They also need people who are not yet the cluster expert. This certificate shows an employer that you speak the language of containers and orchestration. It is also a sensible first step before a harder administrator exam, and it fits career changers and junior engineers.

How it works, in plain steps

  1. Learn what a container is and how it differs from a virtual machine, then run one on your own laptop.
  2. Study the main Kubernetes objects, such as pod, deployment, service and namespace, and what each one does.
  3. Read about cloud native architecture, including microservices, serverless functions and the role of an application programming interface.
  4. Learn how code reaches production, including continuous integration, continuous delivery and Git based workflows.
  5. Study observability, which means logs, metrics and traces, and why a running system must be watched.
  6. Take practice questions until you can explain each answer, then sit the online proctored exam.

Real-world example

Think of a large hotel. Each guest room is like a container, because it holds one guest in an isolated space. The reception desk is like Kubernetes, because it decides which room each guest receives. It also moves a guest if a floor is closed. The hotel manager watches the electricity, the water and the complaints, which is observability. A KCNA candidate understands how those three parts work together, even before taking charge of the building.

Key takeaways

  • You can pass this exam without running a large cluster, but hands on practice makes the ideas stay.
  • Learn the vocabulary of cloud native work, because interviews use the same words as the exam.
  • Always confirm the current objectives and domain weights on the Linux Foundation website before booking.

In more detail

The Kubernetes and Cloud Native Associate, exam code KCNA, is an entry level certification from the Cloud Native Computing Foundation, which is hosted by the Linux Foundation. It is aimed at people who are starting to work with containers and Kubernetes and who want a formal, vendor neutral first step before a deeper administrator exam. The level is associate, so the paper tests broad understanding of the ecosystem rather than deep cluster surgery. Passing it tells an employer that you know how containers are orchestrated, how cloud native applications are built and delivered, and how such systems are observed. The exam is delivered online and is proctored, and it consists of multiple choice questions rather than a hands on lab. It supports roles such as junior DevOps engineer, site reliability engineer, platform support engineer and cloud native developer. The domain structure below follows the published objectives, so check the current version with the Linux Foundation before booking. Exam domains and objectives

  • Explain what Kubernetes is and how it differs from running containers by hand
  • Describe the main Kubernetes objects and the job each one performs
  • Explain container orchestration concerns such as scheduling, scaling and self healing
  • Describe how cloud native applications are packaged, delivered and released
  • Explain observability, including logs, metrics and traces, and why it matters in production
  • Identify the wider cloud native ecosystem, including the projects around Kubernetes
