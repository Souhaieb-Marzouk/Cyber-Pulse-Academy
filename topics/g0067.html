G0067 APT37

G0067Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

APT37 is a name that security companies use for a group of attackers. Public reports link this group to North Korean state interests. That link is an assessment, not a proven fact. The group mostly spies on government, military and media organisations. It is best known for phishing emails written in the Korean language.

Why should you care?

Groups like this one do not want to lock your files or ask you for money. They want to read documents and messages without being noticed. That makes them quiet, slow and hard to spot. If you work with sensitive information, an email that looks ordinary can be the start of a long intrusion.

How it works, in plain steps

  1. The attacker studies an organisation and picks people who hold useful documents or contacts.
  2. A short email is sent in the local language with an attached document or a link.
  3. The attachment hides a small programme inside. It runs when the reader opens the file and allows scripts.
  4. A backdoor is installed so the attacker can control the computer when the user is away.
  5. The attacker reads email, collects files and uses common online services to hide traffic.
  6. Stolen documents leave the network slowly so that normal monitoring does not notice.

Real-world example

Picture a shared office where staff use a printer room with no camera. A visitor in a delivery uniform brings a parcel addressed to one employee. The parcel contains a small camera that looks like a phone charger. Nobody questions the parcel, because the uniform and the label look normal. The camera then watches the room for months. Security guards keep checking the front door, which is locked. Nobody is watching the printer room. A quiet espionage group works like that. The entry step looks ordinary, and the value is in what it collects later.

Key takeaways

  • An email in your own language can still be a phishing attempt. Check the sender when the topic feels urgent.
  • Report anything odd quickly, because these intrusions are found by comparing small clues over time.
  • Documents and messages are the target, not just money or system access.

In more detail

APT37, also tracked by vendors as ScarCruft, Reaper, Group123 and InkySquid, is a suspected state-linked espionage group that public reporting has connected to North Korean interests with moderate confidence. The group has been documented since around 2012 targeting South Korean government, military, media and academic organisations, with occasional activity against targets in the Middle East, Japan and Southeast Asia. Its tradecraft centres on Korean-language spear phishing that delivers weaponised documents, self-extracting archives and shortcut files, followed by a family of remote access tools that blend into normal user activity. Public reporting describes tooling such as RokRAT, which abuses cloud storage and web services for command and control so that malicious traffic resembles ordinary browsing. Evidence in a compromised environment typically includes lure documents in the mail gateway, Office child processes spawning scripting hosts, persistence in startup folders or scheduled tasks, and outbound requests to well-known hosting providers at unusual times. A persistent misunderstanding is that the group only matters to the Korean peninsula: because the tools are portable and the lures adapt to local languages, the defensive lessons apply far beyond it. Analysts should also avoid treating every attributed campaign name as a fixed team, since vendor naming overlaps and splits across years.

  • State clearly that public attribution for this group carries moderate confidence.
  • Recommend practical controls such as macro restrictions and mail filtering for this threat.
