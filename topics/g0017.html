G0017 DragonOK

G0017Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

DragonOK is a research name for a cyber spying group that public reports link to China. It targets governments, armies, and technology companies, mostly in Asia. It often uses email attachments to get inside a network.

Why should you care?

The group sends large email campaigns, so one careless click can start an intrusion. It uses tools that anyone can download, which makes it hard to spot by file name alone. Small organisations are targets too, because they hold useful contacts and documents. Without mail filtering and script monitoring, these attacks land quietly. If nobody reviews the alerts, a loader can stay on one laptop for weeks.

How it works, in plain steps

  1. The attackers build a document or archive that looks like a routine business file.
  2. They email the file to many staff at once, hoping that a few people open it.
  3. When the file opens, it asks the reader to allow content or enable editing.
  4. That permission lets a small script run and start a loader on the machine.
  5. The loader contacts a server and pulls down a full remote control program.
  6. The attackers then explore the network and collect the documents they want.

Real-world example

Imagine a busy post room where hundreds of parcels arrive each morning. Most are ordinary, so workers open them quickly to sort them. One parcel looks exactly like the others. Inside it is a small device that copies everything in the room. Nobody inspects every box, because that would slow the whole post room down. The one odd parcel slips through with the crowd. A wide phishing campaign works the same way. Volume is the weapon here. The sender only needs one person in a hurry to open the file and allow its content.

Key takeaways

  • Attackers hide harmful files inside normal office documents.
  • A script started by a document is a strong warning sign.
  • Blocking or reviewing macro and script execution stops many campaigns at once.

In more detail

DragonOK is a cluster name for espionage activity that public reporting associates with China-nexus operators and describes as targeting government, military, technology, and non-governmental organisations, with a geographic emphasis on East and Southeast Asia. The reported pattern is opportunistic rather than surgically targeted: large phishing waves carrying archive attachments or documents that abuse dynamic data exchange, macro execution, and scripting runtimes to start a loader, followed by commodity and custom remote access families. Documentation of the group is thinner than for the highest-profile clusters, so some published assessments are single-source and should be read as such. In defender terms the activity is recognisable from attachment-heavy mail campaigns, office applications spawning script interpreters or command shells, and loader families reaching out to newly registered domains. The common misunderstanding is expecting a fixed toolkit. Public reporting shows the group reusing publicly available tools and changing lures quickly, so behavioural detections age far better than hashes or domain blocklists.

What you will practise

  • Describe how document-based delivery chains lead from an attachment to a running loader.
  • Explain why volume-based phishing campaigns succeed against busy staff.
  • Identify endpoint evidence such as office applications spawning script interpreters or shells.
  • Explain why publicly available tools complicate attribution and signature-based detection.
  • Describe mail filtering and attachment policy controls that reduce campaign success.
  • Assess the confidence level of public reporting on lower-profile clusters and state its limits.
