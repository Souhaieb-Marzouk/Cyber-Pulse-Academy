T1090 Proxy

T1090Command and ControlExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

A proxy is a middle machine that passes network traffic between two sides. Instead of connecting directly, a computer sends its traffic to the proxy, which forwards it on. This technique describes how attackers use proxies to hide where their control traffic really goes. It is a command and control technique, meaning it concerns how an attacker keeps in touch with a compromised system.

Why should you care?

If defenders block the attacker's server, the attacker loses control of the infected computers. A proxy makes that much harder, because the visible address is only a middle step. Proxies also reduce the number of obvious connections, so the traffic draws less attention. Several proxies in a row make the true source very hard to trace. This is why blocking one address is often not enough.

How it works, in plain steps

  1. The attacker sets up a middle system, called a proxy, that forwards traffic for them.
  2. The compromised host is told to send its control traffic to that proxy, not to the real server.
  3. The proxy passes the traffic on, so the real destination stays hidden.
  4. Attackers may chain several proxies so each one only sees the next hop.
  5. They may also hide inside content delivery networks, which are services that distribute web content.
  6. Defenders detect this through long connections, regular beacon timing and repeated relay behaviour.

Real-world example

Imagine you want to send a letter but you do not want your address on it. You give it to a friend, who gives it to another friend, who posts it. The final envelope shows only the last friend. Everyone in the chain knows only the person before them. A proxy chain works exactly like that, which is why following the trail back is so difficult.

Key takeaways

  • Proxies hide the real destination, so watch traffic behaviour and not only addresses.
  • Long, regular connections to one outside address are worth investigating.
  • Combining network and host logs gives a much clearer picture.

In more detail

A proxy is any intermediary that receives network traffic from one system and forwards it to another, so the victim host connects to the proxy instead of directly to the adversary's command and control server. Adversaries use this redirection to conceal the real destination, to cut the number of simultaneous outbound connections, to keep working when a single hop is lost, and to travel over trusted communication paths that already exist between victims. Implementation ranges from a small port forwarding utility to purchased cloud infrastructure, and chains of several proxies are common, with content delivery network routing sometimes used to hide command and control inside ordinary web traffic. Detection rarely succeeds on destination reputation alone. It works better on behaviour: long-lived sessions to one external address, regular beacon intervals, one host relaying traffic for many internal peers, and destinations that are new to the environment.
