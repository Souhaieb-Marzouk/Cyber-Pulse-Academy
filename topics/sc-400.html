Simple definition

SC-400 was a Microsoft exam about protecting company data and proving that rules are followed. The full title was Microsoft Information Protection Administrator, and the exam code was SC-400. It asked how you would label sensitive files. It also asked how you would stop them leaving the company. Finally, it asked how long to keep them. Microsoft has since retired this exam, so the same skills now support the newer exam in that path.

Why should you care?

Companies must protect personal, financial and legal information, and they must show that they do it. People who can turn those rules into working controls are hard to find. The work needs both technical skill and a feel for policy. This exam proved that you can build those controls in Microsoft Purview, the data protection part of Microsoft 365. Even though Microsoft retired the exam, the skills remain in daily demand and they transfer directly to the newer certification. If you already work with data security, that makes this material worth learning.

How it works, in plain steps

  1. Start with data classification, because labels, retention and protection rules all depend on it.
  2. Use a Microsoft 365 trial tenant with sample documents so that you can watch a policy take effect.
  3. Study one policy area at a time, such as sensitivity labels, then data loss prevention, then retention.
  4. Write down the order in which conflicting policies apply, because exam questions often test precedence.
  5. Practice reading a business requirement and naming the control that answers it.
  6. Check the current Microsoft objectives, because this exam has been retired and replaced.

Real-world example

Imagine a hospital that stores patient letters in SharePoint. A nurse tries to email one letter to a private address by mistake. If the file carries a sensitivity label, the system can warn the nurse, block the message or encrypt it automatically. Later a manager searches for every document marked as patient data. The search shows that one folder has no label at all. The manager then adds a retention rule. Those letters are kept for the required number of years and deleted afterwards. Each of those steps matches an SC-400 objective, and each one solves a real problem.

Key takeaways

  • SC-400 is retired, so use these domains as a skills reference and check the replacement exam.
  • Classification comes first, because most protection policies depend on it.
  • Learn how policy precedence works, since scenarios often involve overlapping rules.

In more detail

Exam SC-400 was Microsoft's associate level certification for information protection and compliance administrators, and this page follows the objectives Microsoft published while the exam was live. Microsoft retired the exam in 2025 and moved that certification path to a newer exam, so treat this material as a study reference for the Microsoft Purview skills that carried over. The exam suited engineers who turn legal and regulatory requirements into technical controls for Microsoft 365 data. It covered classification, sensitivity labels, data loss prevention, retention, records management, eDiscovery, audit and insider risk. The exam used multiple choice and scenario based items. A pass signaled readiness to work as a data security or compliance administrator, a role that still exists under the newer credential.
