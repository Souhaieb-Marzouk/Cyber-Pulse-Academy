T1218.001 System Binary Proxy Execution: Compiled HTML File

T1218.001StealthExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

A CHM file is a single compressed file that holds help pages, pictures and small programs written in script. Windows opens it with a program called hh.exe, which stands for HTML Help. The pages are shown using the same engine that the old Internet Explorer browser used.

Why should you care?

Script inside a CHM runs outside the browser, so browser safety settings do not apply. The viewer hh.exe is signed by Microsoft, so application control tools may allow it without question. A help file that downloads something is almost never normal. If you ignore this, a harmless-looking document can run code on your machine.

How it works, in plain steps

  1. A CHM file is one compressed package that contains help pages, images and small scripts.
  2. Windows opens it with hh.exe, the HTML Help viewer, which is signed by Microsoft.
  3. The viewer draws those pages with the same engine Internet Explorer used, but outside the browser.
  4. Script inside the file runs with the same rights as the person who opened it, with no browser sandbox.
  5. That script can start other programs, download further files, or read data from the computer.
  6. Application control may allow all of this, because it trusts the signed viewer and never inspects the file contents.

Real-world example

Imagine a parcel that looks like a flat-pack furniture box. Inside is not furniture but a small robot with a leaflet of instructions. The delivery office clears the box quickly, because the sender is a shop they know. Only when you open the box and follow the leaflet does the robot start moving around your home. The box is the CHM file, the sender is Microsoft, and the leaflet is the script inside it.

Key takeaways

  • CHM files can carry script that runs outside the browser's safety rules.
  • Watch hh.exe when it opens a file from a user folder or starts another program.
  • A help file that connects to the internet is almost never legitimate.

In more detail

Compiled HTML Help files, which carry the .chm extension, are compressed archives holding HTML pages, images and scripting content. Windows renders them through hh.exe, the HTML Help executable, using underlying Internet Explorer components, so script inside a CHM runs with the privileges of the user who opened it and outside the browser's own security context. An adversary builds a CHM that contains a payload or a downloader, delivers it as a phishing attachment or inside an archive, and relies on the victim to open it, which places the technique under user execution. Because hh.exe is a signed, native Windows binary, application control configurations that only consider executable images may not account for execution that occurs through it, a gap that was especially relevant on older or unpatched systems. Detection evidence concentrates on hh.exe process creation with a file path in a temporary, download or public folder, hh.exe appearing as the parent of a scripting host or command shell, and network connections originating from hh.exe, which a local help file should never produce. Legitimate usage typically shows hh.exe opening a CHM inside a product's Program Files directory from the application's help menu, with no child process and no outbound traffic.
