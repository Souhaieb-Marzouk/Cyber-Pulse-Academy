T1092 Communication Through Removable Media

T1092Command and ControlExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Communication through removable media means two infected computers talk to each other by leaving messages on the same USB stick. One computer is on the internet, the other is locked away on a closed network. The attacker writes a command to the drive, and the other machine reads it later and writes back its answer.

Why should you care?

It gives an attacker a way to give orders inside a network that has no internet connection at all. There is no network traffic to watch, so normal monitoring sees nothing unusual. Without file monitoring on removable drives, an intrusion on an isolated network can stay hidden for a long time.

How it works, in plain steps

  1. The attacker first infects a machine that does have a normal internet connection.
  2. A second machine on the closed network is infected when the same drive is plugged into it.
  3. The implant on the connected machine writes a command file onto the removable drive.
  4. The drive is carried to the closed network and the second implant reads that command file.
  5. The second implant writes results or stolen files back onto the same drive.
  6. When the drive returns to the connected machine, those results are sent out to the attacker.

Real-world example

Think of two prisoners in different cells who cannot speak to each other. A cleaner wheels a laundry cart between the cells. One prisoner hides a note inside a folded towel, and the other prisoner finds it and hides a reply in the same place. Nobody ever saw the two of them communicate, yet messages travel both ways every day.

Key takeaways

  • This technique uses no network connection, so network monitoring alone will never find it.
  • Audit file creation and modification on removable volumes, not just device insertions.
  • Hidden files and folders at the top level of a USB drive deserve a closer look.

In more detail

Communication through removable media is a dead-drop style channel in which two compromised hosts that cannot reach each other over the network exchange commands and files by writing them to a shared removable device. Typically the internet-connected host holds the adversary's real access, while a second host on a segmented or air-gapped network is compromised separately, often through replication by removable media. The implant on the isolated side copies output, tasking or collected files into a hidden directory on the drive; when the drive is carried back to a connected machine, the other implant reads that content and relays it outward, returning new instructions in the same place. The pattern leaves a physical artefact rather than network traffic: recurring file creation and modification on removable volumes, files with hidden or system attributes, unusual directories at the volume root, and a stable file naming or timestamp pattern that repeats each time the medium is mounted. Because there is no session to inspect, detection depends on correlating file-system auditing on the mount point with device connection records.
