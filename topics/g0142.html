G0142 Confucius

G0142Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Confucius is a name given by researchers to a group that spies on governments and armies in South Asia. Spying means quietly reading documents and emails for a long time. The group is best known for sending fake documents that look important to the people it targets.

Why should you care?

Confidential papers about defence, borders and foreign policy can cause serious harm if they leak to another country. The group is patient and returns to the same targets for years, so a single blocked email is not the end of the problem. It also uses ordinary websites and normal web traffic, which makes its activity hard to separate from everyday business. Where this content is taught, remember that a calm, quiet intrusion can do more damage than a loud one.

How it works, in plain steps

  1. The group studies a target office and writes an email that looks like routine government business.
  2. The message carries a document or archive that starts a small program when a person opens it.
  3. That program quietly downloads a remote access tool so the attacker can control the computer.
  4. The attacker searches shared drives and mailboxes for interesting documents and copies them out.
  5. They create scheduled tasks and extra accounts so the access survives restarts and password changes.
  6. They send regular small requests to their own servers, waiting for the next set of instructions.

Real-world example

Imagine a research library where members can request old files. A polite visitor asks for a sealed envelope marked internal review and hands over a form to sign. The envelope is real, and the request looks normal, so the clerk hands it over. Nothing is broken, and no alarm rings. Confucius works in that spirit. It studies the office, copies the style of real messages, and relies on a helpful person opening one document. The theft is slow, quiet and repeated, not a single dramatic break in.

Key takeaways

  • A document can carry a program, so never open unexpected attachments from unknown senders.
  • Long quiet intrusions are hard to spot, so watch for repeated logins and odd scheduled tasks.
  • Public reporting points to a South Asian state interest, but exact sponsor claims stay uncertain.

In more detail

Confucius is a long running espionage cluster named in public research for its focus on South Asian government, military and diplomatic targets. Reporting describes spear phishing messages with weaponised documents and links as the main entry route, followed by loader activity that retrieves a remote access capability and then collects documents, credentials and screenshots from the victim host. The infrastructure is deliberately simple: ordinary hosting, compromised legitimate websites, and command and control reached over common web protocols so that the traffic blends with normal browsing. Evidence available to defenders includes mail gateway detections on document attachments, office applications spawning scripting engines, unusual scheduled tasks for persistence, and regular beacon shaped outbound requests to a small set of domains. The useful misunderstanding to correct is that luring documents are a solved problem: macro restrictions and attachment filtering change the odds, but operators adapt with archive formats, shortcut files and hosted payloads, so monitoring user execution and egress patterns matters more than any single control. Attribution in public reporting points toward a South Asian state interest, though specific sponsor claims rest on moderate confidence and are not treated as settled.

What you will practise

  • Explain how a document based loader chain moves from a phishing email to an interactive remote access session.
  • Identify the host artefacts an espionage loader leaves, including persistence tasks and child processes of office software.
  • Describe the tradecraft choices that help this cluster blend with normal web traffic and legitimate hosting.
  • Summarise what public reporting says about the group's targeting and where attribution confidence is only moderate.
  • Design a monitoring approach for slow document theft that goes beyond blocking email attachments.
