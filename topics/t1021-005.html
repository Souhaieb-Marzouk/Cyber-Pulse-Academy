T1021.005 Remote Services: VNC

T1021.005Lateral MovementExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

VNC stands for Virtual Network Computing. It is a way to see and control another computer's screen over a network. The remote computer sends pictures of its screen, and your mouse and keyboard presses travel back. It works on many systems and is often called screen sharing.

Why should you care?

If an attacker learns a valid password, VNC lets them use a computer like a local user. They can read files, run programs, and jump to other machines without writing any malware. Many VNC servers listen on a fixed network port, so they are easy to find by scanning. If nobody watches for unexpected VNC sessions, this access can stay hidden for a long time.

How it works, in plain steps

  1. Someone installs or enables a VNC server, and that program opens a listening network port.
  2. The server waits for a client, then asks for a password or a local system login.
  3. After the login succeeds, the client receives screen pictures and sends back input events.
  4. The session mirrors the console, so the remote person acts as whoever is already logged on.
  5. An intruder can then copy files, run commands, and start VNC links to other computers.
  6. Some VNC versions handle passwords weakly, so attackers may guess them or abuse known bugs.

Real-world example

Think of a hospital night desk with a big window. The nurse inside can see the whole ward and reach the controls. VNC is like giving a stranger the same window and a long stick that moves the switches. If the stranger has a valid staff card, the door opens and nobody questions it. The danger is not the window itself, but who is holding the stick.

Key takeaways

  • Unexpected VNC software or a new listener on a VNC port is a strong warning sign.
  • VNC mirrors the console, so it uses the rights of the logged-on user, not a separate account.
  • Check who started each VNC session and from which network before you trust it.

In more detail

VNC, or Virtual Network Computing, is a screen-sharing service that relays a remote computer's display, mouse, and keyboard over the network using the RFB protocol. Unlike Remote Desktop Protocol, which shares a whole session and its resources, VNC mirrors the existing console, so a remote operator sees and acts as whoever is already logged on. An intruder holding valid credentials can therefore open documents, pull files, run commands, and pivot to further hosts. Defenders spot it through inbound connections to the well-known VNC ports, the sudden installation or enablement of a VNC server or service, and authentication failures recorded by the VNC daemon itself. Legitimate remote-support sessions usually trace back to a known administrative tool, a scheduled window, and a consistent source subnet.

What you will practise

  • Explain what VNC is and how it differs from resource-sharing remote desktop tools.
  • Describe how a VNC session is set up, from listener to authenticated screen share.
  • Identify the network and host artefacts that a VNC connection leaves behind.
  • Distinguish legitimate remote-support use of VNC from intruder activity.
  • List the log sources that help attribute a VNC session to an account and a host.
