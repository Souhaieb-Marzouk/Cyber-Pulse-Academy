DET0379 Detect Evil Twin Wi-Fi Access Points on Network Devices

DET0379Detection StrategyVery hardDetection Strategy

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

An evil twin is a fake wireless network that uses the same name as a real one. People connect to it because it looks familiar. This detection compares what the wireless system sees with the list of approved access points. It catches the fake one by its different hardware address.

Why should you care?

When a user joins the fake network, their traffic can be read or changed without any warning. The fake access point is often stronger than the real one, so devices choose it. Because the name is identical, users have no reason to suspect anything. Finding it quickly is the only way to protect credentials typed during that session.

How it works, in plain steps

  1. Collect wireless controller and access point logs that report nearby and rogue access points.
  2. Collect wireless intrusion detection alerts for duplicate network names in the same area.
  3. Compare every reported network name against the approved access point inventory with its hardware address.
  4. Correlate a wave of client disconnects with immediate reassociation to an unknown access point.
  5. Check whether clients received certificate errors or portal warnings at the same time.
  6. Alert with the physical location, the spoofed name, and the unapproved hardware address.

Real-world example

Think of a sign in sheet at a conference desk. A person writes a name that is already on the list. The name looks right, but the handwriting and the badge number are new. The organiser checks the badge, not the name. The hardware address is that badge.

Key takeaways

  • The network name proves nothing; the hardware address of the access point is what you verify.
  • A burst of disconnects followed by reassociation to an unknown device is a strong combined signal.
  • A current inventory of approved access points is the foundation of this detection.

In more detail

This strategy detects evil twin access points, where an adversary stands up a wireless access point that copies the name of a legitimate network so that clients associate with it and expose their traffic. Detection lives in the wireless control plane: wireless controller and access point logs reporting a neighbouring basic service set identifier with a matching service set identifier but a different radio hardware address, sudden client disconnects followed by reassociation to an unknown access point, duplicate service set identifier alerts from the wireless intrusion detection system, and certificate or captive portal failures that show clients rejecting a spoofed network. The pattern is a same name, different hardware address combination on the same channel area. It fails when the wireless controller does not forward rogue access point events, when the site survey is stale, and when the same network name is legitimately broadcast by guest or partner infrastructure.
