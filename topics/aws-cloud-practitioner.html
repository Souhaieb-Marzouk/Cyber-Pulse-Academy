CLF-C02 AWS Certified Cloud Practitioner (CLF-C02)

CLF-C02AWSHardCertificationUnofficial Study Resource

In more detail

AWS Certified Cloud Practitioner (CLF-C02) is a foundational certification for people starting with AWS who need to speak about it accurately rather than build on it. The exam is organised into 4 content domains: Cloud Concepts (24%), Security and Compliance (30%), Cloud Technology and Services (34%), Billing, Pricing, and Support (12%). It is delivered as 50 scored questions and 15 unscored, scored against a scaled pass mark of 700 out of 1,000 with no per-domain minimum, so strength in one domain offsets weakness in another. Every task statement in this topic carries a MEDIUM and a HARD exercise batch, so the practice material follows the published outline of the exam rather than a general reading list. The statements here are taken from the exam guide, and the task list is the one AWS publishes: if AWS revises the guide, this topic is revised with it.
