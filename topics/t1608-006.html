T1608.006 Stage Capabilities: SEO Poisoning

T1608.006Resource DevelopmentExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

SEO means search engine optimisation, which is the work of helping a page appear high in search results. SEO poisoning means an attacker tricks a search engine into ranking their bad page near the top. When you search for something normal, their page may be the first result you see. This is one part of a wider idea called staging capabilities, where an attacker prepares everything before the attack starts.

Why should you care?

People trust search results more than they trust email links. A poisoned result arrives with no warning banner and no suspicious sender. Attackers may also target searches for software and code, which developers run all day. If you only filter email, this route stays open.

How it works, in plain steps

  1. Search engines rank pages by words, links, age, and how people use them.
  2. The attacker fills a page with popular keywords, sometimes as hidden text.
  3. They add links from other sites so the page looks popular and trusted.
  4. The page shows normal content to search robots and a payload to people.
  5. Because the ranking is earned over time, victims arrive by searching rather than by email.
  6. The same trick works on in site search for code hosting and app stores.

Real-world example

Imagine a library where the shelves are arranged by how often a book is borrowed. Someone slips a fake book onto a popular shelf, with a cover that matches the topic everyone wants this month. Borrowers pick it up because it sits right beside the real books. Inside, the first page looks normal, and a later page sends the reader somewhere else. The librarian never approved that book, but the shelf itself made it look trustworthy.

Key takeaways

  • Search results can be manipulated, so top ranking is not a safety signal.
  • Hidden keywords and borrowed links are the main tricks behind SEO poisoning.
  • Watch for machines reaching new domains soon after a web search.

In more detail

SEO poisoning is the deliberate manipulation of search ranking signals so that attacker controlled pages appear above legitimate results for terms the target is likely to search. Search engines rank pages using crawler derived signals such as keyword relevance, inbound links, page age, and click behaviour, and each of those signals can be gamed. Adversaries stuff keywords, including hidden text a visitor never sees, into compromised sites, plant or purchase inbound links, and run cloaking logic that serves different content to a crawler than to a human visitor. The same approach is applied to in site search on developer platforms, where a malicious package or repository is promoted by inflating popularity metrics. Campaigns often pair the poisoned page with conditional redirects that inspect browser headers, language settings, or mouse movement before delivering a payload. Defenders detect it through search result monitoring for brand and topic terms, unexpected outbound links on owned sites, and proxy or name resolution logs showing workstations reaching new domains shortly after a search.

What you will practise

  • Explain how search engines rank pages and which ranking signals can be gamed.
  • Describe keyword stuffing, link planting, and cloaking as separate behaviours.
  • Explain why poisoned in site search on developer platforms is a supply chain risk.
  • Identify the telemetry that shows a workstation following a poisoned result.
  • Summarise how cloaking hides malicious content from automated scanners.
