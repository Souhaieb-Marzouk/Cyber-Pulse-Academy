G0125 HAFNIUM

G0125Enterprise GroupExtremeThreat Group

HAFNIUM is an intrusion set that Microsoft and other vendors have attributed to a China-based nexus, and the cluster became widely known in early 2021 after reporting described mass exploitation of vulnerabilities in on-premises internet-facing Microsoft Exchange Server deployments. The group is best understood by its initial access method rather than by a distinctive malware family: public reporting describes opportunistic scanning for vulnerable Exchange servers followed by server-side exploitation that allowed attackers to run commands, drop web shells, and reach credentials and mailbox data without needing to phish a user. Victims reported at the time spanned infectious disease researchers, law firms, defence contractors, policy think tanks, and non-governmental organisations, with a concentration in the United States; subsequent reporting described follow-on activity against additional Exchange flaws and against other internet-facing products. Tradecraft attributed to the group includes web shell persistence on compromised servers, credential theft from the host including from memory, lateral movement using remote administration tooling, and the use of compromised infrastructure for further operations. Because the initial access vector is an unpatched or unreachable-to-patch perimeter service, the defender's central problem is inventory and patch velocity for systems that are exposed to the internet but are often not covered by standard endpoint agents and may lack adequate logging. Detection effort should target web server process trees, file-write events in application directories, authentication from unusual sources, and mailbox access patterns inconsistent with user behaviour. Attribution is a third-party assessment and the group's publicly known tooling is not unique to the cluster.

What you will practise

  • Explain why on-premises, internet-facing and agentless servers are a persistent blind spot in detection coverage.
  • Build detections for web server processes spawning command interpreters and for web shell file-write behaviour.
  • Describe what Exchange server compromise exposes beyond the host itself, including mailbox and credential material.
  • Design logging and inventory requirements for perimeter services that fall outside standard endpoint tooling.
  • Prioritise patch and mitigation work using exposure data rather than severity scores alone.
  • Sequence containment for a compromised perimeter server while preserving volatile evidence for investigation.
  • Explain how credential theft from an exploited server enables follow-on access to other enterprise systems.
