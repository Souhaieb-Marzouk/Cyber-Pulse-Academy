Privileged Access Management

Identity & AccessVery hardKeyword

Privileged access management (PAM) is the discipline and tooling set that controls, brokers, records and audits the use of accounts with elevated rights, including domain administrators, root, database superusers, cloud root and organisation owner roles, and the service accounts that hold equivalent power. The core problem PAM addresses is that privileged credentials are shared, rarely rotated, widely copied into scripts and configuration files, and almost never attributable to an individual, so a single disclosure can be replayed indefinitely with the full authority of the account. A mature programme removes standing privilege wherever possible by vaulting credentials and checking them out for a bounded window, injecting them into sessions so the human never sees the secret, brokering interactive sessions through a jump host that records keystrokes and commands, and replacing human-held credentials with short-lived certificates or tokens. Just-in-time elevation, approval workflows and break-glass procedures with mandatory post-use review are the mechanisms that make this workable when a human genuinely needs emergency access. Beyond vaulting, PAM covers the secrets that machines use: application credentials, API keys and certificates stored in a managed vault with automatic rotation rather than committed to repositories or baked into images. The detection value is substantial, because privileged session recordings, checkout logs and vault audit trails give defenders a well-defined baseline against which unusual hours, unusual source hosts, direct use of an unvaulted credential, or elevation outside the approved workflow stand out sharply.

What you will practise

  • You will be able to inventory privileged identities across on-premises, cloud and database estates and classify them by blast radius.
  • You will be able to design credential checkout, session brokering and rotation workflows that eliminate standing privilege.
  • You will be able to explain how session recording, keystroke logging and command-level auditing support investigation and attribution.
  • You will be able to define break-glass access procedures with approval, time bounds and mandatory post-incident review.
  • You will be able to detect use of unvaulted credentials, out-of-window elevation and anomalous privileged session sources.
  • You will be able to extend PAM controls to service accounts, API keys and certificates with automated rotation.
