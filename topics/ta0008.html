TA0008 Lateral Movement

TA0008EnterpriseExtremeTactic

Lateral Movement is the tactic describing how an adversary moves between systems inside a network, using stolen credentials, remote management protocols, and trusted administrative channels to reach higher-value targets. Behaviours include remote desktop sessions, server message block and administrative share access, secure shell logins, remote service creation and scheduled task deployment, execution framework agents, and pivoting through compromised hosts to reach network segments that are not directly accessible. The telemetry picture is mixed. Authentication events across directory services and endpoints record the source, target, account, and logon type for most remote access, and service creation, remote process start, and file writes to administrative shares show what the adversary did on arrival. Network flow data identifies new host-to-host relationships and unusual internal fan-out. The core detection problem is that lateral movement is largely indistinguishable from normal administration by design: administrators use exactly these protocols and credentials. What separates them is context, such as an account authenticating from a workstation it never uses, administrative protocols appearing on endpoints where they were previously absent, or a single source touching many targets in sequence. Detection therefore relies on relationship baselines, careful use of honeypot or decoy credentials, segmentation that limits what is reachable, and rapid correlation of authentication, process, and flow evidence into a movement path rather than a list of isolated alerts.

What you will practise

  • Describe the remote access protocols and administrative mechanisms adversaries use to move between systems and what each leaves behind.
  • Correlate authentication, process creation, service installation, and network flow data into a coherent movement path.
  • Baseline legitimate host-to-host and account-to-host relationships so unexpected pairings become detectable.
  • Explain how network segmentation and just-in-time administrative access change what lateral movement is even possible.
  • Use decoy credentials and canary hosts to raise detection confidence without adding analyst load.
  • Prioritise containment actions that break a movement path rather than only cleaning individual hosts.
