Explained in plain language

Written for beginners. No security background needed.

Simple definition

The eJPT is an entry-level certification from INE about penetration testing. Penetration testing means testing computer systems with permission, in order to find security weaknesses. It is a practical exam, so you work inside a lab network instead of answering questions from memory. It is aimed at people who are new to security work but comfortable with computers and networks.

Why should you care?

Employers often doubt certificates that only test theory, because real testing needs hands on skill. The eJPT is graded from work you actually perform in a lab, so it answers that doubt. It gives you a clear first milestone on the offensive security path. It is also a natural next step towards more advanced certifications. It teaches you to write down findings, which is a large part of a real tester's job.

How it works, in plain steps

  1. Learn the basics of networks first: addresses, ports, protocols and how a request reaches a service.
  2. Study each exam area in turn, starting with reconnaissance and assessment methodology.
  3. Practise in your own lab with two or three virtual machines that you own and control.
  4. Keep notes as if you were writing a report, because the exam questions ask about your findings.
  5. Take the practical exam inside the time window, working from your notes and your own lab habits.
  6. Answer the questions as you go, because the exam is graded from the answers you submit about the lab.

Real-world example

Imagine a small office network with a web server, a file share and a few staff laptops. You are a junior tester, and you have written permission to test it. First you find which machines are switched on. Next you scan them to see which doors, called ports, are open. Then you check whether a service runs an old version with a known flaw. Finally you write a short report. The report says what you found, how serious it is, and how to fix it. The eJPT exam asks you to do exactly this in a practice network.

Key takeaways

  • You must be comfortable with basic networking before you start.
  • Practical lab hours matter far more than reading alone.
  • Written permission is always required before you test any system.

In more detail

The INE eJPT, also called the Junior Penetration Tester certification, is an entry-level, hands-on credential for people who want to test systems for weaknesses rather than only defend them. It suits students, help desk staff, system administrators and developers who understand basic networking and want proof of practical skill. It proves to an employer that you can find hosts, scan them, exploit known weaknesses and report the result inside a real lab, not just describe tools in theory. The exam is a practical assessment: you work through a virtual network and answer questions about what you found, with a generous time window rather than a fixed question count. It leads to junior penetration tester, security analyst and vulnerability assessment roles, and it prepares you for the vendor's more advanced professional level. Exam domains and objectives

  • Identify live hosts, open ports and running services on a target network segment.
  • Gather information about a target organisation from public sources without touching its systems.
  • Assess how serious a discovered weakness is and explain the likely impact to a client.
  • Compile host information such as users, accounts, shares and system details from a compromised machine.
  • Use exploitation tools and modify an existing exploit so that it works against a target service.
  • Find and confirm common weaknesses in a web application, including hidden files and weak login pages.
