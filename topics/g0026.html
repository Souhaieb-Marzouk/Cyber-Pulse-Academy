G0026 APT18

G0026Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

APT18 is a research name for a cyber spying group that public reports link to China. It is also called Dynamite Panda. It misuses normal file sharing services and stolen signing keys to hide its harmful programs.

Why should you care?

A digital signature tells you which company signed a file, not whether the file is safe. If a key is stolen, harmful files can look completely legitimate. Using well-known sharing sites also hides traffic, because those sites are usually allowed. Antivirus tools may trust signed files and miss them. That means you need to check file details and watch for odd uploads, not just rely on a green tick.

How it works, in plain steps

  1. The attackers steal a signing key from a company that software trusts.
  2. They use that stolen key to sign their own harmful program as if it were genuine.
  3. The signed file now looks genuine to the operating system and to users.
  4. They upload the file to a popular file sharing service that the network allows.
  5. The victim machine downloads it through traffic that looks like ordinary business activity.
  6. The same services carry instructions and stolen data back and forth without raising suspicion.

Real-world example

Think of a courier who copies the logo and van of a well-known delivery firm. Every building he visits lets him through the loading bay, because the uniform and the paperwork look correct. Guards check the branding, not the driver. He makes deliveries and collections all day without being questioned once. A stolen signing key is that copied uniform. Everything about the file looks trustworthy. The check that should protect you confirms exactly the details the attacker forged.

Key takeaways

  • A valid signature proves who signed a file, not that it is safe.
  • Attackers hide traffic inside services your network already trusts.
  • Stolen certificates must be revoked quickly when a theft is found.

In more detail

APT18, also reported as Dynamite Panda, is an espionage cluster that public reporting associates with China-nexus operators and describes as targeting technology, defence, government and healthcare organisations. Its core tradecraft is abuse of legitimate third-party services: reporting describes public file and note sharing platforms hosting payloads and instructions, so outbound traffic resembles normal business use of a trusted service. Reporting also describes stolen code-signing certificates, where a key belonging to a real company signs malicious software so it appears to come from a trusted publisher. That attacks trust twice, first in a service the network allows and then in a signature the operating system respects. A valid signature proves only who signed a file, not that it is safe.

What you will practise

  • Explain what a digital signature proves and what it does not prove.
  • Describe how stolen code-signing certificates enable malware that appears legitimate.
  • Explain how legitimate cloud services can be abused for staging and command-and-control.
  • Identify detection opportunities in file metadata, certificate status, and service usage logs.
  • Describe the incident response steps required when a signing key is compromised.
  • Explain why trust in a platform is not the same as trust in its content.
