G0056 PROMETHIUM

G0056Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

PROMETHIUM is a research name for a group that steals information. Public reports link it closely to a toolset called StrongPity. They are best known for handing out real programs that have been secretly changed. Reported targets include Turkey, the Kurdish region, and parts of Europe.

Why should you care?

Everyone is taught to download tools only from official places, and that advice is good. But this group attacks the next step: it makes an official looking copy that includes something extra. If you trust a file because it is a well known program, you may install the attacker along with it. Checking where a file really came from is the defence.

How it works, in plain steps

  1. The attacker takes a popular free program that many people already want.
  2. Extra hidden code is added so the installer does two jobs at once.
  3. A real but compromised website offers the changed file to visitors.
  4. The victim installs the program and receives the hidden access as well.
  5. The hidden part contacts a fixed outside server for further instructions.
  6. Documents and messages are collected and sent to the attacker over time.

Real-world example

Imagine buying a well known brand of coffee from a shop you trust. The tin looks right and the label is perfect. Inside, someone has added a small packet that is not coffee at all. You drink your usual cup and notice nothing strange. The packet is the hidden access and the shop is the compromised website.

Key takeaways

  • Always confirm you downloaded software from the official source, not a copy.
  • Compare installed program versions against the vendor's release list.
  • Watch outbound connections from programs you have just installed.

In more detail

PROMETHIUM is an espionage cluster best known from public reporting on the StrongPity toolset, which vendors have described in campaigns against users in Turkey, the Kurdish region, Italy, Belgium, and neighbouring areas. Its signature tradecraft is the trojanised installer: a genuine, popular utility is repackaged so that installing it also installs the attacker's backdoor, which means the victim deliberately runs the file and sees expected behaviour. Public analyses also describe watering hole compromises, where a legitimate site is modified to serve the repackaged installer only to selected visitors, and the use of certificate material to make malicious files appear trustworthy. The group maintains a small set of durable command and control locations rather than rotating infrastructure quickly, which is one of the few stable detection anchors available. The common misunderstanding is that file hashes are enough; the underlying utilities are legitimate and frequently updated, so version comparison and source verification matter more than any single hash. Evidence lives in download records, software inventory mismatches, and outbound connections from newly installed programs.
