M1049 Antivirus/Antimalware

M1049Enterprise MitigationVery hardMitigation

Antivirus and antimalware controls are the endpoint and gateway technologies that identify, block, quarantine, and remediate malicious files, scripts, and behaviour before or during execution. A modern deployment is rarely signature-only: it combines static signatures and hashes, emulation and unpacking of obfuscated content, heuristic and machine-learning scoring, script-scanning interfaces that inspect interpreter content at runtime, behavioural monitoring of process trees and file operations, and cloud reputation lookups for samples the local engine has not seen. Protection is placed at several chokepoints, including the endpoint agent with on-access and on-write scanning, mail gateways that strip or detonate attachments, web proxies that block known-malicious downloads, and server or container layers where scanning is often omitted for performance reasons. Operationally the control is dominated by tuning and by exclusions. Build directories, database data paths, backup volumes, and vendor application folders produce constant false positives, and every documented exclusion becomes a place where an intruder can operate unobserved, which is why exclusion lists deserve the same review discipline as firewall rules. The control reliably defeats commodity and mass-market malware, script-based loaders, well-known ransomware families, and infostealers, and it frequently supplies the first detection signal for an intrusion that other controls missed. Its limitations are structural: novel or lightly modified samples evade signatures, living-off-the-land execution and in-memory payloads leave little on disk to scan, attackers target the agent itself for tampering, encrypted archives and some delivery paths escape inspection entirely, and agents left disabled or excluded on server tiers create large unprotected areas.

What you will practise

  • Explain how signature, heuristic, behavioural, and reputation layers complement each other and where each one fails.
  • Tune detection and exclusions for production workloads without creating blind spots an intruder can exploit.
  • Interpret malware alerts alongside process, script, and network telemetry during initial triage.
  • Evaluate agent tamper protection and coverage gaps across servers, containers, and remote endpoints.
  • Assess why script-based, in-memory, and living-off-the-land execution evade file-based detection.
  • Prioritise quarantine and remediation actions when a detection lands on a critical production system.
