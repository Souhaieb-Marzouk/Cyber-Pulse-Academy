T1020.001 Automated Exfiltration: Traffic Duplication

T1020.001ExfiltrationExtremeTechnique

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Traffic mirroring means copying network traffic and sending the copy somewhere else so it can be watched. Network engineers use it as a normal tool for finding faults. This sub-technique is when an attacker changes that setting so the copy goes to a system they control. The parent technique covers automated data transfer in general, while here the network device itself makes the copy.

Why should you care?

Copies of network traffic can contain passwords, documents and session details. The copy leaves through the network device, so no file is taken from any computer. Audit teams often review hosts but forget device settings. If nobody logs changes on switches and cloud networks, this path can stay invisible for a long time.

How it works, in plain steps

  1. The attacker gets administrative access to a switch, router or cloud network.
  2. They change the mirror setting so a chosen source is copied to a new target.
  3. The copy is sent to a collector the attacker controls, inside or outside the network.
  4. Because the device does the work, no extra program runs on the monitored host.
  5. They may combine it with sniffing or session capture to collect useful secrets.
  6. They restore the setting later so the change is hard to notice.

Real-world example

Think of a hotel front desk that photocopies every guest passport for its records. A clerk changes one setting so the photocopies also go into a private locker. The guests never notice, and no item leaves the desk in a bag. The copying is part of normal work, which is exactly why nobody questions it. Traffic duplication turns a network device into that redirected photocopier.

Key takeaways

  • Traffic copies can leave through a network device without touching any host.
  • Configuration change logs on switches, routers and cloud networks are essential.
  • Know every approved mirror or tap target so that a new one stands out.

In more detail

Traffic duplication is the sub-technique of abusing a device's built-in traffic mirroring feature so that a copy of network traffic is forwarded to infrastructure the adversary controls. The parent technique describes automation of data movement in general; here the network itself provides the automation and the mirror becomes the transport. The feature is legitimate and widely used: switches and routers offer port mirroring or monitor sessions, and cloud platforms offer virtual taps where a user names the source instances to copy from and a destination target to send to. An attacker who can alter that configuration can redirect a copy of traffic to an external collector without placing any tool on the monitored host. Malicious changes at firmware level on network devices can enable the same redirection, which is why device integrity matters. Detection focuses on configuration change logs, authentication and command history on network devices, cloud audit records for tap creation or modification, and traffic arriving at a destination that no approved monitoring system owns.
