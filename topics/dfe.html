EC-Council DFE

EC-CouncilExtremeCertificationUnofficial Study Resource

In more detail

EC-Council DFE is a professional certification offered by EC-Council. This independent study guide covers all 12 course modules: Computer Forensics Fundamentals, Computer Forensics Investigation Process, Hard Disks and File Systems, Data Acquisition and Duplication, Defeating Anti-Forensics Techniques, Windows Forensics, Linux and Mac Forensics, Network Forensics, Investigating Web Attacks, Dark Web Forensics, Investigating Email Crimes, Malware Forensics. Every module has a MEDIUM and a HARD scenario exam, written as realistic workplace situations rather than recall questions, so you practise applying each module the way the job asks for it.

Unofficial Study Resource. Unofficial Study Resource.
