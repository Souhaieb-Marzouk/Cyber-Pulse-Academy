T1021.001 Remote Services: Remote Desktop Protocol

T1021.001Lateral MovementVery hardTechnique

Remote Desktop Protocol is a Microsoft protocol that provides graphical remote access to a Windows session, and it is one of the most common lateral movement mechanisms because it is enabled by default on many server builds and requires only valid credentials and reachable network access. An adversary who has obtained credentials or a session token can authenticate to a target host, interact with the desktop as the compromised identity, and from that host repeat the process toward further systems. The same protocol is used for legitimate administration and remote work, which is why detection depends on context, direction of travel, and authentication characteristics rather than on the protocol itself. Events are recorded on both ends. The source host shows a client process and outbound connection to the destination port, while the destination host records the logon with a network logon type, the source address, and often a dedicated operational log for connection and session events that captures the connecting account, address, and session identifiers. Where a gateway or jump host mediates access, gateway logs supply the external source address and may reveal whether the connection was brokered by a known administrative path. Additional artefacts include the creation of user profile directories on first logon, drive and clipboard redirection activity, and any process spawned from the session. Benign remote desktop traffic is extremely heavy in most estates, frequently originating from administrative subnets and management platforms. Investigations look at whether the destination host is one this account or this source normally reaches, whether the connection occurred outside a change window, whether the authentication used a local or domain account that should not be used interactively on that host, and what happened immediately after the session began. Compromised sessions frequently exhibit short dwell time, tool execution, and a rapid sequence of connections to additional hosts using the same credentials.

What you will practise

  • Explain how network logon types, session identifiers, and connection logs combine to identify remote desktop access to a host.
  • Correlate source-side client process telemetry with destination-side authentication records to confirm a session.
  • Distinguish bastion and administrative remote desktop use from adversary lateral movement using baseline direction and account norms.
  • Analyse authentication anomalies such as local account usage, unusual logon hours, and first-seen source to destination pairs.
  • Describe the evidence available when a session is brokered through a gateway or jump host and how it changes scoping.
  • Map remote desktop lateral movement to ATT&CK and specify the mitigation controls that constrain it most effectively.
