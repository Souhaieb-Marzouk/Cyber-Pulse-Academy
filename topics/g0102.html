G0102 Wizard Spider

G0102Enterprise GroupExtremeThreat Group

New to this? Start here

Explained in plain language

Written for beginners. No security background needed.

Simple definition

Wizard Spider is the name for a criminal group that public reporting links to Russia. It has been active since about 2016. It started with a harmful program that steals banking details. Later it moved to ransomware, which locks files until a payment is made. It has attacked hospitals as well as large companies.

Why should you care?

This group is known for speed. Public reports describe ransomware appearing within hours of the first break in. It steals passwords first and creates extra accounts, so removing one entry point is not enough. It also turns off security tools before it acts. If your team waits for a clear sign, such as files being locked, the useful warnings have already passed. Recovering from backups takes days or weeks, and patient care can suffer.

How it works, in plain steps

  1. The intruders get in through a harmful email attachment, or by buying stolen logins.
  2. They use those logins to connect through remote access services such as a company VPN.
  3. They collect passwords from memory and from the directory database that lists all accounts.
  4. They create new accounts, services and scheduled tasks so their access survives a cleanup.
  5. They move to other computers using remote desktop and hunt for backups and valuable files.
  6. They disable security tools, delete recovery copies, and then lock the files for payment.

Real-world example

Imagine robbers who study a bank for weeks. They do not attack the main vault door, which is strong. They learn the staff entrance code, walk in during a shift change, and quietly turn off the alarm panel. Then they copy keys, open a side door for the others, and empty the safe before anyone calls the police. The locks were never the weak point. The weak point was the familiar routine around them. Ransomware crews work the same way. They spend their time on logins, alarms and back doors, and only touch the safe at the very end, when help is already too late.

Key takeaways

  • The warning signs appear hours before files are locked, so watch for them early.
  • Turning off security tools and deleting recovery copies are strong alert signals.
  • Stolen passwords and remote access logins are the main way these crews get in.

In more detail

Wizard Spider is a Russia based financially motivated threat group that MITRE ATT&CK describes as originally known for creating and deploying the TrickBot trojan from at least 2016, and later for ransomware operations against targets that range from major corporations to hospitals. The important property of this cluster is tempo rather than any single tool. Public incident write-ups collected with the entry show a consistent chain: initial access through spear phishing lures or stolen credentials used against remote access services, fast credential theft from memory and directory databases, redundant persistence through new local and domain accounts, services and scheduled tasks given legitimate sounding names, then movement over remote desktop to servers that hold backups or payment data. Defenders also see defence evasion before encryption: security tooling disabled or uninstalled, a registry setting changed so that logon secrets are cached in memory in a recoverable form, backup and recovery features such as volume shadow copies deleted, and data staged into archives in unusual folders before being pushed out over file transfer or cloud storage. Because many of the tools used are publicly available administration utilities, signature matching on tool names is weak and behaviour based detection on process ancestry, service creation and authentication patterns carries more weight. The frequently repeated misunderstanding is that encryption is the incident. In these reports encryption is the last step of a chain that already includes hands on keyboard activity for hours, so detection that waits for mass file modification has already missed every chance to stop it.

What you will practise

  • Explain what Wizard Spider is and why public reporting treats it as financially motivated.
  • Trace the chain from stolen credentials to ransomware and identify where it can be broken.
  • Recognise the privilege escalation and persistence artefacts this activity leaves on a host.
  • Explain why recovering credentials from memory and directory databases is a turning point of the intrusion.
  • Describe detection opportunities created when security tooling is disabled or recovery features are removed.
  • Prioritise response actions when an intrusion appears to be hours old rather than days.
