# CyberPulseAcademy build requirements
#
# The build, the validation gate and the CI workflows need NOTHING beyond the
# Python standard library. That is a deliberate choice: a contributor should be
# able to clone the repository and run the build on any machine with Python 3.8+
# installed, with no virtual environment and no network access.
#
#   python scripts/build_catalog.py
#   python scripts/generate_pages.py
#   python scripts/generate_og.py
#   python scripts/validate.py
#   python scripts/new_topic.py --type keyword --id example --title "Example"
#
# The single optional extra below is used only by `generate_og.py --png`. It
# exists because Facebook, LinkedIn and X do not render SVG link previews, so a
# raster Open Graph image is needed if you want a preview card on those
# platforms. The default SVG output needs no dependency at all, and the script
# degrades to SVG with a clear message when Pillow is absent.
#
#   python -m pip install -r scripts/requirements.txt

Pillow>=10.0.0,<12.0.0
