# CyberPulseAcademy

A free, non-commercial, static study platform for people who work in cyber security and need to get sharper under realistic pressure.

CyberPulseAcademy is a pure static site: hand-written HTML, hand-written CSS, vanilla JavaScript with no framework and no build step, and a small set of Python scripts that use nothing but the standard library. There is no server, no database, no account system and no third-party script. It is designed to be published on GitHub Pages by forking or cloning this repository, editing three values in one config file, and pushing.

Each of the 246 topics carries a written explanation, a set of learning objectives, its sources, cross-links to related topics, and a reservation for **three independent exercise batches**. Each batch is a single self-contained HTML file that the site frames and scores. Reading is always open; only starting an exercise asks for a display name and a country, and those stay in the browser unless the owner deliberately turns on remote statistics.
